Математическая логика (и не только она) состоит из двух частей:

*   **Синтаксис** — запись, форма.
*   **Семантика** — смысл, содержание.

---

## Формальная система

Формальная система нужна для того, чтобы из истинного утверждения получать истинное на этапе синтаксиса (т.е. манипулируя только формой, без обращения к смыслу), чтобы превратить математику из "искусства рассуждать" в механическую дисциплину.

Это набор из 4 множеств:
1.  **Алфавит** ($\sum$)
2.  **Формулы** ($F$)
3.  **Аксиомы** ($A$)
4.  **Правила вывода** ($R$)

### 1. Алфавит ($\sum$)
Как правило, это счётное множество.

### 2. Формулы ($F$)
Некоторое подмножество множества $\sum^*$ (где $\sum^*$ — множество всех конечных слов в алфавите $\sum$).

### 3. Аксиомы ($A$)
Некоторое подмножество множества формул ($A \subset F$).

### 4. Правила вывода ($R$)
Отображение из множества формул в новую формулу. 
Из $k$ формул получают одну новую.
$$R: F^k \to F$$
Правила вывода определены частично (некоторым наборам формул может не соответствовать ничего).

> **Выводимость**
> 
> Формула $A$ **выводится**, если существует последовательность $A_1, A_2, \dots, A_n = A$, где каждое $A_i$ либо является аксиомой, либо получено из предыдущих по правилу MP. Число $n$ — **длина вывода**.

$$
A_{1}, A_{2}, \dots, A_{n} \vdash A
$$

> **Условная выводимость**
> 
> Формула $A$ **выводится из множества гипотез $\Gamma$**, если в последовательности вывода $A_i$ может также являться гипотезой из $\Gamma$.

$$
\text{Г} \vdash A
$$
