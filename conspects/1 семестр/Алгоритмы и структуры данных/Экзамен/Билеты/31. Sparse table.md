## 1. **Область применимости**

**Разреженная таблица** — это структура данных, предназначенная для **быстрого ответа на запросы** на **статическом массиве** (без изменений элементов после построения).

### Основные условия применения:

- **Операция `F`** должна быть:
    
    1. **Ассоциативной**  
        `F(F(a, b), c) = F(a, F(b, c))`
        
    2. **Идемпотентной** 
        `F(a, a) = a`
        
    3. **Коммутативной** (необязательно)
        

### Примеры операций:

- **Минимум** (`min`) - подходит
    
- **Максимум** (`max`) - подходит
    
- **Наибольший общий делитель** (`gcd`) - подходит
    
- **Сумма** (`sum`) - не подходит

---

## 2. **Построение разреженной таблицы**

### Определение:

`ST[i][j]` — результат операции `F` на отрезке длиной `2^j`, начинающемся в индексе `i`.

Формально:

$ST[i][j]=F(A[i],A[i+1],…,A[i+2^j−1])$

где:

- `i` — начало отрезка (0 ≤ i < N)
    
- `j` — степень двойки (0 ≤ j ≤ ⌊log₂N⌋)
    

### Алгоритм построения:

1. **Инициализация** (j = 0):
    
    $ST[i][0]=A[i][0]$
    
    Каждый элемент массива — отрезок длины 1.
    
2. **Рекуррентное соотношение** (j > 0):
    
    $ST[i][j]=F(ST[i][j−1],ST[i+2^{j-1}][j−1])$
    
    Отрезок длины `2^j` разбивается на два отрезка длины `2^{j-1}`.

### Сложность построения:

- **Время:** O(N log N)  
    (каждая ячейка вычисляется за O(1))
    
- **Память:** O(N log N)  
    (N строк, log N столбцов)

---

## 3. **Ответ на запрос**

### Предподсчёт логарифмов:

Для ускорения запросов предподсчитываем массив `log2[k]` = ⌊log₂k⌋ для k от 1 до N.

### Запрос на отрезке [L, R]:

1. Находим длину отрезка: `len = R - L + 1`
    
2. Находим `k = log2[len]` — наибольшую степень двойки, не превышающую длину отрезка.
    
3. Ответ:
    
    $F(ST[L][k],ST[R−2^k+1][k])$
    
    Берём два **перекрывающихся отрезка** длины `2^k`, покрывающих [L, R] 
    (поэтому нужна идемпотентность)
    

### Пример:

Для отрезка длины 6 (k = 2, т.к. 2² = 4 ≤ 6) берём:

- `ST[L][2]` — отрезок [L, L+3]
    
- `ST[R-3][2]` — отрезок [R-3, R] = [L+2,L+5]
    

### Сложность запроса:

- **Время:** O(1)  
    (только два обращения к таблице + операция `F`)
