#### Суть

Мы постепенно разрешаем использовать в качестве промежуточных пунктов вершины $0, 1, 2, \dots, k$.

- На шаге $k$ значение `dist[i][j]` — это кратчайший путь от $i$ до $j$, в котором в качестве промежуточных узлов могут быть только вершины из набора $\{0, 1, \dots, k\}$.
    

___

#### Матрица смежности (`dist[i][j]`)

В отличие от Дейкстры, здесь нам не нужны списки смежности. Мы работаем напрямую с квадратной матрицей:

- `dist[i][j] = weight`, если есть ребро.
    
- `dist[i][i] = 0`.
    
- `dist[i][j] = ∞`, если ребра нет.
    

___

#### Код

```java
for (int k = 0; k < n; k++) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
	        dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
        }
    }
}
```

**Асимптотика:** $O(V^3)$

___

>[!QUESTION] Как обнаружить отрицательный цикл?
> 
> Если `dist[i][i] < 0` — значит, через вершину $i$ проходит **отрицательный цикл**. Ты можешь бесконечно крутиться в нем, уменьшая расстояние.
