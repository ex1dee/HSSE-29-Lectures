Пусть $E_1, E_2$ — линейные пространства. 
Отображение $A: E_1 \to E_2$ называется **линейным оператором** (или гомоморфизмом), если выполнены условия:
 1. Аддитивность: $A(x + y) = A(x) + A(y)$
 2. Однородность: $A(\alpha x) = \alpha A(x)$

Что объединяется в: $A(\alpha x + \beta y) = \alpha A(x) + \beta A(y), \forall \alpha, \beta \in \mathbb{R}, \forall x, y \in E_1$.

> **Примечание**
> Множество всех линейных операторов из $E_1$ в $E_2$ само является линейным пространством относительно операций:
> - $(A + B)(x) := A(x) + B(x)$
> - $(\alpha A)(x) := \alpha \cdot A(x)$

---

Пусть $E_1, E_2$ — линейные нормированные пространства. 
**Нормой линейного оператора** $A: E_1 \to E_2$ называется число:
 $$\|A\| := \sup_{x \neq 0} \frac{\|A(x)\|_{E_2}}{\|x\|_{E_1}}$$
Если $\|A\| < +\infty$, то оператор $A$ называется **ограниченным**.

> **Примечание**
> **Геометрический смысл нормы:** $\|A\|$ показывает «максимальное» искажение (растяжение) длины вектора при данном отображении. 
> 
> Так как $\|A(x)\|/\|x\| = \|A(x/\|x\|)\|$, норму можно считать как супремум на единичной сфере:
> $$\|A\| = \sup_{\|x\|_{E_1} = 1} \|A(x)\|_{E_2}$$



---

 **Ядром линейного оператора** называется множество элементов $E_1$, которые переходят в нуль:
 $$\text{Ker } A = \{x \in E_1 : A(x) = 0_{E_2}\}$$

> **Примечание**
> Ядро всегда является линейным подпространством в $E_1$. Если $\text{Ker } A = E_1$, оператор называется **нулевым** ($A \equiv 0$).

---

> **Критерий нулевого оператора**
> Линейный оператор $A: E_1 \to E_2$ является нулевым $\iff \|A\| = 0$.

_Доказательство:_
- ($\implies$) Если $A \equiv 0$, то $A(x) = 0$ для любого $x$, следовательно, супремум норм также равен 0.
- ($\impliedby$) Если $\|A\| = 0$, то из неравенства $\|A(x)\| \le \|A\| \cdot \|x\|$ следует, что $\|A(x)\| \le 0 \cdot \|x\| = 0$. Значит, $A(x) = 0$ для всех $x$, т.е. $\text{Ker } A = E_1$.

---

> **Лемма (Основное неравенство для оператора)**
> Для любого ограниченного оператора $A \in \mathcal{L}(E_1, E_2)$ и любого $x \in E_1$ справедливо:
> $$\|A(x)\|_{E_2} \le \|A\| \cdot \|x\|_{E_1}$$

_Доказательство:_
Для $x=0$ верно $0 \le 0$. Для $x \neq 0$, по определению супремума:
$\frac{\|A(x)\|}{\|x\|} \le \sup_{z \neq 0} \frac{\|A(z)\|}{\|z\|} = \|A\|$. Умножая на $\|x\|$, получаем искомое.

> **Теорема**
> Множество всех ограниченных линейных операторов $\mathcal{L}(E_1, E_2)$ является линейным нормированным пространством.

_Доказательство:_
1. Свойство нормы $\|A\| = 0 \iff A = 0$ доказано выше.
2. Однородность: $\|\alpha A\| = \sup \frac{\|\alpha A(x)\|}{\|x\|} = |\alpha| \sup \frac{\|A(x)\|}{\|x\|} = |\alpha| \cdot \|A\|$.
3. Неравенство треугольника:
$$\|A+B\| = \sup \frac{\|A(x) + B(x)\|}{\|x\|} \le \sup \frac{\|A(x)\| + \|B(x)\|}{\|x\|} \le \sup \frac{\|A(x)\|}{\|x\|} + \sup \frac{\|B(x)\|}{\|x\|} = \|A\| + \|B\|$$
