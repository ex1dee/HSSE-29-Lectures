## Files

+GET    /api/files/list               # Получить список файлов
- **X-Auth-Token**

*Параметры:*
- **includeDirectories** (опционально)
- **directory** (опционально)

*В недалеком будущем:*
- Пагинация

___

+GET    /api/files?path={filePath}      # Скачать файл (chunked)
- **X-Download-Mode:** chunked
- **X-Auth-Token**

___

+GET    /api/files?path={filePath}      # Скачать файл
- **X-Auth-Token**

___

+POST   /api/files/upload?path={filePath}        # Загрузить файл (chunked)
- **Transfer-Encoding**: chunked
- **X-Auth-Token**
- **X-File-Tags**

___

+POST   /api/files/upload?path={filePath}        # Загрузить файл
- **X-Auth-Token**
- **X-File-Tags**

___

DELETE /api/files?path={filePath}      # Удалить файл (пока только HARD)
- **X-Auth-Token**

___

+PUT    /api/files?path={filePath}      # Обновить метаданные файла
- **X-Auth-Token**
- **X-File-New-Path** (опционально)
- **X-File-Visibility** (опционально)
- **X-File-Tags** (опционально)

___

+GET    /api/files/info?path={filePath} # Получить метаданные файла
- **X-Auth-Token**

## Directories

+PUT   /api/directories?path={directoryPath}              # Создать папку
- **X-Auth-Token**

___

+POST    /api/directories?from={source}}&to={dest}  # Переместить папку
- **X-Auth-Token**

___

+DELETE /api/directories?path={directoryPath}   # Удалить папку
- **X-Auth-Token**
