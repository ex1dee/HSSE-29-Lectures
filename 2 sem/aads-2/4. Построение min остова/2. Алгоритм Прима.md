**Цель:** Построение MST в связном неориентированном графе.

___
### Основная концепция

Алгоритм последовательно наращивает подграф $T$, на каждом шаге добавляя к нему одну вершину $v \notin T$, соединенную с $T$ ребром с минимально возможным весом. Это прямое применение **леммы о безопасном ребре**.

___

### Реализация на массивах ($O(V²)$)

Данный подход эффективен для плотных графов

- **`dist[v]`**: Хранит вес минимального ребра, соединяющего вершину $v$ с растущим деревом $T$.
    
- **`parent[v]`**: Хранит предка вершины $v$ (откуда пришло минимальное ребро).
    
- **`visited[v]`**: Входит ли вершина в $T$.
    

#### Алгоритм:

1. Инициализировать все $d[v] = \infty$, $d[start] = 0$.
    
2. Найти вершину $v \notin T$ с минимальным значением $d[v]$.
    
3. Добавить $v$ в $T$ (`visited[v] = True`).
    
4. Для всех соседей $w$ вершины $v$, если $w \notin T$ и $weight(v, w) < d[w]$:
    
    - Обновить $d[w] = weight(v, w)$.
        
    - Обновить `parent[w] = v`.
        
5. Повторить $n-1$ раз.
    
### Код


```java
public static void primN2(int[][] graph, int n) {
	...

	dist[0] = 0; // Начинаем с 0-й вершины

	for (int k = 0; k < n; k++) {
		// 1. Поиск ближайшей вершины из не посещенных
		int u = -1;
		for (int i = 0; i < n; i++) {
			if (!visited[i] && (u == -1 || dist[i] < dist[u])) {
				u = i;
			}
		}

		visited[u] = true;

		// 2. Релаксация ребер, исходящих из u
		for (int v = 0; i < n; v++) {
			int weight = graph[u][v];
			if (weight > 0 && weight < dist[v] && !visited[v]) {
				dist[v] = weight;
				parent[v] = u;
			}
		}
	}
}
```

2. **Фибоначчиева куча**: $O(E + V \log V)$
