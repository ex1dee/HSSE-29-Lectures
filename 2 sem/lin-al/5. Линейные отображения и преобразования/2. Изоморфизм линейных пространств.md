**Изоморфизм линейных пространств** — взаимно однозначное линейное отображение из $L$ в $L'$. Пространства $L$ и $L'$ называются **изоморфными**, если существует изоморфизм $\phi : L \to L'$.
   

---

> **Теорема** (**об изоморфизме линейных пространств**)
> 
> $L \cong L' \iff \dim L = \dim L'$

_Доказательство:_

$(\Rightarrow)$ Свойства биективного линейного отображения гарантируют сохранение размерности (инъективность дает $\dim \text{Ker } \phi = 0$, сюръективность дает $\text{Im } \phi = L'$, по формуле $\dim L = 0 + \dim L'$).

$(\Leftarrow)$ Пусть $\dim L = \dim L' = n$. Выберем в пространствах произвольные базисы. Тогда каждому вектору $x \in L$ можно сопоставить вектор его координат в $\mathbb{R}^n$, а затем по этим координатам восстановить вектор в $L'$. Это и есть **координатный изоморфизм**. 

Если рассматривать через матрицы: любое линейное отображение $\phi: L \to L'$ записывается как $y = Ax$, где $x$ и $y$ — столбцы координат.

- **Линейность:** Обеспечивается свойствами умножения матрицы на вектор: $A(\alpha x + \beta z) = \alpha Ax + \beta Az$.
    
- **Инъективность:** Если $\det A \neq 0$, то уравнение $Ax = 0$ имеет только тривиальное решение $x = 0$. Значит, $\text{Ker } \phi = \{0\}$.
    
- **Сюръективность:** Если $\det A \neq 0$, то ранг матрицы $A$ максимален ($n$). Значит, размерность образа $\dim \text{Im } \phi = n$. Поскольку $\dim L' = n$, образ совпадает со всем пространством $L'$.


---

> **Теорема** 
> 
> Пусть $\phi : L \to L'$, в пространствах заданы старые базисы $e, f$ и новые $e', f'$. Пусть $S$ — матрица перехода от $e$ к $e'$, а $F$ — от $f$ к $f'$. Если $A$ — матрица в старых базисах, а $A'$ — в новых, то:
> 
> $$A' = F^{-1}AS$$

_Доказательство:_

Связь координат: $x = Sx'$ и $y = Fy'$.

Подставим в уравнение отображения $y = Ax$: $Fy' = A(Sx') \implies y' = F^{-1}ASx'$.

С другой стороны, по определению матрицы $A'$ имеем $y' = A'x'$. Отсюда $A' = F^{-1}AS$.

> **Следствие**
> 
> Для преобразования ($L = L'$) при смене базиса (где $S = F$):
> 
> $$A' = S^{-1}AS$$

---

> **Утверждение** (**о каноническом виде матрицы отображения**)
> 
> Если $\text{rg } \phi = r$, то существуют такие базисы $e$ и $f$, в которых матрица отображения имеет вид:
> 
> $$A_\phi = \begin{pmatrix} E_r & | & 0 \\ \hline 0 & | & 0 \end{pmatrix}$$

_Доказательство:_

Пусть $\dim L = n$ и $\text{rg } \phi = r$ (размерность образа).

1. **Базис ядра**
    
    Мы знаем, что $\dim \text{Ker } \phi = n - r$. Выберем в ядре произвольный базис: $\{e_{r+1}, \dots, e_n\}$. По определению ядра:
    
    $$\phi(e_{r+1}) = \dots = \phi(e_n) = 0$$
    
2. **Дополнение до базиса $L$**
    
    Дополним этот набор до базиса всего пространства $L$ векторами $\{e_1, \dots, e_r\}$. Теперь наш базис в $L$ выглядит так:
    
    $$e = \{\underbrace{e_1, \dots, e_r}_{\text{вне ядра}}, \underbrace{e_{r+1}, \dots, e_n}_{\text{в ядре}}\}$$
    
3. **Образы векторов вне ядра**
    
    Рассмотрим векторы $f_1 = \phi(e_1), \dots, f_r = \phi(e_r)$. Докажем, что они **линейно независимы** в $L'$:
    
    - Если $\sum_{i=1}^r \lambda_i \phi(e_i) = 0$, то $\phi(\sum_{i=1}^r \lambda_i e_i) = 0$.
        
    - Значит, вектор $v = \sum_{i=1}^r \lambda_i e_i$ лежит в ядре.
        
    - Но $v$ выражен только через векторы $e_1, \dots, e_r$, которые по построению не входят в ядро (линейно независимы с базисом ядра).
        
    - Единственный вектор, который одновременно лежит в линейной оболочке $\langle  e_1, \dots, e_r\rangle$ и в $\text{Ker } \phi$ — это нулевой вектор. Значит, все $\lambda_i = 0$.
        
4. **Базис в $L'$**
    
    Так как $\{f_1, \dots, f_r\}$ линейно независимы, мы можем дополнить их до базиса всего пространства $L'$ векторами $f_{r+1}, \dots, f_m$.

В выбранных базисах $e = \{e_1, \dots, e_n\}$ и $f = \{f_1, \dots, f_m\}$ найдем координаты образов векторов базиса $L$:

1. Для векторов **вне ядра** ($i = 1, \dots, r$):
    
    $\phi(e_1) = f_1$, его координаты в базисе $f$: $(1, 0, \dots, 0)^T$
    $\phi(e_2) = f_2$, его координаты в базисе $f$: $(0, 1, \dots, 0)^T$
    ...
    $\phi(e_r) = f_r$, его координаты в базисе $f$: $(0, 0, \dots, 1)^T$
1. Для векторов **ядра** ($i = r+1, \dots, n$):
    
    $\phi(e_{r+1}) = 0$, его координаты: $(0, \dots, 0)^T$
    ...
    $\phi(e_n) = 0$, его координаты: $(0, \dots, 0)^T$

Записывая эти столбцы координат в матрицу, получаем искомый вид

---

- **Пространство линейных отображений** — на множестве всех отображений из $L$ в $L'$ вводятся операции:
    
    - $(A + B)(x) := A(x) + B(x)$
        
    - $(\alpha A)(x) := \alpha A(x)$
        
- **Композиция отображений ($BA$)** — последовательное применение отображений
    
    - **Свойство ранга композиции:** $\text{rg}(BA) \le \text{rg } A$ и $\text{rg}(BA) \le \text{rg } B$.
        

---

**Примечание**

Ранг отображения никогда не превосходит размерности как исходного, так и целевого пространства.
