> [!INFO] **Теорема** (О разложении основных элементарных функций)
> 
> Функции $e^x, \cos x, \sin x, \text{ch } x, \text{sh } x$ представимы своим рядом Тейлора с центром в нуле (рядом Маклорена) на всей $\mathbb{R}$, то есть:
> 
> - $e^x = \sum_{k=0}^{\infty} \frac{x^k}{k!} \quad \forall x \in \mathbb{R}$
>     
> - $\text{ch } x = \sum_{k=0}^{\infty} \frac{x^{2k}}{(2k)!} \quad \forall x \in \mathbb{R}$
>     
> - $\text{sh } x = \sum_{k=0}^{\infty} \frac{x^{2k+1}}{(2k + 1)!} \quad \forall x \in \mathbb{R}$
>     
> - $\sin x = \sum_{k=0}^{\infty} \frac{(-1)^k x^{2k+1}}{(2k + 1)!} \quad \forall x \in \mathbb{R}$
>     
> - $\cos x = \sum_{k=0}^{\infty} \frac{(-1)^k x^{2k}}{(2k)!} \quad \forall x \in \mathbb{R}$
>     

**Доказательство:**

Фиксируем произвольный $\delta > 0$. Рассмотрим случай для $f(x) = e^x$:

1. $f^{(k)}(x) = e^x$ для любого $k \in \mathbb{N}$.
    
2. На интервале $(-\delta, \delta)$ производные ограничены: $\exists M(\delta) = e^\delta > 0$ такое, что $\forall x \in (-\delta, \delta) \implies |f^{(k)}(x)| \le e^\delta$.
    

В силу достаточного условия регулярности, ряд Тейлора $e^x$ сходится к $e^x$ для любого $x \in (-\delta, \delta)$. Так как $\delta$ было выбрано произвольно, утверждение верно для всей числовой прямой $\mathbb{R}$.

Аналогичные рассуждения применимы к остальным функциям:

- Для $\sin x$ и $\cos x$ производные по модулю не превосходят $M = 1$.
    
- Для $\text{sh } x$ и $\text{ch } x$ производные также ограничиваются экспонентой от $\delta$ на любом симметричном интервале.

> [!NOTE] **Напоминание**
> 
> $e^z := e^x(\cos y + i \sin y)$, если $z = x + iy$. Это определение связывает вещественную экспоненту и тригонометрические функции.

> [!INFO] **Теорема** (О комплексной экспоненте)
> 
> Для любого комплексного числа $z \in \mathbb{C}$ справедливо разложение в степенной ряд:
> 
> $$e^z = \sum_{k=0}^{\infty} \frac{z^k}{k!}$$

**Доказательство:**

Обозначим сумму ряда за $f(z) = \sum_{k=0}^{\infty} \frac{z^k}{k!}$.

**1. Область сходимости:**

Мы знаем, что при $z = x \in \mathbb{R}$ ряд $\sum \frac{x^k}{k!}$ сходится к $e^x$. Поскольку степенной ряд, сходящийся на всей вещественной оси, обязан иметь радиус сходимости $R_{\text{сх}} = +\infty$, данный ряд сходится абсолютно для любого $z \in \mathbb{C}$.

**2. Функциональное уравнение:**

Покажем, что $f(z_1 + z_2) = f(z_1)f(z_2)$. Воспользуемся теоремой о произведении абсолютно сходящихся рядов (произведение по Коши):

$$f(z_1)f(z_2) = \left( \sum_{k=0}^{\infty} \frac{z_1^k}{k!} \right) \cdot \left( \sum_{m=0}^{\infty} \frac{z_2^m}{m!} \right) = \sum_{s=0}^{\infty} \sum_{k=0}^{s} \frac{z_1^k}{k!} \frac{z_2^{s-k}}{(s-k)!}$$

Умножим и разделим внутреннюю сумму на $s!$:

$$f(z_1)f(z_2) = \sum_{s=0}^{\infty} \frac{1}{s!} \sum_{k=0}^{s} \frac{s!}{k!(s-k)!} z_1^k z_2^{s-k} = \sum_{s=0}^{\infty} \frac{1}{s!} \sum_{k=0}^{s} C_s^k z_1^k z_2^{s-k}$$

По формуле бинома Ньютона внутренняя сумма равна $(z_1 + z_2)^s$, следовательно:

$$f(z_1)f(z_2) = \sum_{s=0}^{\infty} \frac{(z_1 + z_2)^s}{s!} = f(z_1 + z_2)$$

**3. Анализ мнимого аргумента:**

Рассмотрим $f(iy)$ для $y \in \mathbb{R}$:

$$f(iy) = \sum_{k=0}^{\infty} \frac{(iy)^k}{k!} = \sum_{k=0, 2, 4 \dots}^{\infty} \frac{i^k y^k}{k!} + \sum_{k=1, 3, 5 \dots}^{\infty} \frac{i^k y^k}{k!}$$

Учитывая, что $i^{2k} = (-1)^k$ и $i^{2k+1} = i(-1)^k$:

$$f(iy) = \sum_{k=0}^{\infty} \frac{(-1)^k y^{2k}}{(2k)!} + i \sum_{k=0}^{\infty} \frac{(-1)^k y^{2k+1}}{(2k+1)!} = \cos y + i \sin y$$

**4. Итоговая сборка:**

Для любого $z = x + iy$:

$$f(z) = f(x + iy) = f(x)f(iy)$$

Так как $f(x) = e^x$ (вещественный случай) и $f(iy) = \cos y + i \sin y$, получаем:

$$f(z) = e^x(\cos y + i \sin y) = e^z$$

Что и требовалось доказать.

___

- **Определения через степенные ряды:**
    
    - $\text{ch } z := \sum_{k=0}^{\infty} \frac{z^{2k}}{(2k)!} \quad \forall z \in \mathbb{C}$
        
    - $\text{sh } z := \sum_{k=0}^{\infty} \frac{z^{2k+1}}{(2k + 1)!} \quad \forall z \in \mathbb{C}$
        
    - $\sin z := \sum_{k=0}^{\infty} \frac{(-1)^k z^{2k+1}}{(2k + 1)!} \quad \forall z \in \mathbb{C}$
        
    - $\cos z := \sum_{k=0}^{\infty} \frac{(-1)^k z^{2k}}{(2k)!} \quad \forall z \in \mathbb{C}$
        

> [!NOTE] **Примечание**
> 
> Данное определение корректно, так как для всех указанных рядов $R_{\text{сх}} = +\infty$. Доказательство аналогично случаю с комплексной экспонентой.

> [!INFO] **Следствие** (Формулы Эйлера)
> 
> Для любого $z \in \mathbb{C}$ справедливы равенства:
> 
> 1. $e^{iz} = \cos z + i \sin z$
>     
> 2. $\cos z = \frac{e^{iz} + e^{-iz}}{2}$
>     
> 3. $\sin z = \frac{e^{iz} - e^{-iz}}{2i}$
>     

**Доказательство:**

Докажем первую формулу. Согласно теореме о комплексной экспоненте:

$$e^{iz} = \sum_{k=0}^{\infty} \frac{(iz)^k}{k!} \quad \forall z \in \mathbb{C}$$

Разобьём сумму на части по чётным и нечётным индексам $k$:

$$e^{iz} = \sum_{k=0, 2, \dots}^{\infty} \frac{(iz)^k}{k!} + \sum_{k=1, 3, \dots}^{\infty} \frac{(iz)^k}{k!}$$

Учитывая свойства мнимой единицы ($i^{2k} = (-1)^k$ и $i^{2k+1} = i(-1)^k$):

$$e^{iz} = \sum_{k=0}^{\infty} \frac{(-1)^k z^{2k}}{(2k)!} + i \sum_{k=0}^{\infty} \frac{(-1)^k z^{2k+1}}{(2k+1)!}$$

По определению выше, первая сумма — это $\cos z$, а вторая — $\sin z$. Следовательно:

$$e^{iz} = \cos z + i \sin z$$

Остальные формулы получаются из системы:

$\begin{cases} e^{iz} = \cos z + i \sin z \\ e^{-iz} = \cos z - i \sin z \end{cases}$

Складывая и вычитая эти уравнения, выражаем $\cos z$ и $\sin z$.

> [!INFO] **Теорема** (Формула Тейлора с остаточным членом в интегральной форме)
> 
> Пусть $x_0 \in \mathbb{R}, \delta > 0$. Пусть $f \in C^{n+1}((x_0 - \delta, x_0 + \delta))$. Тогда для любого $x \in (x_0 - \delta, x_0 + \delta)$ справедливо:
> 
> $$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + \frac{1}{n!} \int_{x_0}^{x} (x - t)^n f^{(n+1)}(t) dt$$

**Доказательство:**

Проведем доказательство методом математической индукции по $n$.

**База индукции ($n = 0$):**

По определению $T_0^{x_0}[f](x) = f(x_0)$. Тогда формула принимает вид:

$$f(x) - f(x_0) = \int_{x_0}^{x} f'(t) dt$$

Это в точности формула Ньютона-Лейбница, которая верна для $f \in C^1$.

**Индукционный переход:**

Пусть формула верна при $n = s$. Покажем её справедливость для $n = s + 1$:

$$f(x) = \sum_{k=0}^{s} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + R_s(x), \quad \text{где } R_s(x) = \frac{1}{s!} \int_{x_0}^{x} (x - t)^s f^{(s+1)}(t) dt$$

Преобразуем интеграл в остаточном члене $R_s(x)$, используя интегрирование по частям:

$\int_{x_0}^{x} U d V = UV \big|_{x_0}^{x} - \int_{x_0}^{x} V d U$, где:

- $U = f^{(s+1)}(t) \implies dU = f^{(s+2)}(t) dt$
    
- $dV = (x - t)^s dt \implies V = -\frac{(x - t)^{s+1}}{s+1}$
    

Получаем:

$$\int_{x_0}^{x} (x - t)^s f^{(s+1)}(t) dt = \left[ -f^{(s+1)}(t) \frac{(x - t)^{s+1}}{s+1} \right]_{x_0}^{x} + \int_{x_0}^{x} \frac{(x - t)^{s+1}}{s+1} f^{(s+2)}(t) dt =$$

$$= \left( 0 - \left( -f^{(s+1)}(x_0) \frac{(x - x_0)^{s+1}}{s+1} \right) \right) + \int_{x_0}^{x} \frac{(x - t)^{s+1}}{s+1} f^{(s+2)}(t) dt =$$

$$= \frac{f^{(s+1)}(x_0)}{s+1} (x - x_0)^{s+1} + \int_{x_0}^{x} \frac{(x - t)^{s+1}}{s+1} f^{(s+2)}(t) dt$$

Подставим это выражение обратно в $f(x)$, учитывая коэффициент $\frac{1}{s!}$:

$$f(x) = \sum_{k=0}^{s} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + \frac{f^{(s+1)}(x_0)}{(s+1)s!} (x - x_0)^{s+1} + \frac{1}{(s+1)s!} \int_{x_0}^{x} (x - t)^{s+1} f^{(s+2)}(t) dt$$

$$f(x) = \sum_{k=0}^{s+1} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + \frac{1}{(s+1)!} \int_{x_0}^{x} (x - t)^{s+1} f^{(s+2)}(t) dt$$

Индукционный шаг доказан.

> [!INFO] **Теорема**
> 
> Для любого $\alpha \in \mathbb{R}$ выполняется следующее разложение в ряд при всех $x \in (-1, 1)$:
> 
> $$(1+x)^\alpha = \sum_{k=0}^{\infty} C_k^\alpha x^k$$

**Доказательство:**

Если $\alpha \in \mathbb{N} \cup \{0\}$, то формула вырождается в бином Ньютона (ряд Тейлора становится конечной суммой, так как коэффициенты при $k > \alpha$ равны $0$).

Далее считаем, что $\alpha \notin \mathbb{N} \cup \{0\}$. Известно, что для функции $f(x) = (1 + x)^\alpha$ коэффициенты ряда Тейлора имеют вид:

$$\frac{f^{(k)}(0)}{k!} = C_k^\alpha = \frac{\alpha \cdot (\alpha - 1) \cdot \dots \cdot (\alpha - k + 1)}{k!}$$

Покажем, что остаточный член стремится к нулю:

$$(1 + x)^\alpha - \sum_{k=0}^{n} C_k^\alpha x^k \to 0, \quad n \to \infty, \quad \forall x \in (-1, 1)$$

Воспользуемся формулой Тейлора с остаточным членом в интегральной форме:

$$(1 + x)^\alpha - \sum_{k=0}^{n} C_k^\alpha x^k = \frac{1}{n!} \int_{0}^{x} (x - t)^n f^{(n+1)}(t) \, dt$$

где $f^{(n+1)}(t) = \alpha(\alpha - 1) \cdot \dots \cdot (\alpha - n) \cdot (1 + t)^{\alpha-n-1}$.

Обозначим $\lambda_n = \frac{\alpha(\alpha - 1) \cdot \dots \cdot (\alpha - n)}{n!}$. После замены $t = \tau x$ выражение принимает вид:

$$\lambda_n x^{n+1} \int_{0}^{1} (1 - \tau)^n (1 + \tau x)^{\alpha-n-1} \, d\tau = \lambda_n x^{n+1} \int_{0}^{1} \left( \frac{1 - \tau}{1 + \tau x} \right)^n (1 + \tau x)^{\alpha-1} \, d\tau$$

Так как для $x \in (-1, 1)$ выполняется $0 \le \frac{1 - \tau}{1 + \tau x} \le 1$, интеграл по модулю оценивается как:

$$\left| \lambda_n x^{n+1} \right| \cdot \int_{0}^{1} (1 + \tau x)^{\alpha-1} \, d\tau \le \lambda_n |x|^{n+1} \cdot C$$

где $C$ — константа, не зависящая от $n$.

Исследуем поведение $\lambda_n |x|^{n+1}$ через признак Даламбера:

$$\lim_{n \to \infty} \left| \frac{\lambda_{n+1} x^{n+2}}{\lambda_n x^{n+1}} \right| = \lim_{n \to \infty} \left| x \cdot \frac{\alpha - n - 1}{n + 1} \right| = |x| < 1$$

Так как предел отношения меньше 1, то $\lambda_n |x|^{n+1} \to 0$ при $n \to \infty$, что и доказывает сходимость ряда к функции.

# Ряды для логарифма и обратных тригонометрических функций

> [!NOTE] **Замечание** (Радиус сходимости биномиального ряда)
> 
> Радиус сходимости ряда $\sum_{k=0}^{\infty} C_k^\alpha x^k$ равен $1$.

**Доказательство:**

Воспользуемся формулой связи радиуса сходимости с пределом отношения коэффициентов для $z^k$ ($m=1, n=0$):

$$\lim_{k \to \infty} \left| \frac{C_{k+1}^\alpha}{C_k^\alpha} \right| = \left| \frac{\alpha \cdot \dots \cdot (\alpha - k)}{(k + 1)!} \cdot \frac{k!}{\alpha \cdot \dots \cdot (\alpha - k + 1)} \right| = \left| \frac{\alpha - k}{k + 1} \right| \to 1, \quad k \to \infty$$

Следовательно, $R_{\text{сх}} = 1^{-1} = 1$.

> [!NOTE] **Замечание**
> 
> $(1 + x)^{-1} = \sum_{k=0}^{\infty} (-1)^k x^k, \quad \forall x \in (-1, 1)$

> [!Следствие] **Следствие** (Разложение логарифма)
> 
> По теореме о почленном интегрировании вещественного степенного ряда:
> 
> $$\ln(1 + x) = \sum_{k=0}^{\infty} \frac{(-1)^k x^{k+1}}{k + 1} \quad \forall x \in (-1, 1)$$
> 
> После переобозначения индексов:
> 
> $$\ln(1 + x) = \sum_{k=1}^{\infty} \frac{(-1)^{k-1} x^k}{k}$$

> [!INFO] **Лемма** (О значении ряда в граничной точке)
> 
> $$\ln 2 = \sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k}$$

**Доказательство:**

Заметим, что правая часть сходится по признаку Лейбница. Следовательно, степенной ряд $\sum_{k=1}^{\infty} \frac{(-1)^{k-1} x^k}{k}$ сходится в точке $x = 1$.

По второй теореме Абеля это влечет равномерную сходимость ряда на отрезке $[0, 1]$. Поскольку на интервале $(0, 1)$ ряд сходится к $\ln(1 + x)$, а сама функция $\ln(1 + x)$ непрерывна на $[0, 1]$, мы можем совершить предельный переход.

В силу непрерывности суммы равномерно сходящегося ряда:

$$\ln 2 = \lim_{x \to 1} \ln(1 + x) = \lim_{x \to 1} \sum_{k=1}^{\infty} \frac{(-1)^{k-1} x^k}{k} = \left( \sum_{k=1}^{\infty} \frac{(-1)^{k-1} x^k}{k} \right) \bigg|_{x=1} = \sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k}$$

> [!INFO] **Лемма** (Разложение арктангенса)
> 
> $$\text{arctg } t = \sum_{k=0}^{\infty} \frac{(-1)^k t^{2k+1}}{2k + 1} \quad \forall t \in (-1, 1)$$

**Доказательство:**

Используя разложение геометрической прогрессии для производной:

$$(1 + t^2)^{-1} = \sum_{k=0}^{\infty} (-1)^k t^{2k}$$

Интегрируя почленно, получаем:

$$\text{arctg } t = \sum_{k=0}^{\infty} \frac{(-1)^k t^{2k+1}}{2k + 1} \quad \forall t \in (-1, 1)$$

> [!INFO] **Лемма** (Разложение арксинуса)
> 
> $$\arcsin t = \sum_{k=0}^{\infty} \frac{t^{2k+1}(2k - 1)!!}{2^k k! (2k + 1)} \quad \forall t \in (-1, 1)$$

**Доказательство:**

Рассмотрим биномиальное разложение для $(1 + t)^{-1/2}$:

$$(1 + t)^{-1/2} = \sum_{k=0}^{\infty} \frac{(-\frac{1}{2}) \cdot \dots \cdot (-\frac{1}{2} - k + 1) t^k}{k!} = \sum_{k=0}^{\infty} \frac{(-1)^k (2k - 1)!! t^k}{2^k k!}$$

(По определению считается, что $(-1)!! = 1$).

Для вычисления $\arcsin t$ необходимо подставить $-t^2$ в разложение и проинтегрировать (либо использовать разложение для $(1 - t^2)^{-1/2}$):

$$\arcsin t = \sum_{k=0}^{\infty} \frac{t^{2k+1}(2k - 1)!!}{2^k k! (2k + 1)} \quad \forall t \in (-1, 1)$$
