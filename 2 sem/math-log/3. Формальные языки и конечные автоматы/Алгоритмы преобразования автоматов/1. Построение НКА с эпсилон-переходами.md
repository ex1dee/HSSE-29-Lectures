Позволяет рекурсивно собрать НКА для любого регулярного выражения.

**Базовые элементы:**

- **Символ $a$:**

```mermaid
graph LR
    s1((start)) -- a --> f1(((finish)))
```

- **Пустое слово $\varepsilon$:**
    

```mermaid
graph LR
    s1((start)) -- ε --> f1(((finish)))
```

**Операции:**

- **Конкатенация $AB$:**
    

```mermaid
graph LR
    direction LR
    subgraph A
    sA(( )) -- ... --> fA(( ))
    end
    subgraph B
    sB(( )) -- ... --> fB(( ))
    end
    Start[ ] --> sA
    fA -- ε --> sB
    fB --> Finish[ ]
    style Start fill:none,stroke:none
    style Finish fill:none,stroke:none
    style fA db:dashed
    style sB db:dashed
```

_(Финиш А соединяется со стартом В)_

- **Объединение $A + B$:**

```mermaid
graph LR
    direction LR
    subgraph A
    sA(( )) -- ... --> fA(( ))
    end
    subgraph B
    sB(( )) -- ... --> fB(( ))
    end
    S((start)) -- ε --> sA
    S -- ε --> sB
    fA -- ε --> F(((finish)))
    fB -- ε --> F
```

- **Итерация $A^*$ (Звезда Клини):**

```mermaid
graph LR
    direction LR
    subgraph A
    sA(( )) -- ... --> fA(( ))
    end
    S((start)) -- ε --> sA
    S -- ε --> F(((finish)))
    fA -- ε --> sA
    fA -- ε --> F
```
___

### **Пример**
$$a (a + b)^*$$

#### Шаг 1: Базис для символов $a$ и $b$

Сначала создаем простейшие автоматы для каждой буквы.

```mermaid
graph LR
    subgraph block_b
    direction LR
    s2((3)) -- b --> f2((4))
    end
    subgraph block_a
    direction LR
    s1((1)) -- a --> f1((2))
    end
```

#### Шаг 2: Объединение $(a+b)$

Соединяем блоки $a$ и $b$ через $\varepsilon$-переходы, добавляя новые старт и финиш.

```mermaid
graph LR
    direction LR
    subgraph union_ab
    S_u((5)) -- ε --> s1((1))
    S_u -- ε --> s2((3))
    s1 -- a --> f1((2))
    s2 -- b --> f2((4))
    f1 -- ε --> F_u((6))
    f2 -- ε --> F_u
    end
```

#### Шаг 3: Итерация $(a+b)^*$ (Звезда Клини)

Оборачиваем полученный блок объединения по схеме итерации. Добавляем петлю возврата ($\varepsilon$) и обходной путь ($\varepsilon$).

```mermaid
graph LR
    direction LR
    subgraph star_ab
    S_s((7)) -- ε --> S_u((5))
    S_s -- ε (bypass) --> F_s((8))
    
    subgraph union_ab
    S_u -- ε --> s1((1))
    S_u -- ε --> s2((3))
    s1 -- a --> f1((2))
    s2 -- b --> f2((4))
    f1 -- ε --> F_u((6))
    f2 -- ε --> F_u
    end
    
    F_u -- ε (repeat) --> S_u
    F_u -- ε --> F_s
    end
```

#### Шаг 4: Конкатенация $a \cdot (a+b)^*$ (Итоговый автомат)

Берем еще один базовый блок $a$ и соединяем его $\varepsilon$-переходом со стартом блока $(a|b)^*$. Состояние 8 становится единственным принимающим.

```mermaid
graph LR
    direction LR
    Start[ ] --> s0
    
    s0((0)) -- a --> f0((2))
    f0 -- ε --> S_s((7))
    
    subgraph star_ab
    S_s -- ε --> S_u((5))
    S_s -- ε --> F_s(((8)))
    
    subgraph union_ab
    S_u -- ε --> s1((1))
    S_u -- ε --> s2((3))
    s1 -- a --> f1((3))
    s2 -- b --> f2((4))
    f1 -- ε --> F_u((6))
    f2 -- ε --> F_u
    end
    
    F_u -- ε --> S_u
    F_u -- ε --> F_s
    end
    style Start fill:none,stroke:none
```
