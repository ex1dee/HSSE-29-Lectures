**Сложность алгоритма** — это функция, показывающая, как количество основных операций (время) или объем используемой памяти (пространство) зависит от размера входных данных `n`

### **O (О-большое) — асимптотическая верхняя оценка.**

`f(n) = O(g(n))`, если ∃ `c > 0` и `n₀ > 0`: `0 ≤ f(n) ≤ c·g(n)` для всех `n ≥ n₀`.  

**Смысл:** "Алгоритм работает **не хуже, чем** g(n)".
**Пример**: `2n + 10 = O(n)`, `n² = O(n³)`.
### **Ω (Омега-большое) — асимптотическая нижняя оценка.**

`f(n) = Ω(g(n))`, если ∃ `c > 0` и `n₀ > 0`: `f(n) ≥ c·g(n) ≥ 0` для всех `n ≥ n₀`.

**Смысл:** "Алгоритм работает **не лучше, чем** g(n)". 
**Пример**: `n² = Ω(n)`, `5n log n = Ω(n log n)`.

### **Θ (Тета) — асимптотически точная оценка.**

`f(n) = Θ(g(n))`, если `f(n) = O(g(n))` и `f(n) = Ω(g(n))`.

**Смысл:** "Скорость роста f(n) и g(n) одинакова с точностью до константы". Пример: `½n² - 3n = Θ(n²)`.

### **o (о-малое) — асимптотическая верхняя оценка (строгая)**
`f(n) = o(g(n))`, если для **любого** `c > 0` ∃ `n₀ > 0`: `0 ≤ f(n) < c·g(n)` 
для всех `n ≥ n₀`.

**Эквивалентно**: `lim (n→∞) [f(n) / g(n)] = 0`.
**Смысл:** "Функция `f(n)` растет **сильно медленнее**, чем `g(n)`". 
**Пример:** `n = o(n log n)`, `1000√n = o(n)`. Но `n ≠ o(n)`.
### **ω (омега-малое) — асимптотическая нижняя оценка (строгая)**    
`f(n) = ω(g(n))`, если для **любого** `c > 0` ∃ `n₀ > 0`: `f(n) > c·g(n) ≥ 0` 
для всех `n ≥ n₀`.

**Эквивалентно**: `lim (n→∞) [f(n) / g(n)] = ∞`.
**Смысл:** "Функция `f(n)` растет **сильно быстрее**, чем `g(n)`".
**Пример:** `n² = ω(n)`, `n log n = ω(n)`. Но `n ≠ ω(n)`.

*Примеры сравнений:*
$1 < log n < √n < n < n log n < n² < 2ⁿ < n!$
