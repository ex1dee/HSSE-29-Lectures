Позволяет рекурсивно собрать НКА для любого регулярного выражения.

**Базовые элементы:**

- **Символ $a$:**

```mermaid
graph LR
    s1((start)) -- a --> f1(((finish)))
```

- **Пустое слово $\varepsilon$:**
    

```mermaid
graph LR
    s1((start)) -- ε --> f1(((finish)))
```

**Операции:**

- **Конкатенация $AB$:**
    

```mermaid
graph LR
    direction LR
    subgraph A
    sA(( )) -- ... --> fA(( ))
    end
    subgraph B
    sB(( )) -- ... --> fB(( ))
    end
    Start[ ] --> sA
    fA -- ε --> sB
    fB --> Finish[ ]
    style Start fill:none,stroke:none
    style Finish fill:none,stroke:none
    style fA db:dashed
    style sB db:dashed
```

_(Финиш А соединяется со стартом В)_

- **Объединение $A + B$:**

```mermaid
graph LR
    direction LR
    subgraph A
    sA(( )) -- ... --> fA(( ))
    end
    subgraph B
    sB(( )) -- ... --> fB(( ))
    end
    S((start)) -- ε --> sA
    S -- ε --> sB
    fA -- ε --> F(((finish)))
    fB -- ε --> F
```

- **Итерация $A^*$ (Звезда Клини):**

```mermaid
graph LR
    direction LR
    subgraph A
    sA(( )) -- ... --> fA(( ))
    end
    S((start)) -- ε --> sA
    S -- ε --> F(((finish)))
    fA -- ε --> sA
    fA -- ε --> F
```

___

>[!EXAMPLE] **Пример**
>Регулярное выражение: $a(a + b)^*$
> ```mermaid
> graph TD
>     direction LR
>     Start[ ] --> s0
>     
>     s0(( )) -- a --> f0(( ))
>     f0 -- ε --> S_s(( ))
>     
>     subgraph star_ab
>     S_s -- ε --> S_u(( ))
>     S_s -- ε --> F_s((( )))
>     
>     subgraph union_ab
>     S_u -- ε --> s1(( ))
>     S_u -- ε --> s2(( ))
>     s1 -- a --> f1(( ))
>     s2 -- b --> f2(( ))
>     f1 -- ε --> F_u(( ))
>     f2 -- ε --> F_u
>     end
>     
>     F_u -- ε --> S_u
>     F_u -- ε --> F_s
>     end
>     style Start fill:none,stroke:none
> ```
