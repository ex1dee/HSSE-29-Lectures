> **Параметрическое уравнение прямой**
> Задаётся точкой на прямой с радиус-вектором $\bar{r}_{0}$ и направляющим вектором $\bar{a}\neq 0$ 

**Векторная форма**
$\bar{r}=\bar{r}_{0}+t\bar{a}, t\in \mathbb{R}$ 
$\bar{r}$ – радиус вектор произвольной точки на прямой

**Координатная форма**
Пусть $r_{0} = (x_{0}, y_{0}), \bar{a} = (a_{1}, a_{2}), \bar{r} = (x, y)$. Тогда из $\bar{r} = \bar{r}_{0} + t\bar{a}$: 
$x = x_{0} + a_{1} t$
$y = y_{0} + a_{2}t$

___

>**Каноническое уравнение прямой**
>Задаётся уравнением $\frac{x-x_{0}}{a_{1}} = \frac{y-y_{0}}{a_{2}}$

Выводится из координатной формы параметрического уравнения:
$x = x_{0}+a_{1}t \iff t=\frac{x-x_{0}}{a_{1}}$
$y=y_{0}+a_{2}t \iff t=\frac{y-y_{0}}{a_{2}}$

**Важно!** 
Если $a_{1} = 0$ или $a_{2} = 0$ (но не одновременно), 
то возвращаемся к уравнению $(x-x_{0})a_{2} = (y-y_{0})a_{1}$

Тогда либо $x=x_{0}$, либо $y=y_{0}$:
$a_{1}=0\implies$ т.к. $a_{2}\neq 0$, то $x = x_{0}$
$a_{2}=0\implies$ т.к. $a_{1}\neq 0$, то $y = y_{0}$

___

>**Нормальное уравнение прямой**
>Задаётся точкой на прямой с радиус-вектором $\bar{r}_{0}$ и вектором нормали $\bar{n}\neq 0$

$(\bar{r} - \bar{r}_{0}, \bar{n}) = 0 \iff (\bar{r}, \bar{n}) = D, \text{где } D = (\bar{r}_{0}, \bar{n})$ 

> Нормальное и параметрическое уравнения прямой эквивалентны

Возьмём произвольную точку $\bar{r}_{1}$ на прямой.

1. Параметрическое $\implies$ Нормальное
$\bar{r}_{1} = r_{0} + t_{1}\bar{a}$. Подставим $\bar{r}_{1}$ в нормальное уравнение:
$(\bar{r}_{1}, \bar{n}) = (\bar{r}_{0} + t_{1}\bar{a}, \bar{n}) = (\bar{r}_{0}, \bar{n}) + t_{1}(\bar{a}, \bar{n}) = D + 0 = D$ – *верно*
2. Нормальное $\implies$ Параметрическое
Выберем любой ненулевой вектор $\bar{a}\perp \bar{n}$.
$(\bar{r}_{1} - \bar{r}_{0}, \bar{n}) = 0 \implies \bar{r}_{1} - \bar{r}_{0} = t\bar{a} \iff \bar{r}_{1} = \bar{r}_{0} + t\bar{a}$


___

>**Общее уравнение прямой**
>Пусть $\bar{n}(A,B)$. 
>Тогда прямая задаётся уравнением $Ax + By + C = 0$, где $C=-(Ax_{0}+By_{0})$,
>или же $A(x - x_{0}) + B(y - y_{0})$

Выводится из нормального уравнения прямой:
Зададим $\bar{r}(x, y), \bar{r}_{0}(x_{0},y_{0})$

$(\bar{r}-\bar{r}_{0}, \bar{n}) = 0 \iff A(x - x_{0}) + B(y -y_{0}) = 0$
$Ax + By - Ax_{0} - By_{0} = 0$
Обозначим $-Ax_{0}-By_{0}=C$
Тогда $Ax + By + C = 0$

>Одно из частных решений $(\bar{r}, \bar{n}) = D: \frac{D\bar{n}}{|n|^2}$

Пусть $\bar{r}_{0} = \lambda \bar{n} \implies (\lambda \bar{n}, \bar{n}) = D \iff \lambda(\bar{n},\bar{n})=D \iff \lambda=\frac{D}{|n|^2}$
Тогда $\bar{r}_{0} = \frac{Dn}{|n|^2}$
