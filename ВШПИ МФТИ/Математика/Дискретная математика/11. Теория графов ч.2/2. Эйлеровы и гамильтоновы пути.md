**Эйлеров путь/цикл** — путь/цикл, проходящий через каждое **ребро** графа ровно **один раз**
**Эйлеров граф** — граф, содержащий эйлеров **цикл**

**Гамильтонов путь/цикл** — путь/цикл, проходящий через 
каждую **вершину** графа ровно **один раз**
**Гамильтонов граф** — граф, содержащий гамильтонов **цикл**

___

>**Следующие условия эквивалентны**
>1. Граф Эйлеров
>2. $\ \forall v\to deg(v)$ – чётная
>3. Рёбра графа можно разбить на непересекающиеся по рёбрам циклы (можно на один)

*Доказательство:*
**(1) => (2)**
Т.к. все рёбра в эйлерове цикле различны и каждое посещение 
вершины $v$ происходит через входящую и выходящую рёбра,
то они разбиваются на пары $\implies$ $deg (v)$ – чётно

**(2) => (3)**
1. Начнём с вершины $v_{0}$. Из неё будем идти по ещё неиспользованным
рёбрам, пока не дойдём обратно до $v_{0}$. 
Так мы посетим чётное количество рёбер и получим цикл. 
2. Удалим все вершины и рёбра цикла. 
В полученном графе все вершины останутся чётной степени
3. Повторим 1 шаг

**(3) => (1)**

**База:**
Для $k=1$ граф сам является циклом, который и является эйлеровым

**Шаг:**
Пусть утверждение верно для разбиений с числом циклов $< k$.

Рассмотрим разбиение на $k$ циклов: $C_{1}, C_{2}, \dots, C_{k}$.
Среди них найдутся хотя бы два, имеющие общую вершину (иначе граф несвязный).
Пусть циклы $C_{1}$ и $C_{2}$ пересекаются по вершине $v$.

Объединим $C_{1}$ и $C_{2}$ в один цикл $C'$ так: 
Начнём обход в вершине $v$, пройдём весь цикл $C_{1}$,
вернувшись в $v$, а затем пройдём весь цикл $C_{2}$, вернувшись в $v$.

Теперь рёбра графа $G$ разбиты на $k - 1$ цикл: $C', C_{3}, \dots, C_{k}$,
а для такого разбиения, по предположению индукции, существует эйлеров цикл, ч.т.д.

___

>**Теорема**
>В любом графе можно найти маршрут, проходящий по каждому ребру два раза

*Доказательство:*
1. Удвоим каждое ребро графа (заменим его двумя паралелльными рёбрами) 
2. В полученном мультиграфе все вершины имеют чётную степень
3. Тогда существует и эйлеров цикл, проходящий по всем рёбрам
4. Но в исходном графе ребро и его копия, по которым цикл проходит, являются одним ребром, это даёт прохождение по каждому ребру два раза.
