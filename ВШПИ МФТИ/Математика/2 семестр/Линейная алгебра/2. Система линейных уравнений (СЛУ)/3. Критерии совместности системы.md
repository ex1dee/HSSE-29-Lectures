>**Теорема Кронекера-Капелли** 
>Система совместна $\iff rg (A | B) = rgA$
>*Аналогична рассмотренной [[2. Ранг и линейная зависимость|здесь]]*

___

>**Теорема**
>Система несовместна $\iff$ после приведения расширенной матрицы к упрощенному виду есть строка вида $\begin{pmatrix}0 & 0 & \dots & 0 & 1\end{pmatrix}$

*Доказательство:*
**(=>)** По теореме Кронекера-Капелли $rg(A) < rg(A|b)$. Это возможно только в том случае, если при приведении к упрощенному виду в расширенной матрице «ступенька» (базисный элемент) в какой-то строке попала в столбец $b$, в то время как в основной матрице $A$ в этой строке стоят одни нули. Так и получается строка $(0 \dots 0 | 1)$.

**(<=)** Пусть в упрощенной матрице есть строка $(0 \dots 0 | 1)$. Переведем её обратно на язык уравнений:

$$0\cdot x_1 + 0\cdot x_2 + \dots + 0\cdot x_n = 1 \implies 0 = 1$$

Полученное противоречие означает, что ни один набор $x_i$ не может удовлетворить этому уравнению $\implies$ система несовместна

$A^Ty= 0$ (или $y^TA = 0$) — **сопряженная однородная система** к $Ax = b$

>**Теорема Фредгольма**
>Система $Ax = b$ совместна $\iff$ $\ \forall$ решения системы $y^TA = 0 \to y^Tb = 0$

*Доказательство:*

**(=>)** $Ax = b$ совместна $\iff$ $\ \exists x : Ax = b$

Пусть $y$ – решение $y^TA  =0$
Умножим слева на $y^T:$ $y^T(Ax) = y^Tb \iff (y^TA)x = 0 = y^Tb$, ч.т.д.

**(<=)** Пусть $Ax = b$ несовместна. 
Тогда в упрощенном виде матрицы $(A | b)$ есть строка $\begin{pmatrix}0 & 0 & \dots & 0 & 1\end{pmatrix}$
$\implies \ \exists y - \text{столбец} : y^T(A| b) = \begin{pmatrix}0  & 0 & \dots & 0 & 1\end{pmatrix} \implies y^TA = 0, y^Tb=1$ – противоречие
