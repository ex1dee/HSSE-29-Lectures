**Рефакторинг и замечания**
- **База данных и миграции**
	
	- CONSTRAINT unique_file_per_parent UNIQUE (user_id, parent_id, name) — добавить ограничение уникальности для предотвращения дубликатов в одной папке.
	    
	- CREATE INDEX idx_files_parent_name ON files(parent_id, name) — оптимизация поиска файлов внутри директории.
	    
	- CREATE INDEX idx_files_status ON files(status) WHERE status != 'READY' — частичный индекс для быстрой обработки "зависших" файлов.
	    
	- Добавить поле createdAt — добавить аудит времени создания записи (сейчас только updatedAt).
	    
	- Настроить репо — security и правила PR

	- Валидация путей — проверка корректности структуры при перемещении и создании папок.
	    
	- Правильный хедер для Authorization — переход на стандартный заголовок `Authorization: Bearer <token>` вместо кастомного
