##### Таблица "users"
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,

	phoneNumber VARCHAR(100) UNIQUE NOT NULL, ?
    password_hash VARCHAR(255) NOT NULL,
    username VARCHAR(100) NOT NULL,
    storage_limit BIGINT DEFAULT 10737418240, -- 10GB в байтах
    used_storage BIGINT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT true

Поле *is_active* равно *false*, если пользователь удалил свой аккаунт (или был заблокирован, к примеру). Нужно в случаях, когда аккаунт нужно восстановить.
##### Таблица "files"
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    owner_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    storage_path VARCHAR(500) NOT NULL,             -- путь в Minio
    file_size BIGINT NOT NULL,           -- размер в байтах
    mime_type VARCHAR(100),              -- MIME-тип
    tags VARCHAR(500),                   -- теги через запятую
	visibility VARCHAR(20) DEFAULT 'private', -- 'private', 'public', 'link_only'
    is_deleted BOOLEAN DEFAULT false$,
    
    -- Временные метки
    uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP NULL,
    last_accessed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

Примеры MIME-type:

| Файл         | MIME-type        |
| ------------ | ---------------- |
| photo.jpg    | image/jpeg       |
| document.pdf | application/pdf  |
| data.json    | application/json |
| movie.mp4    | video/mp4        |
