- **Разбиением** $T$ отрезка $[a, b]$ называется конечный упорядоченный по возрастанию набор точек:
    
    $$T = \{x_i\}_{i=0}^{N_T}, N_T \in \mathbb{N}$$
    
    $$a = x_0 < x_1 < \dots < x_{N_T} = b$$
    
    $\mathcal{T}([a, b])$ — множество всех разбиений отрезка $[a, b]$.
    
- Если $T$ — разбиение $[a, b]$, то **лёгкость разбиения** (мелкость):
    
    $$l(T) := \max_{1 \le i \le N_T} |x_i - x_{i-1}|$$
    
- Пусть $T \in \mathcal{T}([a, b])$ и $f : [a, b] \to \mathbb{R}$. Тогда:
    
    - $s_f(T) := \sum_{i=1}^{N_T} m_i(f)(x_i - x_{i-1})$ — **нижняя сумма Дарбу**
        
    - $S_f(T) := \sum_{i=1}^{N_T} M_i(f)(x_i - x_{i-1})$ — **верхняя сумма Дарбу**
        Где $m_i(f)$ и $M_i(f)$ определены как:
        
        $$m_i(f) := \inf_{x \in [x_{i-1}, x_i]} f(x)$$
        
        $$M_i(f) := \sup_{x \in [x_{i-1}, x_i]} f(x)$$
        

> [!NOTE] **Примечание**
> 
> При работе с суммами будем придерживаться следующих соглашений:
> 
> 1. $(+\infty) + (+\infty) = +\infty$
>     
> 2. $(-\infty) + (-\infty) = -\infty$
>     
> 3. $\lambda(\pm\infty) = \pm\infty$, если $\lambda > 0$
>     
> 4. $\lambda(\pm\infty) = \mp\infty$, если $\lambda < 0$
> 	
> 5. $(\pm\infty) + C = \pm\infty$


___

> [!INFO] **Лемма** (об ограниченности сумм Дарбу)
> 
> Пусть $f : [a, b] \to \mathbb{R}$. Тогда:
> 
> 1. $s_f(T) > -\infty \quad \forall T \in \mathcal{T}([a, b]) \iff f$ ограничена снизу на $[a, b]$
>     
> 2. $S_f(T) < +\infty \quad \forall T \in \mathcal{T}([a, b]) \iff f$ ограничена сверху на $[a, b]$
>     

**Доказательство:**

Докажем первое утверждение (второе доказывается аналогично):

$(\Leftarrow)$ Если $f$ ограничена снизу на $[a, b]$, то для любого разбиения $T \in \mathcal{T}([a, b])$ выполнено $m_i(f) > -\infty$ для всех $i \in \{1, \dots, N_T\}$. Следовательно, их сумма (нижняя сумма Дарбу) также конечна: $s_f(T) > -\infty$.

$(\Rightarrow)$ Пусть $\forall T \in \mathcal{T}([a, b]) \implies s_f(T) > -\infty$.

Фиксируем произвольное разбиение $T = \{x_i\}_{i=0}^{N_T}$. Тогда для каждого сегмента $i \in \{1, \dots, N_T\}$ должно выполняться $m_i(f) > -\infty$ (иначе вся сумма стала бы $-\infty$ по правилам сложения).

Воспользовавшись определением $m_i(f)$, получим:

$$\forall i \in \{1, \dots, N_T\} \implies \inf_{x \in [x_{i-1}, x_i]} f(x) > -\infty$$

Так как $\bigcup_{i=1}^{N_T} [x_{i-1}, x_i] = [a, b]$, то инфимум функции на всём отрезке оценивается минимальным из локальных инфимумов:

$$\inf_{x \in [a, b]} f(x) \ge \min_{1 \le i \le N_T} m_i(f) > -\infty$$

Следовательно, $f$ ограничена снизу на $[a, b]$.

---

**Функция** $f : [a, b] \to \mathbb{R}$ называется **интегрируемой по Риману** на $[a, b]$ (обозначается $f \in \mathcal{R}([a, b])$), если:

$$\ \exists J \in \mathbb{R} : \begin{cases} \exists \lim_{l(T) \to 0} s_f(T) = J \\ \exists \lim_{l(T) \to 0} S_f(T) = J \end{cases}$$

$$\iff \begin{cases} \forall \varepsilon > 0 \ \exists \delta(\varepsilon) > 0 : \forall T \in \mathcal{T}([a, b]) : l(T) < \delta(\varepsilon) \implies |s_f(T) - J| < \varepsilon \\ \forall \varepsilon > 0 \ \exists \delta(\varepsilon) > 0 : \forall T \in \mathcal{T}([a, b]) : l(T) < \delta(\varepsilon) \implies |S_f(T) - J| < \varepsilon \end{cases}$$

Если $f$ интегрируема на $[a, b]$ по Риману, то число $J$ называется **интегралом Римана** функции $f$ по отрезку $[a, b]$ и обозначается:

$$\int_a^b f(x) \, dx$$
