>**Основные параметры:**
>Фокус: $F\left( \frac{p}{2}, 0 \right)$
>Директриса: $x = -\frac{p}{2}$
>Эксцентриситет: $\epsilon = 1$ 
>(*расстояние от точки до фокуса равно расстоянию от точки до директрисы*)

___

> **Фокальное свойство**
> Пусть $M$ – точка $I$ четверти на параболе
> $MF = x + \frac{p}{2}$

*Доказательство:*
$MF = \sqrt{ \left( x - \frac{p}{2} \right)^2 + y^2 } = \sqrt{ x^2 - px + \frac{p^2}{4} + 2px } = \sqrt{ x^2 + px + \frac{p^2}{4} } = \sqrt{ \left( x+ \frac{p}{2} \right)^2 } = |x + \frac{p}{2}|$
$x \geq 0, p > 0 \implies MF = x + \frac{p}{2} =$ *расстоянию от точки до директрисы*

___

>**Оптическое свойство**
>Лучи, проведённые к точке $M$, отражаясь от параболы,
>проходят через её фокус

___

>**Уравнение касательной**

$$yy_{0} = p(x + x_{0})$$
*В точке* $(0, 0)$ — вертикальная касательная $x = 0$: верно
*В остальных точках*:

Продифференцируем обе части $y^2 = 2px$:
$2yy' = 2p \implies y'(x_{0}) = \frac{p}{y_{0}}$

Тогда касательная имеет вид
$y - y_{0} = \frac{p}{y_{0}}(x - x_{0})$
$y = \frac{p(x - x_{0}) + y_{0}^2}{y_{0}}$
$yy_{0} = px - px_{0} + y_{0}^2 = px - px_{0} + 2px_{0} = px + px_{0} = p(x + x_{0})$
