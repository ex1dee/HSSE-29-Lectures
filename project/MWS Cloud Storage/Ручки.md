## Users

+POST   /api/users/auth/login          # Вход в систему
- **X-Auth-Email**
- **X-Auth-Password**

___

+POST /api/users/auth/refresh # Ротация токенов
- **X-Refresh-Token**

___

GET   /api/users/info          # Инфо о юзере
- **X-Auth-Token**

___

POST   /api/users/update          #  Изменение данных о юзере
- **X-Auth-Token**
- **X-New-Username** (опционально)
- **X-Old-Password** (опционально)
- **X-New-Password** (опционально)

___

POST   /api/users/auth/login          # Вход в систему
- **X-Auth-Email**
- **X-Auth-Password**

___

POST   /api/users/auth/register       # Регистрация нового пользователя
- **X-Auth-Email**
- **X-Auth-Password**
- **X-Auth-Username**

___

POST   /api/users/auth/logout         # Выход
- **X-Auth-Token**

## Files

+GET    /api/files/list               # Получить список файлов
- **X-Auth-Token**

*Параметры:*
- **includeDirectories** (опционально)
- **directory** (опционально)

*В недалеком будущем:*
- Пагинация

___

+GET    /api/files/download?path={}      # Скачать файл (всегда чанково)
- **X-Auth-Token**

___

+POST   /api/files/upload?path={}        # Загрузить файл
- **X-Auth-Token**
- **X-File-Size**
- **X-File-Tags**

___

+POST   /api/files/upload/resume?path={}        # Восстановить чанковую загрузку
- **X-Auth-Token**
- **X-File-Size**

___

DELETE /api/files?path={}      # Удалить файл (пока только HARD)
- **X-Auth-Token**

___

+PUT    /api/files?path={}&newPath={}     # Обновить метаданные файла
- **X-Auth-Token**
- **X-File-New-Visibility** (опционально)
- **X-File-New-Tags** (опционально)

___

+GET    /api/files/info?path={} # Получить метаданные файла
- **X-Auth-Token**
