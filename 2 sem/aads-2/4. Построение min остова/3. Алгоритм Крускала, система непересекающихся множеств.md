2. Проходимся по отсортированному списку и пытаемся добавить ребро. Если ребро не образует цикл, добавляем.

Определим структуру данных. 
Хотим проверить $u$ и $v$ в одном множестве и объединить два множества.
Система непересекающися множеств (СНМ/DSU)
Изначально $n$ множеств из одного элемента.
При расширении множеств строим ориентированне деревья. 
Корень - лидер множества.

```python
int get_leader(v)
	if p[v] == -1
		return v;
	return get_leader(p[v]);

```

$p[v]$ - родитель $v$
$p[v]=-1$, если $v$ - лидер

Подвешиваем меньшее дерево к большему (ранговая эвристика).

```
void merge(a, b)
	a=get_leader(a);
	b=get_leader(b);     // a != b
	
	if (size[a] > size[b])
		swap(a, b);
	size[a] += size[b];
	p[a] = b;
```

Все операции и этой структурой данных работают за $O(\log n)$
Доказательство.
$size[b] \leq \frac{1}{2}size[c]$ ($c$ - объединение $a$ и $b$)

Пусть все вершины на пути переподвешиваются к лидеру. (Эвристика сжатия путей)


```
int get_leader(v)
	if p[v] == -1
		return v;
	return p[v] = get_leader(p[v]);

```

Функция Аккермана:
$A(m, n) = \begin{cases}n+1, m=0 \\ A(m-1, 1), m>0, n=0 \\ A(m-1, A(m, n-1)), m>0, n>0\end{cases}$
Растёт очень быстро $A(4, 4) = 2^{2^{65565}}$-3

Введём обратную функцию Аккермана. Она растёт очень медленно.
$\alpha(n)=min(n)$, что $A(n,n)\geq k$

Если применить обе эвристики, то асимптотика операций СНМ равна $O^*(\alpha(n))$

Алгоритм Крускала: Сортируем, проходим по всем рёбрам, ищем их в другом множестве СНМ.
Асимптотика: $O(m*\log m+m*\alpha(n))$
