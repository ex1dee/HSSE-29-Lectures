#### [[1. Формула включений-исключений |Формула включений-исключений]]

**Утверждение**:  
Для конечных $A_{1}, \dots, A_{n}$:

$$|\cup_{i=1}^n A_{i}| = \sum_{m=1}^n (-1)^{m+1}\sum_{1\leq i_{1}<i_{2}<\dots<i_{m}\leq n}|\cap_{k=1}^m A_{i_{k}}|$$

**Доказательство:**

1. **База $n=2$** — стандартная формула:
    $|A \cup B| = |A| + |B| - |A \cap B|$
2. **Предположение индукции** — формула верна для $n$ множеств.
3. **Шаг**:  
    Пусть $B = \cup_{i=1}^nA_{i}$​. Тогда:
    $$
\cup_{i=1}^{n+1}A_{i}=B \cup A_{n+1}
$$
    - По формуле для двух множеств:
        
        $$
|A_{n+1}\cup B| = |A_{n+1}|+ |B|- |A_{n+1}\cap B|
$$
    - Для $|B|$ используем **предположение индукции**.
        
    - Для $|B \cap A_{n+1}|$ замечаем, что
        
        $$
A_{n+1}\cap B = A_{n+1}\cap(\cup_{i=1}^nA_{i}) = (A_{n+1}\cap A_{i})\cup\dots \cup(A_{n+1}\cap A_{n}) = \cup_{i=1}^n(A_{i}\cap A_{n+1})
$$
        
        и применяем **предположение индукции** к множествам $A_{i}\cap A_{n+1}$.
        
    - Подставляем, перегруппировываем слагаемые, меняем индексы — получаем формулу для $n+1$.

#### [[6. Китайская теорема об остатках|Китайская теорема об остатках]]

**Утверждение**:  
Для попарно взаимно простых $a_{1}, \dots, a_{n}$​ и любых $r_{1}, \dots, r_{n}$ система

$$N \equiv_{a_{i}} r_{i}$$

имеет решение, единственное по модулю $a_{1}a_{2}\dots a_{n}$.

**Доказательство:**

1. **База $n = 1$** — тривиально.
2. **Шаг**:
    
    - Пусть $N$​ — решение первых $k$ уравнений.
        
    - $d = a_{1}\dots a_{k}, НОД(d, a_{k+1}) = 1$
        
    - Рассмотрим числа $N, N + d, \dots, N + (a_{k+1} - 1)d$
        Они дают все остатки по модулю $a_{k+1}$ (доказываем, что они разные).
        
    - Берём то, которое даёт остаток $r_{k+1}$​ ⇒ это решение системы из $k+1$ уравнений.
        
3. **Единственность**:  
    Если $N_{1}, N_{2}$ — решения, то $N_{1} - N_{2}$​ делится на все $a_{i}$​ ⇒ делится на их произведение, т.к. все $a_{i}$ взаимнопросты между собой.

#### [[5. Левый сдвиг. Теорема Кэли |Теорема Кэли]]

**Утверждение**:  
Всякая конечная группа $G$ порядка $n$ изоморфна некоторой подгруппе симметрической группы $S_{n}$
$$
\ \exists H <S_{n}:G \cong H
$$

**Доказательство**:

1. **Занумеруем элементы группы**:
    $G = \{ g_{1}, g_{2}, \dots, g_{n} \}$
2. **Сопоставим каждому $a \in G$ левый сдвиг $L_{a}$​**:
    $L_{a} : G \to G, L_{a}(g) = ag$
    - $L_{a}$​ — биекция (обратное: $L_{a^{-1}}$)
        $\implies$ $L_{a}$​ — перестановка на множестве из $n$ элементов, т.е. $L_{a} \in S_{n}$.
        
3. **Рассмотрим множество всех левых сдвигов**:
    $$
L_{G} = \{ L_{a} \ | \ {a \in G} \} \subseteq S_{n}
$$
4. **Покажем, что $L_{G}$​ — группа**
5. $L_{G} < S_{n}$, т.к. в $L_{G}$ групповая операция композиции – это и есть композиция из $S_{n}$
6. **Построим изоморфизм $G \cong L_{G}$​**:  
    Отображение $\phi:G \to L_{G}, \phi(a) = L_{a}$:
    
    - Биекция
        
    - Гомоморфизм: $L_{a}\circ L_{b} = L_{ab}$
        
7. **Итог**:  
    $G \cong L_{G} < S_{n}$

#### [[4. Факторгруппа|Теорема о гомоморфизме]]

**Утверждение**:
Если $\phi: G\to G'$ — гомоморфизм групп, то
$$
G / ker \ \phi \cong \mathrm{Im} \ \phi
$$
**Доказательство**:

1. **Определим отображение**:
	$$f : G / ker \ \phi \to \mathrm{Im} \ \phi, f(g ker \ \phi) = \phi(g)$$
2. **Корректность**:
    
    - Если $g_{1}ker \ \phi = g_{2}ker \ \phi$, то $g_{2}^{-1}g_{1}\in ker \ \phi$
        
    - Тогда $\phi(g_{2}^{-1}g_{1}) = e' \implies \phi(g_{1})=\phi(g_{2})$
        $\implies$ Значение $f$ не зависит от выбора представителя класса.
        
3. **Гомоморфность**:
    $f((g_{1}ker \ \phi)(g_{2} ker \ \phi)) = f(g_{1}g_{2} ker \ \phi) = \phi(g_{1}g_{2}) = \phi(g_{1})\phi(g_{2}) = f(g_{1}ker \ \phi)f(g_{2}ker \ \phi)$
4. **Инъективность**:
    
    - Если $f(g_{1} ker \ \phi) = f(g_{2}ker \ \phi)$, то $\phi(g_{1}) = \phi(g_{2})$
        
    - $\phi(g_{2}^{-1})\phi(g_{1}) = e' \implies \phi(g_{2}^{-1}g_{1}) = e' \implies g_{2}^{-1}g_{1} \in ker \ \phi$ $\implies$ $g_{1}ker \ \phi = g_{2} ker \ \phi$ 
        
5. **Сюръективность**:
    
    - Любой элемент $\mathrm{Im} \ \phi$ имеет вид $\phi(g) = f(gker \ \phi)$
        
6. **Вывод**:  
    $f$ — изоморфизм групп $\implies G / ker \ \phi \cong \mathrm{Im} \ \phi$

#### [[7. Дерево|Теорема об эквивалентности четырёх определений дерева]]

**Определения**:

1. Связный граф без циклов (оригинальное определение)
2. Между любыми двумя вершинами $\ \exists$ **единственный** **простой путь**
3. Связный граф с $|V| = |E| + 1$
4. Ациклический граф с $|V| = |E| + 1$

**Доказательство эквивалентности:**

**(1) => (2)**
- Связность $\implies$ путь существует.
- Если есть два разных пути между $u$ и $v$, то та их часть, где нет общих рёбер, содержит цикл (через первые/последние точки расхождения) — противоречие с ацикличностью.

**(2) => (3)**

- Ацикличность: иначе в цикле два пути между вершинами.
- Существует висячая вершина (конец максимального по длине пути).
- Индукция по $|V|$:  
    **База**: $|V| = 1$ — верно.  
    **Шаг**: Удалим висячую вершину с ребром, применим предположение индукции

**(3) => (4)**

- Предположим, есть цикл
- Удалим ребро цикла — связность сохранится
- Повторяем, пока не получим связный ациклический граф (дерево)
- Для него $|V| = |E'| + 1$, но $|E'| < |E|$ $\implies$ противоречие с $|V| = |E| + 1$

**(4) => (1)**

- Пусть граф имеет $k$ компонент связности.
    
- Каждая компонента — связный ациклический (дерево) ⇒ $|V_{i}| = |E_{i}| + 1$.
    
- Суммируем:
    $|V| =\sum_{i=1}^k |V_{i}| = \sum_{i=1}^k|E_{i}|+k = |E| + k$
- По условию $|V| = |E| + 1$ $\implies k = 1$ $\implies$ граф связен

#### [[2. Эйлеровы и гамильтоновы пути|Критерий эйлеровости графа]]

**Определения**:

1. Граф Эйлеров
2. Граф связный и $\ \forall v\to deg(v)$ – чётная
3. Рёбра графа можно разбить на непересекающиеся по рёбрам циклы

**Доказательство эквивалентности**:

**(1) => (2)**

- В эйлеровом цикле каждое посещение вершины $v$ использует одно входящее и одно выходящее ребро.
- Все рёбра, инцидентные $v$, разбиваются на пары $\implies deg (v)$ – чётно
- Граф связен (эйлеров цикл проходит через все рёбра и вершины)

**(2) => (3)**

- **Шаг 1**: Из любой вершины $v_{0}$​ строим цикл, идя по непосещённым рёбрам.  
    Чётность степеней гарантирует, что мы не "застрянем" на вершине с нечётным числом непосещённых рёбер. Так что рано или поздно вернёмся в $v_{0}$.
    
- **Шаг 2**: Удаляем все рёбра найденного цикла.  
    Степени всех вершин остаются чётными (вычитаем 2 для каждой инцидентной вершины).
    
- **Шаг 3**: Повторяем, пока рёбра не кончатся.  
    Получаем разбиение рёбер на непересекающиеся циклы.
    

**(3) => (1)**

**Индукция по числу циклов $k$ в разбиении**:

- **База $k = 1$**: Граф — один цикл, он же эйлеров.
    
- **Шаг**:  
    Пусть для разбиений с $< k$ циклов утверждение верно. 
    Возьмём разбиение на $k$ циклов.
    Так как граф связен, найдутся два цикла $C_{1}, C_{2}$ с общей вершиной $v$.  
    Объединим их в один цикл $C'$:    
    $$C' = (v \xrightarrow{C_{1}}v) + (v \xrightarrow{c_{2}}v)$$
    
    Получим разбиение на $k - 1$ цикл $\implies$ по предположению индукции существует эйлеров цикл.

#### [[6. Полный и двудольный граф. Раскраска графа|Критерий двудольности графа]]

**Утверждение**:
Граф $G$ является **двудольным** $\iff$ он **не содержит циклов нечётной длины**

**Доказательство**:

**(=>)**

1. Пусть $G$ двудолен с долями $U$ и $W$
2. Рассмотрим любой цикл $C=v_{1}v_{2}\dots v_{k}$
    Без ограничения общности: $v_{1} \in U$, $v_{2} \in W$, $v_{3} \in U, \dots$
    Тогда:
    $$
v_{i} \in U \text{ при нечётном } i, \ \ v_{i} \in W \text{ при чётном } i
$$
3. Чтобы ребро $(v_{k}, v_{1})$ существовало, $v_{k} \in W \implies k$ – чётно $\implies$ длина цикла чётна
    

**(<=)**

Предположим граф связен (иначе доказываем для каждой компоненты).

1. Фиксируем произвольную вершину $u$.
    
2. Разбиваем вершины по чётности расстояния от $u$:
    - $U = \{ v \in V : \text{расстояние от } u \text{ до } v \text{ чётно} \}$
	* $W = \{ v \in V : \text{расстояние от } u \text{ до } v \text{ нечётно} \}$
3. **Докажем, что рёбер внутри $U$ и $W$ нет** (от противного):  
    Пусть есть ребро $(x, y)$, где $x, y \in U$.
    
    - Рассмотрим кратчайшие пути $P_{x}$​ (из $u$ в $x$) и $P_{y}$​ (из $u$ в $y$)
        
    - Пусть $w$ — последняя общая вершина на этих путях.
    - $w \neq x$, ведь иначе $P_{y} = P_{x} + (x, y) \implies d(u, x)$ и $d(u, y)$ разной чётности
        
    - Части путей $P_{w\to x}$ и $P_{w \to y}$​ не пересекаются (кроме $w$).
        
4. **Строим цикл**:
    $C = P_{w\to x} + (x, y) + P_{y\to w}$
    Его длина: $\begin{vmatrix}C\end{vmatrix} = (d(u, x) - d(u, w))+ 1 + (d(u, y) - d(u, w))$
    
    Так как $d(u, x)$ и $d(u, y)$ чётны, а $d(u, w)$ одинаково в обоих случаях,  
    длины $d(u, x) - d(u, w)$ и $d(u, y) - d(u, w)$ **одинаковой чётности**.  
    $\implies$ $|C|$ — **нечётно** 
    
1. Получили нечётный цикл — противоречие с условием. 
    $\implies$ Рёбер внутри $U$ и $W$ нет $\implies$ разбиение корректно $\implies$ граф двудолен.

#### [[3. Паросочетания. Теорема Холла|Теорема Холла]]

**Утверждение**:  
Пусть $G = (L \cup R, E)$ — двудольный граф, $|L| \leq |R|$
Следующие условия эквивалентны:

1. Существует **паросочетание**, покрывающее все вершины $L$.
2. **Условие Холла**: $\ \forall X\subseteq L \to|N(X)| \geq |X|$,
    где $N(X)$ – подмножество вершин $\in R$, смежных хотя бы с одной вершиной из $X$

**Доказательство**:

**(=>)**

- Пусть $M$ — искомое паросочетание.
- Для любого $X \subseteq L$ вершины из $X$ сопоставлены в $M$ различным вершинам из $R$, которые лежат в $N(X)$.
- Следовательно, $|N(X)| \geq |X|$

**(<=)**

**Индукция по $|L|$**:

- **База** $|L| = 1$: условие Холла для $X = L: |N(L)| \geq 1 \implies$ ребро существует.
    
- **Шаг**:  
    Пусть утверждение верно для всех графов с $|L| \leq m$. Рассмотрим $|L| = m$
    **Случай 1**: $\ \exists A \subset L : |N(A)|=|A|$
    
    1. В подграфе на $A \cup N(A)$ условие Холла выполнено $\implies$ по индукции существует паросочетание $M_{1}$​, покрывающее $A$.
        
    2. Рассмотрим $L'=L \setminus A, R' = R \setminus N(A)$
        Проверяем условие Холла для $X \subseteq L'$ в новом графе:
        $$
|N_{G'}(X)| = |N_{исх}(X) \setminus N(A)| \geq |X|
$$
    3. По индукции существует паросочетание $M_{2}$​, покрывающее $L'$.
        
    4. $M_{1} \cup M_{2}$​ — искомое паросочетание для $L$.
        
    
    **Случай 2**: $\ \forall A \subset L \to |N(A)| > |A|$
    
    1. Берём любое ребро $(l, r) \in E$.
        
    2. Удаляем $l$ и $r$ вместе с инцидентными рёбрами, получаем граф $G'$.
        
    3. Проверяем условие Холла для $X \subseteq L \setminus \{ l \}$
        
        - Если $r \not\in N_{исх}(X)$, то $|N_{G'}(X)|=|N_{исх}(X)| \geq |X|$
            
        - Если $r \in N_{исх}(X)$, то
            $$
|N_{G'}(X)|=|N_{исх}(X)| - 1 \geq |X| + 1 - 1 = |X|
$$
    1. По индукции в $G'$ существует паросочетание $M'$, покрывающее $L \setminus \{  l \}$
        
    2. Добавляем ребро $(l, r) \implies$ получаем паросочетание для всего $L$.
