>**Собственный пучок прямых**
>Это множество всех прямых, проходящих через фиксированную точку $P$ (*центр пучка*)
>
   Пусть две различные прямые заданы уравнениями:
$F₁(x, y) = A₁x + B₁y + C₁ = 0$
$F₂(x, y) = A₂x + B₂y + C₂ = 0$
>
> Тогда уравнение любой прямой $m$ из этого пучка представимо в виде:
$F(x, y) = \lambda F_{1}(x, y) + \nu  F_{2}(x,y), (\lambda, \nu) \neq (0, 0)$

*Доказательство:*
$(A_{1}, B_{1}), (A_{2},B_{2})$ - базис, т.к. прямые различные и у них различные нормали
Нормаль любой прямой любого пучка можно представить в виде линейной комбинации
$(A,B) = \lambda(A_{1},B_{1}) + \nu(A_{2}, B_{2})$

Мы хотим получить уравнение прямой $F(x,y)$ 
с нормалью $(A, B)$, проходящей через точку $P(x_{0}, y_{0})$.

$F(x, y) = A(x- x_{0}) + B(y - y_{0}) = (\lambda A_{1} + \nu A_{2})(x-x_{0}) + (\lambda B_{1} + \nu B_{2})(y - y_{0})$ 
$= \lambda(A_{1}(x-x_{0}) + B_{1}(y - y_{0})) + \nu(A_{2}(x-x_{0}) + B_{2}(y-y_{0}))$
$= \lambda F_{1}(x, y) + \nu F_{2}(x,y)$
