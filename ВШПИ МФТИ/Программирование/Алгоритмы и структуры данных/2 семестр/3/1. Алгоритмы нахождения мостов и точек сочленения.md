**Дерево обхода DFS** — это остовное дерево (или лес), которое строится в процессе обхода графа в глубину. Ребра графа в контексте DFS делятся на:

- **Древесные ребра**: по которым мы впервые зашли в новую вершину.
    
- **Обратные ребра**: ведут из текущей вершины в уже посещенного предка в дереве DFS.
    

**Мост** — это ребро, при удалении которого количество компонент связности графа увеличивается.

**Точка сочленения** — это вершина, при удалении которой (вместе со всеми инцидентными ей ребрами) количество компонент связности увеличивается.

### Вспомогательные величины

Для поиска этих объектов используются два массива:

1. **`tin[v]`**: время входа в вершину
    
2. **`up[v]`**: минимальное `tin`, до которого можно добраться из $v$, используя ребра поддерева и не более одного обратного ребра.
    

### Алгоритм нахождения мостов

**Асимптотика:** $O(|V| + |E|)$ 

**Условие моста:** Ребро $(v, u)$ является мостом, если из поддерева $u$ нет обратных ребер в саму $v$ или выше нее:

$$tin[v] < up[u]$$

```python
def dfs_bridges(v, p=-1): # p - пред. вершина
    used[v] = True
    tin[v] = up[v] = timer++
    for u in graph[v]:
        if u == p: continue
        if used[u]:
            # Обратное ребро: подтягиваем up[v] через tin[u]
            up[v] = min(up[v], tin[u])
        else:
            # Древесное ребро
            dfs_bridges(u, v)
            up[v] = min(up[v], up[u])
            if tin[v] < up[u]:
                # Ребро (v, u) — мост
```

### Алгоритм нахождения точек сочленения

**Условие:**

1. Если $v$ — **корень** дерева DFS: она является точкой сочленения, если у нее $>1$ сына в дереве.
    
2. Если $v$ — **не корень**: она является точкой сочленения, если $\exists$ сын $u$ такой, что $tin[v] \leq up[u]$.

## 2. Кратчайшие расстояния в графах

- Далее $w$ – возмозжные значения весов рёбер
- По умолчанию $dist[v] = -1 \ \forall v \neq \text{start}$

### Случай $w = 1$: Алгоритм BFS

**Асимптотика:** $O(V + E)$.

```cpp
dist[start] = 0;
queue.push(start);
while (!queue.empty()) {
    v = queue.front(); queue.pop();
    for (u : graph[v]) {
        if (dist[u] == -1) {
            dist[u] = dist[v] + 1;
            queue.push(u);
        }
    }
}
```

### Случай $w \in \{0, 1\}$: 0-1 BFS

Если в графе есть ребра с нулевым весом, обычная очередь заменяется на **двустороннюю очередь (deque)**.

- Если вес ребра $0$: `push_front` (обрабатываем как можно быстрее, расстояние не выросло).
    
- Если вес ребра $1$: `push_back` (стандартное поведение).
    
    **Асимптотика:** $O(V + E)$.
    

### Случай $w \in \{1, \dots, k\}$: Алгоритм Диала

**Асимптотика:** $O(V \cdot k + E)$.

**Суть:**

Вместо приоритетной очереди мы заводим массив бакетов (списков) размером $k+1$. В бакете `i` лежат вершины, расстояние до которых сейчас равно `i`.

- Мы просто сканируем бакеты по кругу.
    
- Когда мы находим более короткий путь до вершины (релаксация), мы просто перекладываем ее из одного списка в другой.
