- **Отображение из $L$ в $L'$** — правило, по которому каждому элементу из $L$ сопоставляется элемент из $L'$. Записывается как $\phi : L \to L'$ или $\phi(x) = y$, где $x \in L, y \in L'$.
    
- **Преобразование** — отображение, при котором $L = L'$.
    
- **Линейное отображение $\phi$** — отображение, удовлетворяющее условиям:
    
    1. $\forall x, y \in L \implies \phi(x + y) = \phi(x) + \phi(y)$
        
    2. $\forall \alpha \in \mathbb{R}, \forall x \in L \implies \phi(\alpha x) = \alpha \phi(x)$
        

---

> **Теорема** (**о линейности комбинации**)
> 
> $\forall \alpha, \beta \in \mathbb{R}, \forall x, y \in L \implies \phi(\alpha x + \beta y) = \alpha \phi(x) + \beta \phi(y)$

_Доказательство:_

Утверждение напрямую следует из аксиом аддитивности и однородности определения линейного отображения.

---

> **Теорема** (**о сохранении линейной зависимости**)
> 
> ЛЗ набор векторов при линейном отображении переходит в ЛЗ набор.

_Доказательство:_

Рассмотрим линейно зависимый набор $\{x_i\}$ и комбинацию $\sum \lambda_i x_i = 0$, где не все $\lambda_i = 0$. В силу линейности:

$\phi(\sum \lambda_i x_i) = \sum \lambda_i \phi(x_i) = \phi(0)$.

Поскольку $\phi(0) = \phi(0 \cdot x) = 0 \cdot \phi(x) = 0$, получаем $\sum \lambda_i \phi(x_i) = 0$, что означает линейную зависимость образов.

> **Примечание**
> 
> ЛНЗ при линейном отображении может перейти в любой набор 

*В дальнейшем рассматриваются только конечномерные пространства.*

___

> **Теорема** (**о размерности образа подпространства**)
> 
> Пусть задано линейное отображение $\phi : L \to L'$ и подпространство $L_1 \subset L$. Тогда $\phi(L_1) \subset L'$ и $\dim \phi(L_1) \le \dim L_1$.

_Доказательство:_

Если $L_1 = \{0\}$, утверждение очевидно. Пусть $L_1 \neq \{0\}$. Выберем в $L_1$ базис $f_1, \dots, f_k$. Рассмотрим произвольный вектор $x \in L_1$:

$x = x_1 f_1 + \dots + x_k f_k$.

Тогда его образ $\phi(x) \in L'$ в силу линейности имеет вид:

$\phi(x) = x_1 \phi(f_1) + \dots + x_k \phi(f_k)$.

Отсюда следует, что $\phi(L_1) = \langle \phi(f_1), \dots, \phi(f_k) \rangle$, то есть $\phi(L_1)$ является подпространством в $L'$, порожденным образами базисных векторов. Так как количество порождающих векторов равно $k$, то $\dim \phi(L_1) \le k = \dim L_1$.

---

- **Образ отображения ($\text{Im } \phi$)** — подпространство $\phi(L) \subset L'$, состоящее из всех векторов $y \in L'$, для которых существует $x \in L$ такой, что $\phi(x) = y$.
- **Матрица линейного отображения** — если в $L$ задан базис $e_1, \dots, e_n$, а в $L'$ — базис $f_1, \dots, f_m$, то образ любого вектора $x$ вычисляется через умножение матрицы $A$ на столбец координат $x$:
    
    $$\phi(x) = A \cdot x$$
    
    где столбцы матрицы $A$ — это координаты образов базисных векторов $\phi(e_j)$ в базисе $\{f_i\}$
- **Ранг отображения ($\text{rg } \phi$)** — размерность образа отображения $\dim(\text{Im } \phi)$.
    - $\text{rg } \phi = \text{rg } A$, где $A$ – матрица отображения
- **Сюръективное отображение** — отображение, для которого $\forall y \in L' \ \exists x \in L : \phi(x) = y$.
    
    - **Критерий сюръективности:** $\text{rg } \phi = \dim L'$.
	    Но для бесконечномерных это только необходимое условие
        
- **Ядро отображения ($\text{Ker } \phi$)** — множество векторов $x \in L$, таких что $\phi(x) = 0$. Ядро является линейным подпространством в $L$.
    
- **Инъективное отображение** — отображение, для которого из $x \neq y$ следует $\phi(x) \neq \phi(y)$.
    
    - **Критерий инъективности:** $\text{Ker } \phi = \{0\}$.
        
- **Биективное отображение** — отображение, являющееся одновременно сюръективным и инъективным.
    

___

> **Теорема** (**о сохранении линейной независимости**)
> 
> Линейное отображение $\phi : L \to L'$ инъективно $\iff$ оно переводит любой ЛНЗ набор векторов в ЛНЗ.

_Доказательство:_

$(\Rightarrow)$ Пусть $\phi$ инъективно. Возьмем ЛНЗ набор $f_1, \dots, f_k \in L$. Предположим от противного, что их образы $\phi(f_1), \dots, \phi(f_k)$ линейно зависимы. Тогда существует нетривиальная комбинация:

$\beta_1 \phi(f_1) + \dots + \beta_k \phi(f_k) = 0$, где $\sum \beta_i^2 > 0$.

В силу линейности: $\phi(\beta_1 f_1 + \dots + \beta_k f_k) = 0$.
Так как $\phi$ инъективно ($\text{Ker } \phi = \{0\}$), то $\beta_1 f_1 + \dots + \beta_k f_k = 0$.
Но $f_1, \dots, f_k$ — ЛНЗ, значит все $\beta_i = 0$. Противоречие.

$(\Leftarrow)$ Пусть любой ЛНЗ набор переходит в ЛНЗ. Предположим, что $\phi$ не инъективно, тогда существует $v \in \text{Ker } \phi$, такой что $v \neq 0$. Набор из одного ненулевого вектора $\{v\}$ всегда линейно независим. Однако его образ $\phi(v) = 0$ является линейно зависимым набором. Противоречие. Значит, $\text{Ker } \phi = \{0\}$.

> **Теорема** (**о сумме размерностей ядра и образа**)
> 
> Пусть $\phi: L \to L'$ — линейное отображение.
> Тогда $\dim L = \dim \text{Ker } \phi + \dim \text{Im } \phi$

_Доказательство:_

Пусть $\dim L = n$, а ранг отображения $\text{rg } \phi = \dim \text{Im } \phi = r$.

Ядро отображения $\text{Ker } \phi$ по определению состоит из векторов $x$, таких что $Ax = 0$ (где $A$ — матрица отображения). Это однородная система линейных уравнений. Размерность пространства решений такой системы равна $n - \text{rg } A$.

Так как $\text{rg } A = r$, получаем: $\dim \text{Ker } \phi = n - r$.
Тогда сумма размерностей: $\dim \text{Im } \phi + \dim \text{Ker } \phi = r + (n - r) = n = \dim L$.
