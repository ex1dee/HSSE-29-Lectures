#### Подготовка к демонстрации

1. Зарегистрировать юзера
2. Подготовить запросы, разбить по в категориям (файлы, папки, юзеры)
3. Из авторизации сохранять accessToken в переменную {{token}}, refreshToken в {{refreshToken}}
4. Везде, где можно, указать теги
5. Для обычной загрузки подготовить картинку image.jpg
6. Для чанковой загрузки можно юзать файл book.txt, который я скинул

#### Сценарий

**(0-5 сек) Введение:**  
_"А теперь давайте посмотрим, как работает наше облачное хранилище на практике. Мы покажем полный цикл работы с файлами через PostMan."_

**1. (5-8 сек) Вход в систему**  
**`POST /api/users/auth/login`**  
_Заголовки:_

- `X-Auth-Email: user@example.com`
- `X-Auth-Password: password123`

_"Начинаем с авторизации — получаем access токен для доступа к API и refresh токен для обновления токенов"_

---

**2. (8-13 сек) Загрузка файла**  
**`POST /api/files/upload?path=/image.jpg`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`
- `X-File-Tags: <...>`

_"Загружаем картинку с тегами обычной загрузкой"_

---

**3. (13-21 сек) Потоковая загрузка большого файла**  
**`POST /api/files/upload?path=/book.txt`** 
_Заголовки:_

- `X-Auth-Token: {{token}}`
- `Transfer-Encoding: chunked`
- `X-File-Tags: <???>`

_"А вот ключевая фича –- потоковая загрузка. Большой файл разбивается на части и отправляется последовательно. Это позволяет обрабатывать большие файлы без их полной загрузки в память."_

(После выполнения запроса)
_"Видим ответ сервера: файл успешно принят, размер 13.8 МБ, частей 3"_ (проверить числа)

---

**4. (21-25 сек) Просмотр содержимого хранилища**  
**`GET /api/files/list`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`

_"Проверяем — оба файла успешно загружены и отображаются в списке."_

---

**5. (25-30 сек) Обновление метаданных файла**  
**`PUT /api/files?path=/image.jpg`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`
- `X-File-New-Path: /pictures/image.jpg`
- `X-File-Visibility: private`
- `X-File-Tags: <???>`


_"Теперь обновляем метаданные файла: переносим его в папку 'pictures', меняем видимость на private и обновляем теги."_

---

**6. (30-35 сек) Получение информации о файле**  
**`GET /api/files/info?path=/pictures/image.jpg`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`


_"Запрашиваем метаданные первого файла: видим, что они изменились"_

---

**7. (35-40 сек) Создание папки**  
**`PUT /api/directories?path=/library/`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`

_"Создаём папку 'library' для организации файлов."_

---

**8. (40-45 сек) Перемещение файла в папку**  
**`POST /api/directories?from=/book.txt&to=/library/book.txt`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`

_"Переносим добавленный ранее TXT-файл в созданную папку."_

---

**9. (45-52 сек) Потоковое скачивание**  
**`GET /api/files?path=/library/book.txt`**  
_Заголовки:_
- `X-Auth-Token: {{token}}`
- `X-Download-Mode: chunked`

_"А теперь скачиваем этот же файл в потоковом режиме. Используем наш заголовок X-Download-Mode — сервер отдаёт файл частями, что оптимально для больших объёмов."_

(После выполнения запроса)
_"Видим начало файла: первые строки текста. Файл корректно передаётся частями."_

---

**10. (52-56 сек) Просмотр содержимого папки**  
**`GET /api/files/list?directory=/library/**  
_Заголовки:_

- `X-Auth-Token: {{token}}`

_"Убеждаемся, что файл находится в папке 'library'."_

---

**11. (56-60 сек) Удаление файла**  
**`DELETE /api/files?path=/pictures/image.jpg`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`

_"Удаляем первый файл"_

---

**12. (60-63 сек) Удаление пустой папки**  
**`DELETE /api/directories?path=/library`**  
_Заголовки:_

- `X-Auth-Token: {{token}}`

_"Теперь удаляем папку 'library'."_

---

**13. (63-68 сек) Обновление токена**  
`POST /api/users/auth/refresh`  
_Заголовки:_

- `X-Refresh-Token: {{refreshToken}}`

_"И напоследок — ротация токенов. Используем refresh-токен для получения новой пары access/refresh токенов"_
