Между $u$ и $v$ орграфа $G$ есть **отношение двухсторонней достижимости**, 
если $\ \exists$ пути ($\iff$ маршруты) $u \to v$ и $v \to u$. Оно является *отношением эквивалентности*.

Классы эквивалентности относительно него — **компоненты сильной связности**.
Орграф называется **слабо связным**, если его неориентированная версия связна.

___

**Ациклический орграф** — орграф, в котором нет замкнутых маршрутов *положительной длины* (т.е. за исключением нулевой длины)

>**Лемма**
>Если орграф **ациклический**, то в нём есть вершина с **нулевой исходящей степенью**

*Доказательство:*
Рассмотрим путь наибольшей длины $v_{i_{1}}\to v_{i_{2}}\to\dots\to v_{i_{k}}$

Т.к. граф ациклический, то все $v_{i}$ различны.
Тогда $outdeg \ v_{i_{k}} = 0$, иначе можно добавить ребро, 
не совпадающее с предыдущими – противоречие максимальности длины

>**Следующие три условия эквивалентны**:
>1. Орграф $G$ (без петель) — ациклический
>2. Каждая компонента сильной связности имеет единичный размер
>3. $\ \exists$ нумерация вершин такая, что $(u_{i}, u_{j}) \in E \implies i < j$ 
>(**топологическая сортировка**)

*Доказательство:*
**(1)** $\iff$ **(2)** 
По определению

**(3)** $\implies$ **(1)**
Если бы существовал замкнутый маршрут, т.е. $v_{i_{1}} \to v_{i_{2}} \to \dots \to v_{i_{n}}=v_{i_{1}}$, то
$i_{1}<i_{2}<\dots<i_{n}=i_{1} \implies i_{1} < i_{1}$ – противоречие антирефлексивности

**(1)** $\implies$ **(3)**
Докажем индукцией по количеству вершин в $G$.

**База**: $|V| = 1$ 
Очевидно

**Шаг:** пусть утверждение выполняется для всех $G$ с $|V| \leq n$
Рассмотрим $G'$ – ациклический орграф с $|V| = n + 1$
По лемме выше есть вершина с нулевой исходящей степенью.
Сопоставим ей номер $n+1$ и удалим из графа.
Для оставшегося графа, по предположению индукции, 
есть нумерация $1,\dots,n$

>**Следствие**
>Любой частичный порядок можно дополнить до линейного

*Доказательство:*
Рассмотрим орграф частичного порядка $(M, \prec)$.
Он ациклический $\implies$ есть нумерация вершин.

Дополним заданное отношение $\prec$ до линейного
в соответствии с нумерацией и получим линейный порядок
на исходном множестве.
