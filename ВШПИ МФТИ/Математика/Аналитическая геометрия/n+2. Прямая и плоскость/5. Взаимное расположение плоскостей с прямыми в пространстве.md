>**Критерий параллельности вектора и плоскости**
>$П: Ax + By + Cz + D = 0 \parallel \bar{a}(\alpha + \beta+\gamma) \iff A\alpha+B\beta+C\gamma = 0$

*Доказательство*
Возьмём точку $M_{0}(x_{0}, y_{0}, z_{0})\in П$ с радиус-вектором $\bar{r}_{0}$.
Пусть $M_{1}(x_{0}+\alpha, y_{0}+\beta, z_{0}+\gamma)$
$\bar{a}\parallel П\iff M_{1}\in П$
$A(x_{0}+\alpha) + B(y_{0}+\beta) + C(z_{0}+\gamma) + D= 0$
$Ax_{0}+By_{0}+Cz_{0}+D + A\alpha+B\beta+C\gamma =0$
$Ax_{0} + By_{0}+Cz_{0}+D=0 \iff A\alpha+B\beta+C\gamma =0$

___

>**Критерий параллельности двух плоскостей**
>$П_{1}: A_{1}x + B_{1}y + C_{1}z + D_{1} = 0$ 
>$П_{2}:A_{2}x + B_{2}y + C_{2}z + D_{2} = 0$
>
>$П_{1} \ || \ П_{2} \iff (A_{1}, B_{1}, C_{1}) = \lambda(A_{2}, B_{2}, C_{2}), \lambda \neq 0  \text{ (т.е. нормали коллинеарны)}$
>$\iff [(A_{1}, B_{1}, C_{1}), (A_{2}, B_{2}, C_{2})] = 0$

___

>**Критерий совпадения плоскостей**
>$П_{1}: A_{1}x + B_{1}y + C_{1}z + D_{1} = 0$
>$П_{2}:A_{2}x + B_{2}y + C_{2}z + D_{2} = 0$
>
>$П_{1} = П_{2} \iff (A_{1}, B_{1}, C_{1}, D_{1}) = \lambda(A_{2}, B_{2}, C_{2}, D_{2}), \lambda \neq 0$

(**<=**) 
$A_{1}x+B_{1}y+C_{1}z+D = 0 \ (*), \ A_{1} = \lambda A_{2}, B_{1}=\lambda B_{2}, C_{1}=\lambda C_{2}, D_{1}=\lambda D_{2}$
Тогда $(*) \iff \lambda(A_{2}x + B_{2}y+C_{2}z+D_{2})=0 \implies$ т.к $\lambda\neq 0$, то $A_{2}x+B_{2}y+C_{2}z+D_{2}=0$
Т.е. множество решений $(x, y, z)$ для первой плоскости совпадает с множеством второй плоскости

(**=>**) 
$(A_{1}, B_{1}, C_{1}) = \lambda(A_{2}, B_{2}, C_{2})$, т.к. $П_{1} \parallel П_{2}$

Возьмём точку $P(x_{0}, y_{0},z_{0}) \in П_{1}=П_{2}$
$A_{1}x_{0}+B_{1}y_{0}+C_{1}z+D_{1} = 0, A_{2}x_{0}+B_{2}y_{0}+C_{2}z+D_{2} = 0$

Тогда $A_{1}x_{0}+B_{1}y_{0}+C_{1}z+D_{1} - \lambda(A_{2}x_{0} + B_{2}y_{0} + C_{2}z+D_{2}) = 0$
$(A_{1}-\lambda A_{2})x_{0} + (B_{1} - \lambda B_{2})y_{0} + (C_{1}-\lambda C_{2})z_{0} + D_{1}-\lambda D_{2} = 0$, 
но $A_{1}=\lambda A_{2}, B_{1}=\lambda B_{2}, C_{1}=\lambda C_{2} \implies D_{1}=\lambda D_{2}$ 

Итого: $(A_{1}, B_{1}, C_{1}, D_{1}) = \lambda(A_{2}, B_{2}, C_{2}, D_{2})$
