## 1. Идея и процесс поиска

Процесс заключается в поиске дополняющего пути. Если путь найден, выполняется симметрическая разность (инверсия ребер вдоль пути), что увеличивает размер паросочетания ровно на 1.

В базовом виде алгоритм выглядит так:

```cpp
while (есть дополняющий путь) {
    найти дополняющий путь P;
    M = M Δ P; // инвертировать ребра на пути
}
```

Для двудольных графов процесс упрощается: достаточно один раз перебрать все вершины левой доли и для каждой попытаться найти дополняющий путь.

---

## 2. Реализация

**Функция поиска в глубину (DFS)**

DFS пытается найти дополняющий путь, начиная с вершины $v$ (`true`, если удалось). Если соседняя вершина $u$ свободна или если можно перенаправить вершину, с которой $u$ уже в паре, путь считается найденным.
- `p[u]` — массив, хранящий для вершины правой доли индекс соответствующей ей вершины из левой доли.

```python
def dfs(v):
    if used[v]:
        return False
    used[v] = True
    for u in adj[v]: # для всех соседей u вершины v
        # если u свободна ИЛИ можем найти доп. путь из той вершины, что уже в паре с u
        if p[u] == -1 or dfs(p[u]):
            p[u] = v # теперь v в паре с u
            return True
    return False
```


**Главный цикл**

```cpp
for (int v = 0; v < n; v++) { // итерируемся по левой доле
    fill(used, 0); // сброс посещений для каждого нового поиска
    if (dfs(v)) {
        ans++; // размер паросочетания
    }
}
```

**Асимптотика**: **$O(V \cdot (V + E))$**
