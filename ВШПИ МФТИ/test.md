##### next/prev
Рассмотрим *next*, *prev* рассматривается аналогично
На вход поступает нода $node$ и значение $value$.
Нужно найти максимальное значение ноды, меньшее $value$

Алгоритм таков (начинаем с $next(root, value)$):
1. Если $node = null$, то возвращаем $null$
2. Если $node.value \leq value$, то искомое число точно находится в правом ребенке $node$. Вызываем $next(node.right, value)$
3. Иначе, имеет смысл искать его в левом ребёнке $node$
Вызываем $next(node.left, value)$. Получаем кандидата на искомое число.
**a.** Если получили не $null$, то возвращаем кандидата.
**b.** Иначе, искомого числа в дереве нет

Т.к. на каждом вызове мы спускаемся по одному из поддеревьев, то асимптотика $O(\log n)$

##### kthStatistics
Нужно найти $k$-е по величине значение в дереве.
Для этого будем хранить в каждой ноде $node$ поле $size$ – размер поддерева с корнем в $node$

Алгоритм таков (начинаем с $kthStatistics(root, k)$):
1. Если $node = null$, то возвращаем $null$
2. Записываем $leftSize = getSize(node.left)$
3. Если $k < leftSize$, то искомое значение лежит в левом ребёнке $node$.
Вызываем $kthStatistics(node.left, k)$
4. Если $k > leftSize$, то искомое значение лежит в правом ребёнке $node$.
$k$-е по величине значение во всём дереве
является $k-leftSize-1$ по величине значением в правом ребёнке 
Вызываем $kthStatistics(node.right, k - leftSize- 1)$
5. Если $k=leftSize$, то мы победили

Т.к. на каждом вызове мы спускаемся по одному из поддеревьев, то асимптотика $O(\log n)$
