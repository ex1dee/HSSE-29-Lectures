- Пусть $X$ — абстрактное множество, $X \neq \emptyset$. Пусть $\forall n \in \mathbb{N}$ определено отображение $f_n : X \to \mathbb{R}$. Тогда говорим, что определена **функциональная последовательность** $\{f_n\}_{n=1}^{\infty}$
- Будем говорить, что последовательность $\{f_n\}$ **сходится поточечно** на множестве $X$, если:
    
    $$\forall x \in X \ \exists \lim_{n \to \infty} f_n(x) \in \mathbb{R} \ (=: f(x))$$
    
    $$\iff \forall x \in X \ \forall \varepsilon > 0 \ \exists N(x, \varepsilon) \in \mathbb{N} : \forall n \ge N(x, \varepsilon) \to |f(x) - f_n(x)| < \varepsilon$$
    
    (Последовательность $\{f_n\}$ при этом называется поточечно сходящейся к $f$ и обозначается $f_n \xrightarrow{X} f, n \to \infty$).
    
- Пусть $\{f_n\}_{n=1}^{\infty}$ — функциональная последовательность (все функции определены на $X$). Пусть $f : X \to \mathbb{R}$. Будем говорить, что $f_n \rightrightarrows_X f, n \to \infty$ (**последовательность $\{f_n\}$ равномерно сходится к $f$ на $X$**), если:
    
    $$\forall \varepsilon > 0 \ \exists N(\varepsilon) \in \mathbb{N} : \forall n \ge N(\varepsilon) \text{ и } \forall x \in X \to |f(x) - f_n(x)| < \varepsilon$$

___


> [!NOTE] **Примечание**
> 
> Если $f_n \rightrightarrows_X f$, то $f_n \xrightarrow{X} f$. Для доказательства достаточно $\forall \varepsilon > 0 \ \forall x \in X$ взять $N(x, \varepsilon) = N(\varepsilon)$.
> 
> Обратное, вообще говоря, неверно. Отрицание равномерной сходимости:
> 
> $$\exists \varepsilon > 0 : \forall N \in \mathbb{N} \ \exists n \ge N \text{ и } \exists x \in X \text{ т. ч. } |f_n(x) - f(x)| \ge \varepsilon$$

> [!EXAMPLE] **Пример**
> 
> $f_n(x) = x^n$ на $X = [0, 1]$.
> 
> Предельная функция:
> 
> $$f(x) = \begin{cases} 0, & x \in [0, 1) \\ 1, & x = 1 \end{cases}$$
> 
> Проверим равномерную сходимость. Возьмём $\varepsilon = \frac{1}{2}$. Тогда $\forall N \in \mathbb{N}$ выберем $n = N$ и точку $x_N = \left( \frac{1}{2} \right)^{1/N}$.
> 
> Тогда $|f_N(x_N) - f(x_N)| = |( (\frac{1}{2})^{1/N} )^N - 0| = \frac{1}{2} \ge \varepsilon$.
> 
> Следовательно, $x^n \not\rightrightarrows_{[0, 1]} f, n \to \infty$.
> 
> Однако $\forall x \in [0, 1] \to \exists \lim_{n \to \infty} x^n = f(x)$, то есть имеет место поточечная сходимость.
