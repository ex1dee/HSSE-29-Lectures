## 1. **Область применимости**

Дерево отрезков — структура данных для работы с **ассоциативными операциями** на массиве с возможностью:

- **Быстрого запроса** на любом отрезке: **O(log N)**
    
- **Быстрого обновления** в точке: **O(log N)**
    

### Требования к операции:

1. **Ассоциативность**: `op(op(a,b), c) = op(a, op(b, c))`
    
2. **Нейтральный элемент**: `op(a, neutral) = a`
    

### Примеры операций:

- **Сумма** (нейтральный 0)
    
- **Произведение** (нейтральный 1)
    
- **Минимум/максимум** (нейтральный ±∞)
    
- **GCD** (обычно нейтральный 0)
	
- **LCM** (обычно нейтральный 1)
	
- **Логические операции** (AND, OR, XOR)
    

### Отличие от Sparse Table:

- **Поддерживает изменения** данных
    
- **Медленнее** на запрос (log N вместо O(1))
    
- **Меньше памяти** (O(N) против O(N log N))
    

---

## 2. **Построение**

### Основная идея:

Каждый узел дерева хранит результат операции на некотором отрезке.

### Структура дерева:

- **Корень**: весь массив `[0, N-1]`
    
- **Дети**: делят отрезок родителя пополам
    
- **Листья**: отрезки длины 1 (отдельные элементы)
    

### Алгоритм построения (снизу вверх):

1. **Подготавливаем массив**:
    
    - Если N не степень двойки, дополняем нейтральными элементами
        
    - `size = 2^k` – первая степень двойки $\geq N$ (размер ДО = `2*size`)
        
2. **Заполняем листья** (последние N элементов массива `t`):
    
    ```text
    t[size-1 ... size-1+N-1] = исходный массив
    t[size-1+N ... 2*size-1] = нейтральный элемент
    ```
    
1. **Заполняем внутренние узлы** (с конца):
`t[узел] = op(t[левый ребёнок], t[правый ребёнок])`

    
    ```cpp
    for (int i = size-2; i >= 0; i--) {
        t[i] = op(t[2*i + 1], t[2*i + 2]);
    }
    ```

## 3. **Ответ на запрос**

### Алгоритм (рекурсивный):

Запрос на отрезке `[L, R]` в узле с отрезком `[l, r]`:

1. **Если отрезки не пересекаются**: вернуть нейтральный элемент
    
2. **Если текущий отрезок `[l, r]` полностью внутри `[L, R]`**: вернуть значение узла
    
3. **Иначе**: рекурсивно спуститься в оба ребенка и применить операцию к результатам
    
### Почему работает за O(log N):

- На каждом уровне дерева "активными" могут быть не более **4 узлов**
    
- Глубина дерева = **`⌈log₂(N)⌉`** (т.к. ДО — полное бинарное дерево)
    

---

## 4. **Изменение в точке**

### Алгоритм:

1. Находим лист, соответствующий индексу `i`
    
2. Обновляем значение в листе
    
3. Поднимаемся к корню, пересчитывая значения родителей
    

### Код:

```cpp
void update_point(int i, T new_val) {
    i += size - 1;  // переход к листу
    t[i] = new_val;
    
    // Поднимаемся к корню
    while (i > 0) {
        i = (i - 1) / 2;  // родитель
        t[i] = op(t[2*i+1], t[2*i+2]);
    }
}
```

**Сложность**: O(log N)

## 5. **Поддержка группового обновления на подотрезке**

Для операций, которые можно применять **ко всему подотрезку сразу**:

### Требования к операции:

1. **Ассоциативность**: `ch(a, ch(b, c)) = ch(ch(a, b), c)`
    
2. **Дистрибутивность** относительно операции `op`:
    `ch(op(a, b), c) = op(ch(a, c), ch(b, c))`
3. **Нейтральный элемент** для `ch`
    

### Примеры:

1. **Прибавление константы** ко всем элементам отрезка
    
2. **Присваивание значения** всем элементам отрезка, например, относительно минимума
    
3. **Умножение на константу**
    
4. **Побитовые операции** (AND, OR, XOR с константой)
### Инициализация:

```cpp
// При построении
for (int i = 0; i < 2*size; i++) {
    t[i] = neutral;  // для операции запроса
    d[i] = neutral_ch;  // для операции изменения
}
```

### **Построение**

Аналогично обычному дереву отрезков, но добавляем 
массив `d[]` для **отложенных изменений** (lazy values):
- `d[node]` — отложенное изменение, которое еще не применено к детям

### Ключевая идея: **Ленивое распространение (Lazy propagation)**

- Не обновляем все элементы сразу
    
- "Запоминаем" операцию в узле
    
- При необходимости "проталкиваем" в детей
    

### Алгоритм `push(node)`:

```cpp
void push(int node) {
    // Применяем отложенное изменение к детям
    if (d[node] != neutral_ch) {
        // Левый ребенок
        t[2*node+1] = ch(t[2*node+1], d[node]);
        d[2*node+1] = ch(d[2*node+1], d[node]);
        
        // Правый ребенок
        t[2*node+2] = ch(t[2*node+2], d[node]);
        d[2*node+2] = ch(d[2*node+2], d[node]);
        
        // Сбрасываем отложенное изменение
        d[node] = neutral_ch;
    }
}
```

### Алгоритм обновления на отрезке:

```cpp
void update_range(int node, int l, int r, int L, int R, T val) {
    // [l, r] - отрезок текущего узла
    // [L, R] - обновляемый отрезок
    // val - значение для операции ch
    
    if (r < L || R < l) return;  // не пересекаются
    
    if (L <= l && r <= R) {
        // Весь отрезок попадает в обновление
        t[node] = ch(t[node], val);
        d[node] = ch(d[node], val);
        return;
    }
    
    // Проталкиваем отложенное изменение
    push(node);
    
    int mid = (l + r) / 2;
    update_range(2*node+1, l, mid, L, R, val);
    update_range(2*node+2, mid+1, r, L, R, val);
    
    t[node] = op(t[2*node+1], t[2*node+2]);
}
```

### **Ответ на запрос**

```cpp
T query_range(int node, int l, int r, int L, int R) {
    if (r < L || R < l) return neutral;
    
    if (L <= l && r <= R) return t[node];
    
    // Важно: проталкиваем перед спуском к детям!
    push(node);
    
    int mid = (l + r) / 2;
    return op(query_range(2*node+1, l, mid, L, R),
              query_range(2*node+2, mid+1, r, L, R));
}
```

### **Изменение в точке**

#### Вариант 1: Через обновление на отрезке длины 1

```cpp
update_range(0, 0, N-1, i, i, val);
```

#### Вариант 2: Специализированная функция

```cpp
void update_point(int node, int l, int r, int idx, T val) {
    if (l == r) {
        t[node] = ch(t[node], val);
        return;
    }
    
    push(node);  // все равно нужно push!
    
    int mid = (l + r) / 2;
    if (idx <= mid)
        update_point(2*node+1, l, mid, idx, val);
    else
        update_point(2*node+2, mid+1, r, idx, val);
    
    t[node] = op(t[2*node+1], t[2*node+2]);
}
```
