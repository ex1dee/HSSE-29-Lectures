## 1. Особенности типизации

Python — это язык с **динамической** и **неявной** типизацией.

- **Динамическая:** Тип переменной определяется в момент присваивания значения, а не при объявлении. Одну и ту же переменную можно переназначить с `int` на `str`.
    
- **Неявная:** Вам не нужно вручную указывать тип (например, `int x = 5`). Интерпретатор понимает это сам.
    

___

## 2. Выражения, операторы и переменные

- **Переменная** — это ссылка на объект в памяти.
    
- **Операторы:** Арифметические (`+`, `-`, `*`, `/`, `//`, `%`, `**`), сравнения (`==`, `!=`, `>`, `<`) и логические (`and`, `or`, `not`).
    
- **Выражение** — комбинация операндов и операторов, которая вычисляется в конкретное значение.
    

---

## 3. Паттерн Singleton (Одиночка) в Python

Синглтон — это объект, который существует в системе в единственном экземпляре. В Python есть встроенные объекты-синглтоны, которые используются повсеместно:

- **`None`:** Обозначает отсутствие значения. Все переменные, которым присвоено `None`, ссылаются на один и тот же объект в памяти.
    
- **`NotImplemented`:** Специальное значение, которое возвращают методы сравнения (например, `__eq__`), если они не знают, как сравнить объект с данным типом.
    
- **`Ellipsis` (`...`):** Часто используется в срезах (numpy) или как заглушка в коде вместо `pass`.

## 4. Числовые типы и приведение типов

В Python три основных числовых типа:

1. **`int`**: Целые числа произвольной точности (ограничены только вашей оперативной памятью).
    
2. **`float`**: Числа с плавающей точкой (аналог `double` в C).
    
3. **`complex`**: Комплексные числа (вид: `1 + 2j`).
    

**Приведение типов (Casting):** Для явного преобразования используются функции-конструкторы: `int()`, `float()`, `str()`, `bool()`.

## 5. Логический тип (bool) и функции проверки

Тип `bool` имеет два значения: `True` и `False`.

> **Важно:** В Python многие объекты имеют встроенное «логическое» значение. Например, `0`, `[]`, `{}`, `""`, `None` — это `False`, всё остальное — `True`.

### Функции `any()` и `all()`

Работают с итерируемыми объектами (списками, кортежами):

- **`all(iterable)`**: Возвращает `True`, если **все** элементы истинны.
    
- **`any(iterable)`**: Возвращает `True`, если **хотя бы один** элемент истинен.

## 6. Строки (`str`)

Строки в Python — это **неизменяемые** последовательности символов Unicode.

- **Методы:** `.upper()`, `.lower()`, `.split()`, `.join()`, `.strip()`.
    
- **Форматирование:** f-строки (наиболее современный способ): `f"Результат: {variable}"`.

## 7. Базовые коллекции

### Списки (`list`)

Упорядоченные, **изменяемые** коллекции. Могут хранить элементы разных типов.

- Создание: `my_list = [1, "apple", 3.14]`
    
- Добавление: `.append(x)`, `.extend(list2)`
    
- Удаление: `.pop()`, `.remove(value)`
    

### Словари (`dict`)

Неупорядоченные (с версии 3.7 сохраняют порядок вставки) коллекции пар **ключ: значение**.

- Ключом может быть только **неизменяемый (hashable)** тип (число, строка, кортеж).
    
- Создание: `my_dict = {"name": "Alice", "age": 25}`
    
- Доступ: `my_dict["name"]` или `.get("name")` (безопасный способ).

### Кортежи (`tuple`)

Это **неизменяемый** (immutable) аналог списка.

- **Синтаксис:** `my_tuple = (1, 2, "три")`.
    
- **Зачем они нужны?**
    
    1. **Безопасность:** Ты гарантируешь, что данные не изменятся случайно (например, координаты GPS или настройки).
        
    2. **Скорость:** Они чуть быстрее списков и занимают меньше памяти.
        
    3. **Ключи словарей:** Только неизменяемые типы могут быть ключами в `dict`. Список ключом быть не может, а кортеж — может.
        

### Множества (`set`)

Это неупорядоченная коллекция **уникальных** элементов.

    
- **Синтаксис:** `my_set = {1, 2, 3, 3, 3}` -> в итоге останется `{1, 2, 3}`.
    
- **Операции:** Поддерживают математические операции: объединение (`|`), пересечение (`&`), разность (`-`).
