Грамматика $G$ — это набор из четырех множеств $(N, T, P, S)$, где:

- $N$ — алфавит нетерминальных символов
    
- $T$ — алфавит терминальных символов (символы из алфавита формального языка), $T \cap N = \emptyset$
    
- $P$ — конечное множество правил вида $\alpha \to \beta$, где $\alpha \in (N \cup T)^*N(N \cup T)^*$, $\beta \in (N \cup T)^*$
    
- $S \in N$ — начальный знак (аксиома) грамматики
    

___

> [!INFO] **Теорема**
> 
> Пусть $\Sigma$ — алфавит. Тогда имеем $2^{\Sigma^*}$ языков, заданных над ним. $\text{REG} \subset 2^{\Sigma^*}$. Каждый регулярный язык может быть записан через:
> 
> 1. регулярные выражения
>     
> 2. НКА
>     
> 3. ДКА
>     
> 4. грамматику
>     
> 
> Причём из одной формы записи мы всегда можем получить другую.

___

По заданному НКА для каждого $q$ определим правый язык:

$$R_q := \{x \mid q \xrightarrow{x} q_f, q_f \in Q_f\}$$

То есть все слова, считывая которые, можно попасть из состояния $q$ в одно из финальных состояний.

> [!NOTE]
> 
> Именно правые языки мы будем использовать в качестве переменных при составлении системы. Если отбросить строгие определения, то $R$ — это переменная, которая обозначает «остаток пути до финиша»:
> 
> $$R_{\text{где я стою}} = \text{Буква на стрелке} \cdot R_{\text{куда эта стрелка ведет}}$$
> 
> Если из состояния выходит несколько стрелок, мы просто складываем их через плюс ($+$). Если состояние является финальным, мы в самом конце строки дописываем $+\varepsilon$ (это значит «мы можем закончить путь прямо здесь»).

> [!EXAMPLE] **Пример**
> 
> Согласно алгоритму:
> 
> $$R_0 = a(bR_0 + \varepsilon) = abR_0 + a$$

**Обоснование примера**

Применяя [[5. Построение РВ по НКА|лемму Ардена]] (решение уравнения $X = AX + B$ в виде $X = A^*B$), из полученного соотношения находим искомое регулярное выражение для языка:

$$R_0 = (ab)^*a$$
