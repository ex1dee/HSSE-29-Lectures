### **1. Определение. Теорема о высоте**

#### **1. Определение**

**AVL-дерево** — это **самобалансирующееся бинарное дерево поиска (БДП)**, предложенное **Адельсон-Вельским и Ландисом (1962 г.)**.

**Основное свойство (инвариант AVL):** Для **каждой** вершины дерева высота её левого и правого поддеревьев отличаются не более чем на 1.

- `|height(left) - height(right)| <= 1`
    
- Это свойство должно выполняться **после каждой операции** модификации дерева (вставка, удаление).
    

**Высота поддерева** (`height`) обычно определяется как длина **самого длинного** пути от данной вершины до листа (глубина). Высота пустого поддерева (`nullptr`) чаще всего принимается равной `-1` или `0` (в лекции, судя по формуле `S(0)=0`, используется высота пустого = 0). Важно быть последовательным.

**Цель:** Гарантировать, что высота дерева с `n` узлами есть `O(log n)`, что обеспечивает эффективность операций `Find`, `Insert`, `Erase` за `O(log n)` в худшем случае.

#### **2. Теорема о высоте AVL-дерева**

**Утверждение:** Высота `h` AVL-дерева с `n` узлами равна `O(log n)`.

**Доказательство (логика через минимальное число узлов):**

1. Введем функцию `S(h)` — **минимальное** количество узлов в AVL-дереве высоты `h`.
    
2. Чтобы построить AVL-дерево **минимального размера** для высоты `h`, нужно:
    
    - Взять корень (1 узел).
        
    - Сделать одно из его поддеревьев AVL-деревом высоты `h-1` (чтобы достичь высоты `h`).
        
    - Второе поддерево, чтобы соблюсти баланс (`|Δh| <= 1`), может быть высотой **не меньше** `h-2`.
        
    - И чтобы общее число узлов было **минимальным**, второе поддерево должно быть **минимальным AVL-деревом высоты `h-2`**.
        
3. Получаем **рекуррентное соотношение**:  
    `S(h) = S(h-1) + S(h-2) + 1`, где `S(0) = 0` (пустое дерево), `S(1) = 1` (один узел).
    
4. По индукции `S(h) = F_{h+2} - 1`, где `F_k` — `k`-ое число Фибоначчи (`F_1=1, F_2=1` или `F_0=0, F_1=1` в зависимости от определения)
	`S(0) = 0 = F_2 - 1, S(1) = 1 = F_3 - 1`
	`S(h + 1) = S(h) + S(h - 1) + 1 = F_{h+2} + F_{h+1} - 2 + 1 = F_{h+3} - 1`
    
5. **Формула Бине** (без доказательства) для чисел Фибоначчи:  
    `F_n = (φ^n - ψ^n) / √5`, где `φ = (1+√5)/2 ≈ 1.618` (золотое сечение), `ψ = (1-√5)/2 ≈ -0.618`.
    
6. Главный член асимптотики: `F_n ∼ φ^n / √5`. Следовательно, `S(h) ∼ φ^{h+2} / √5`.
    
7. Для AVL-дерева с `n` узлами верно: `n >= S(h)`. Поэтому:  
    `n >= C * φ^h` (где `C` — константа).  
    Логарифмируя по основанию `φ`: `h <= log_φ(n) + C'`.  
    Следовательно, `h = O(log n)`.
    

**Итог:** Высота AVL-дерева **логарифмически** зависит от числа узлов, что гарантирует эффективность операций.

### **2. Повороты и балансировка. Основные операции**

#### **1. Коэффициент балансировки (Balance Factor, BF)**

Для удобства вводится величина:  
`BF(node) = height(right) - height(left)` или наоборот (зависит от реализации).  
В сбалансированной вершине: `BF ∈ {-1, 0, 1}`.  
Нарушение баланса: `|BF| = 2`.

#### **2. Повороты (вращения)**

Повороты — это локальные операции перестройки дерева, которые **сохраняют свойство БДП** (порядок ключей) и **восстанавливают баланс** (приводят `|BF|` к допустимым значениям).

Существует **4 основных случая** нарушения баланса, требующих поворотов:

**Случай 1: Малое правое вращение (Right Rotation)**

- **Ситуация:** Несбалансированная вершина `A`. Её **левое** поддерево выше (`BF(A) = -2`). У **левого** ребенка `B` **левый** же потомок тоже выше или равен (`BF(B) <= 0`). Это **"Left-Left"** случай.
    
- **Действие:** "Поднимаем" `B` на место `A`, делаем `A` правым ребенком `B`, а исходное правое поддерево `B` (`T2`) — левым поддеревом `A`.
    
- **Результат:**
	До: `h(A)=h`, `h(B)=h-1`, `h(T1)=h-2`, `h(T2)=h-2 или h-3`, `h(T3)=h-3`
	После: `h(B)=h-1`, `h(A)=max(h(T2), h(T3)) + 1 = max(h-2, h-3) + 1 = (h-2) + 1 = h-1`, `h(T1)=h-2`, `h(T2)=h-2 или h-3`, `h(T3)=h-3`

```text
     A (BF=-2)          B
    / \                / \
   B   T3    -->      T1  A
  / \                    / \
 T1  T2                T2  T3
(BF<=0)
```

**Случай 2: Малое левое вращение (Left Rotation)**

- **Ситуация:** Зеркальна случаю 1. `BF(A) = +2`, у правого ребенка `B` `BF(B) >= 0` (**"Right-Right"**).
    
- **Действие:** "Поднимаем" `B`, делаем `A` его левым ребенком, а исходное левое поддерево `B` — правым поддеревом `A`.
- **Результат:**
	До: `h(A)=h`, `h(B)=h-1`, `h(T1)=h-3`, `h(T2)=h-2 или h-3`, `h(T3)=h-2`
	После: `h(B)=h-1`, `h(A)=h-2`, `h(T1)=h-3`, `h(T2)=h-2 или h-3`, `h(T3)=h-2`

```text
  A (BF=+2)              B
 / \                    / \
T1  B        -->       A  T3
   / \                / \
  T2  T3            T1  T2
 (BF>=0)
```

**Случай 3: Большое правое вращение (Right-Left Rotation)**

- **Ситуация:** Несбалансированная вершина `A` (`BF = -2`). У её левого ребенка `B` **правое** поддерево выше (`BF(B) = +1`)
    
- **Действие:** Два шага:
    
    1. **Левое вращение** вокруг `B`
        
    2. **Правое вращение** вокруг `A`.
        
- **Ключевая фигура:** Внук `C` (правый ребенок `B`) становится новым локальным корнем.
- **Результат:**
    До: `h(A)=h`, `h(B)=h-1`, `h(C)=h-2`, `h(T1)=h-3`, `h(T2)=h-3 или h-4`, `h(T3)=h-3`, `h(T4)=h-2`
	После: `h(C)=h-1`, `h(B)=h-2`, `h(A)=h-2`, `h(T1)=h-3`, `h(T2)=h-3 или h-4`, `h(T3)=h-3`, `h(T4)=h-2`

```text
     A                  A                  C
    / \                / \                / \
   B   T4   Лев(B)    C   T4   Прав(A)   B   A
  / \       --->     / \       --->    /  \  / \
 T1  C              B  T3             T1 T2 T3 T4
    / \            / \
   T2 T3          T1 T2
```

**Случай 4: Большое левое вращение (Left-Right Rotation)**

- **Ситуация:** Зеркальна случаю 3. `BF(A) = +2`, у правого ребенка `B` `BF(B) = -1` (**"Right-Left"**).
    
- **Действие:**
    
    1. Правое вращение вокруг `B`.
        
    2. Левое вращение вокруг `A`.
- **Результат:**
	До: `h(A)=h`, `h(B)=h-1`, `h(C)=h-2`, `h(T1)=h-2`, `h(T2)=h-3`, `h(T3)=h-3 или h-4`, `h(T4)=h-3`
	После: `h(C)=h-1`, `h(A)=h-2`, `h(B)=h-2`, `h(T1)=h-2`, `h(T2)=h-3`, `h(T3)=h-3 или h-4`, `h(T4)=h-3`
#### **3. Балансировка (процедура восстановления AVL-свойства)**

После **вставки** или **удаления** баланс может нарушиться (`|BF| = 2`) в некоторых вершинах на пути от измененной вершины к корню.

1. **Начинаем** с родителя измененного узла (или с самого узла при удалении) и идём **вверх к корню**.
    
2. Для **каждой** вершины `P` на этом пути:
    
    - Пересчитываем её высоту `height(P)` (как `max(height(left), height(right)) + 1`).
        
    - Вычисляем `BF(P)`.
        
    - Если `|BF(P)| = 2` — выполняем **нужный поворот** (один из 4-х), чтобы сбалансировать `P`.
        
    - После поворта **пересчитываем высоты** для затронутых вершин (`A`, `B`, `C` в схемах выше).
        
3. **Остановка:** Можно прекратить подъём, когда высота текущей вершины **после балансировки** **не изменилась** по сравнению с её высотой до операции (значит, вышележащие узлы не затронуты).

#### **4. Основные операции**

Все операции (Find, Insert, Erase) сначала выполняют стандартные действия, как в наивном БДП, а затем, если это не поиск, **балансировку**.

**Итоговая гарантия:** AVL-дерево обеспечивает все операции за `O(log n)` в худшем случае благодаря поддержанию логарифмической высоты.
