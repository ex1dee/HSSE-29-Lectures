Сортируем рёбра на основании весов. Проходимся по отсортированному списку и пытаемся добавить ребро. Если ребро не образует цикл, добавляем в остов.

### Система непересекающихся множеств (DSU)

Это структура данных, которая позволяет эффективно управлять разделением элементов на множества, не имеющие общих элементов.

- Изначально $n$ множеств из одного элемента.
    
- При расширении множеств строим ориентированные деревья.
    
- Корень — лидер множества.
    

```java
int get_leader(int v) {
    if (p[v] == -1)
        return v;
    return get_leader(p[v]);
}
```

- `p[v]` — родитель $v$, `p[v] = -1`, если $v$ — лидер.
- `size[v]` — количество элементов в дереве с корнем $v$. Используется только для лидеров.

> [!TIP] Ранговая эвристика
> 
> Подвешиваем меньшее дерево к большему для оптимизации высоты.
> 
> ```java
> void merge(int a, int b) {
>     a = get_leader(a);
>     b = get_leader(b); // a != b
>     
>     if (size[a] > size[b])
>         swap(a, b);
>     size[b] += size[a];
>     p[a] = b;
> }
> ```
> 
> Так как размер нового дерева $size[c] \geq 2 \cdot size[a]$, где $a$ — подклеиваемое дерево. Каждый раз, когда высота пути от вершины до корня увеличивается на **1**, размер дерева, в котором она находится, как минимум **удваивается**. Соответственно, при таком подходе высота дерева не превышает $\log n \implies$ все операции (get_leader и merge) с этой структурой данных работают за $O(\log n)$.

> [!TIP] Эвристика сжатия путей
> 
> Пусть все вершины на пути переподвешиваются напрямую к лидеру при вызове функции.
> 
> ```java
> int get_leader(int v) {
>     if (p[v] == -1)
>         return v;
>     return p[v] = get_leader(p[v]);
> }
> ```

---

> [!INFO] **Теорема (об асимптотике СНМ)**
> 
> Если применить обе эвристики (ранговую и сжатия путей), то асимптотика операций СНМ становится практически константной и равна $O(\alpha(n))$, где $\alpha$ — обратная функция Аккермана.

> [!NOTE] Примечание
> 
> Функция Аккермана растёт чрезвычайно быстро:
> 
> $$A(m, n) = \begin{cases} n+1, & m=0 \\ A(m-1, 1), & m>0, n=0 \\ A(m-1, A(m, n-1)), & m>0, n>0 \end{cases}$$
> 
> Например, $A(4, 4) = 2^{2^{65536}} - 3$. Обратная функция Аккермана $\alpha(n) = \min \{k : A(k, k) \geq n\}$ растёт очень медленно (для всех практических значений $n$ она не превышает 4-5).

---

### Алгоритм Крускала

1. Сортируем все рёбра графа по весу.
    
2. Инициализируем СНМ, где каждая вершина в своем множестве.
    
3. Проходим по отсортированному списку рёбер $(u, v)$:
    
    - Если `get_leader(u) != get_leader(v)`, добавляем ребро в MST и вызываем `merge(u, v)`.
        

**Асимптотика:**

$$O(m \log m + m \cdot \alpha(n))$$

где $m \log m$ — время сортировки рёбер, а $m \cdot \alpha(n)$ — работа с СНМ.
