**Определения:**
- Отображение $f: X \to X$ называется **преобразованием**
- Преобразование $f:(x, y) \to (x', y')$ назовём **линейным**, если существует декартовая система координат, в которой оно задаётся формулами $\begin{cases} x' = a_{1}x+b_{1}y+c_{1} \\ y' = a_{2}x+b_{2}y+c_{2} \end{cases}$
- Взаимнооднозначное линейное преобразование назовём **аффинным**

___

>**Теорема**
>Линейное преобразование аффинно $\iff$ $\Delta= \begin{vmatrix} a_{1}&b_{1} \\ a_{2}&b_{2} \end{vmatrix} \neq 0$

*Доказательство:*
По теореме Крамера система $\begin{cases} x' = a_{1}x+b_{1}y+c_{1} \\ y' = a_{2}x+b_{2}y+c_{2} \end{cases}$ имеет решение $(x, y)$ $\iff \begin{vmatrix} a_{1}&b_{1} \\ a_{2}&b_{2} \end{vmatrix} \neq 0$

___

>**Теорема**
>В любой декартовой системе координат линейное преобразование 
>задаётся формулами вида $\begin{cases} x' = a_{1}x+b_{1}y+c_{1} \\ y' = a_{2}x+b_{2}y+c_{2} \end{cases} \ (1)$

*Доказательство:*
Рассмотрим системы координат:
- Старая: $O, \bar{e}_{2}, \bar{e}_{2}$ 
- Новая: $O^*, \bar{e}^*_{1}, \bar{e}^*_{2}$

Переход от новой системы к старой:
$\begin{cases}x = \alpha_{1} x^* + \beta_{1} y^* + \gamma_{1}  \\ y=\alpha_{2} x^* + \beta_{2} y^* + \gamma_{2}\end{cases} \ (2)$

Обратный переход (от старой к новой):
$\begin{cases}x^* = \hat{\alpha}_{1} x + \hat{\beta}_{2} y + \hat{\gamma}_{1}  \\ y^*=\hat{\alpha}_{2} x + \hat{\beta}_{2} y + \hat{\gamma}_{2}\end{cases} \ (3)$

Рассмотрим произвольную точку $(x^*, y^*)$
Переводим её координаты в старую по $(2)$
В старой системе применяем преобразование $f$ по $(1)$

Получаем:
$\begin{cases} x' = a_{1}(\alpha_{1} x^* + \beta_{1}y^* + \gamma_{1}) + b_{1}(\alpha_{2}x^* + \beta_{2}y^* + \gamma_{2}) + c_{1}  \\ y' = a_{2}(\alpha_{1} x^* + \beta_{1}y^* + \gamma_{1}) + b_{2}(\alpha_{2}x^* + \beta_{2}y^* + \gamma_{2}) + c_{1} \end{cases}$

Приведём подобные:
$\begin{cases} x' = (a_{1}\alpha_{1} + b_{1}\alpha_{2})x^* + (a_{1}\beta_{1} + b_{1}\beta_{2})y^* + (a_{1}\gamma_{1} + b_{1}\gamma_{2} + c_{1})  \\ y' = (a_{2}\alpha_{1} + b_{2}\alpha_{2})x^* + (a_{2}\beta_{1} + b_{2}\beta_{2})y^* + (a_{2}\gamma_{1} + b_{2}\gamma_{2} + c_{2}) \end{cases}$

Обозначим коэффициенты так:
$\begin{cases} x' = P_{1}x^* + Q_{1}y^* + R_{1}  \\ y' = P_{2}x^* + Q_{2}y^* + R_{2} \end{cases}$

Теперь переведём координаты $(x', y')$ обратно в новую по $(3)$
После подстановки, группировки слагаемых и переобозначения коэффициентов получаем:
$\begin{cases}x'^* = A_{1} x' + B_{2} y' + C_{1}  \\ y'^*=A_{2} x' + B_{2} y' + C_{2}\end{cases}$

Таким образом, линейное преобразование в любой 
декартовой системе координат сохраняет свою форму, ч.т.д.

___

>**Теорема**
>Произведение линейных преобразований — линейное
>Произведение аффинных преобразований — аффинное

___

>**Теорема**
>Обратное к аффинному преобразование — аффинное

*Доказательство:*
Обратное преобразование взаимооднозначно.
Тогда достаточно доказать, что оно — линейное

$\begin{cases} x' = a_{1}x+b_{1}y+c_{1} \ | \cdot b_{2} \\ y' = a_{2}x+b_{2}y+c_{2} \ | \cdot b_{1} \end{cases}$

Вычтем второе из первого:
$x'b_{2} - y_{2}b_{1} = x(a_{1}b_{2} - a_{2}b_{1}) + c_{1}b_{2} - c_{2} ba$
$x'b_{2} - y_{2}b_{1} = x\cdot\Delta + c_{1}b_{2} - c_{2} ba$
$x=\frac{b_{2}}{\Delta}x'-\frac{b_{1}}{\Delta}y'-\frac{b_{2}c_{1}-b_{1}c_{2}}{\Delta}, \Delta \neq 0$
Аналогично $y=-\frac{a_{2}}{\Delta}x'+\frac{a_{1}}{\Delta}y'-\frac{a_{1}c_{2}-a_{2}c_{1}}{\Delta}$

Получаем, что обратное преобразование линейно:
$\begin{cases} x=A_{1}x'+B_{1}y'+C_{1}  \\ y =A_{2}x'+B_{2}y'+C_{2} \end{cases}$

____

>**Свойство линейных преобразований**
>Они сохраняют векторную структуру координат

$M_{1}(x_{1},y_{1}) \to M_{1}^*(x^*_{1}, y^*_{1})$
$M_{2}(x_{2},y_{2}) \to M_{2}^*(x^*_{2}, y^*_{2})$
$M_{1}M_{2} = (x_{2} - x_{1}, y_{2}- y_{1}) = (\alpha, \beta)$
$M_{1}^*M_{2}^* = (x^*_{2} - x^*_{1}, y^*_{2} - y^*_{1}) = (\alpha^*, \beta^*)$

$x^*_{1} =a_{1}x_{1}+b_{1}y_{1}+c_{1}$
$x^*_{2} =a_{1}x_{2}+b_{1}y_{2}+c_{1}$
$\alpha^* = x^*_{2}-x^*_{1} = a_{1}(x_{2} - x_{1}) + b_{1}(y_{2} - y_{1}) = a_{1}\alpha + b_{1}\beta$
Аналогично $\beta^* = y^*_{2}-y^*_{1} = a_{2}(x_{2} - x_{1}) + b_{2}(y_{2} - y_{1}) = a_{2}\alpha + b_{2}\beta$

$\begin{cases} \alpha^* = a_{1}\alpha + b_{1}\beta \\ \beta^* = a_{2}\alpha + b_{2}\beta\end{cases}$

**Геометрический смысл:**
- Линейная часть аффинного преобразования действует на **векторы**
- Перенос $(c_{1}, c_{2})$ действует на **точки**

*Тогда мы можем определить линейные преобразования для векторов:* 

>**Определение**
>Преобразование векторов $f$ называется **линейным**, если:
>$\ \forall \bar{a}, \bar{b} \ \forall k \in \mathbb{R} \to$ $\begin{cases} f(\bar{a}+\bar{b}) = f(\bar{a}) + f(\bar{b}) \\f(k\bar{a}) = kf(\bar{a}) \end{cases}$

*Доказательство:*
Пусть $\bar{a}(\alpha, \beta), \bar{b}(\alpha', \beta')$
Из *свойства линейных преобразований*, 
$f(\bar{a}) = (a_{1}\alpha+b_{1}\beta, a_{2}\alpha + b_{2}\beta), f(\bar{b}) = (a_{1}\alpha'+b_{1}\beta', a_{2}\alpha' + b_{2}\beta')$

**1. Аддитивность**
$f(\bar{a}+\bar{b}) = f(\alpha + \alpha', \beta + \beta') = (a_{1}(\alpha + \alpha') + b_{1}(\beta + \beta'), a_{2}(\alpha + \alpha') + b_{2}(\beta + \beta'))$
$= (a\alpha + b_{1}\beta + a_{1}\alpha'+b_{1}\beta', a_{2}\alpha+b_{2}\beta+a_{2}\alpha'+b_{2}\beta') = f(\bar{a}) + f(\bar{b})$

**2. Однородность**
$f(k\bar{a}) = f(k\alpha,k\beta) = (a_{1}k\alpha + b_{1}k\beta, a_{2}k\alpha+b_{2}k\beta) = kf(\bar{a})$

>**Следствие для линейных преобразований**
>При линейном преобразовании линейно зависимый набор 
>переходит в линейно зависимый набор.

*Доказательство:*
Векторы $\bar{a}, \bar{b}$ линейно зависимы $\iff \ \exists\lambda_{1}, \lambda_{2} : \lambda_{1}\bar{a} + \lambda_{2}\bar{b} = 0$ 
Мы знаем, что $f(\lambda_{1} \bar{a} + \lambda_{2} \bar{b}) = \lambda_{1} f(\bar{a}) + \lambda_{2} f(\bar{b})$ (*следует из аддитивности и однородности*)
Но $f(\lambda_{1} \bar{a} + \lambda_{2} \bar{b}) = f(0) = 0 = \lambda_{1} f(\bar{a}) + \lambda_{2} f(\bar{b}) \implies f(\bar{a}), f(\bar{b})$ линейно зависимы

>**Следствие для аффинных преобразований**
>При аффинном преобразовании линейно независимый набор 
>переходит в линейно независимый набор.

*Доказательство: от противного*
Пусть векторы $\bar{a}, \bar{b}$ линейно независимы, а их образы $f(\bar{a}), f(\bar{b})$ линейно зависимы.
Тогда $\ \exists\lambda_{1}, \lambda_{2}: \lambda_{1}f(\bar{a}) + \lambda_{2} f(\bar{b}) = 0 \iff f(\lambda_{1} \bar{a} + \lambda_{2} \bar{b}) = 0$
Но т.к. $f$ – взаимооднозначное, то $\lambda_{1}\bar{a}+\lambda_{2}\bar{b}=0$ – противоречие

>**Геометрический смысл коэффициентов преобразования**

В ОНБ $O(0, 0), \bar{e}_{1}(1, 0), \bar{e}_{2}(0, 1)$ линейное преобразование задаётся
формулами $\begin{cases} x' = a_{1}x+b_{1}y+c_{1} \\ y' = a_{2}x+b_{2}y+c_{2} \end{cases}$ . Тогда
- $f(O) = (c_{1}, c_{2})$
- $f(\bar{e}_{1}) = (a_{1}, a_{2})$
- $f(\bar{e}_{2}) = (b_{1}, b_{2})$

___

>**Теорема**
>$\ \forall$ точек $L, M, N$, не лежащих на одной прямой и $\ \forall L^*, M^*, N^*:$
>1. $\exists$ единственное линейное преобразование $f:$ $L^* = f(L), M^* = f(M), N^* = f(N)$ 
>2. Если $L^*, M^*, N^*$ не лежат на одной прямой, то $f$ — аффинное

*Доказательство:*
Рассмотрим ДСК ($L, LM, LN$). 
В ней: $L^*(c_{1}, c_{2})$, $L^*M^* (a_{1},a_{2}), L^*N^*(b_{1}, b_{2})$

1. Линейное преобразование $\begin{cases} x' = a_{1}x+b_{1}y+c_{1} \\ y' = a_{2}x+b_{2}y+c_{2} \end{cases}$ подходит:
$L = (0, 0) \to (c_{1}, c_{2}) = L^*$
$M = (1, 0) \to (a_{1} + c_{1}, a_{2} + c_{1}) = M^*$
$N = (0, 1) \to (b_{1} + c_{1}, b_{2} + c_{2}) = N^*$
Любое другое линейное преобразование имело бы другие коэффициенты $a_{i}, b_{i}, c_{i}$.
Тогда в таком случае изменились бы координаты какой-то из точек
2. Преобразование аффинно $\iff \begin{vmatrix} a_{1}&b_{1} \\ a_{2}&b_{2} \end{vmatrix} \neq 0 \iff$ $(a_{1}, a_{2})$ и $(b_{1}, b_{2})$ линейно независимые $\iff$ $L^*M^*$ и $L^*N^*$ не лежат на одной прямой

___

>**Теорема**
>Пусть $f$: $M \to M^*$ — аффинное преобразование.
>Тогда $M^*$ в системе координат $f(O)=O^*, f(\bar{e}_{1}), f(\bar{e}_{2})$ имеет те же координаты,
> что и точка $M$ в системе координат $O, \bar{e}_{1}, \bar{e}_{2}$

*Доказательство:*
$OM = x\bar{e}_{1} + y\bar{e}_{2}$
$f(OM) = xf(\bar{e}_{1}) + yf(\bar{e}_{2})$
$O^*M^* = xf(\bar{e}_{1}) + yf(\bar{e}_{2})$

>**Инвариантная прямая** — прямая, которая при линейном преобразовании отображается на себя

*Как находить?*
Пусть задано преобразование 
$$
\begin{cases}
x' = a_{1}x + b_{1}y + c_{1} \\
y' = a_{2}x + b_{2}y + c_{2}
\end{cases}
$$

Подставляем параметризацию прямой $y = kx + c$ в преобразование и требуем, чтобы её образ лежал на той же прямой

Для точки $(x, kx + c)$ её образ:
$$
\begin{cases}
x' = a_{1}x + b_{1}(kx + c) + c_{1} \\
y' = a_{2}x + b_{2}(kx + c) + c_{2}
\end{cases}
$$

Требуем:
$$
\begin{array}c
y' = kx' + c \\
a_{2}x + b_{2}(kx + c) = ka_{1}x + k^2b_{1}x + kb_{1}c + kc_{1} \\
(a_{2} + kb_{2} - ka_{1} - k^2b_{1})x + (cb_{2} - kb_{1}c - kc_{1}) = 0 \\
\end{array}
$$

Т.к. это должно выполняться $\ \forall x$, то:
$$
\begin{cases} a_{2} + kb_{2} - ka_{1} - k^2b_{1} = 0 \\
cb_{2} - kb_{1}c - kc_{1} = 0 \end{cases}
$$
Решаем, находим $k$ и $c$
