>**Кольцо** ($M, +, \times$):
>1. Коммутативная (aka Абелева) ($a + b = b + a$) группа по "$+$"
>2. Ассоциативность по "$\times$": $(a \times b) \times c = a \times (b \times c)$
>3. Дистрибутивность: $a \times (b + c) = a \times b + a \times c$ и $(b + c) \times a = b \times a + c \times a$

*Примеры:*
1. $(\mathbb{Z}_{m}, +, \times)$ - кольцо
2. $M = \{ 0, 1 \},$ $+$ = $\lor$, $\times = \land$:
$a\lor(b\lor c) = (a\lor b)\lor c$
$e=0: a \lor0 = 0 \lor a = a$
$x \lor 1 \neq 0$ - не существует обратный
Следовательно, $(M, \lor, \land)$ - не кольцо. Однако $(M, \oplus, \land)$ - кольцо
3. $a \times x + b = c, a \neq 0$ - нельзя решить в общем случае, т.к. нет обратного элемента по умножению

___

>**Поле** ($M, +, \times$)
>1. Коммутативная группа по "$+$"
>2. $(M\setminus \{ 0 \}, \times)$ - коммутативная группа по "$\times$"
>($\{ 0 \}$ - нейтральный элемент, у него нет обратного)
>3. Дистрибутивность: $a \times (b + c) = a \times b + a \times c$ и $(b + c) \times a = b \times a + c \times a$

*Примеры:*
1. ($\mathbb{Z}_{p}, +, \times$) - поле ($p$ - простое)
2. $a \times x + b = c, a \neq 0$ - можно решить
