##### Задача про города (гамильтонов путь)

$n$ городов
$(x_{i}, y_{i})$ - координаты городов

Карта двумерная. Хочется найти самый короткий гамильтонов путь.

Перебором? За $O(n! * n)$, к сожалению.

Оптимизируем при помощи масок.

$dp[mask][i]$ - минимальный Гамильтонов путь для mask городов.
Единички для тех городов, где уже были + поддерживаем последний город, в котором были.

$min(dp[2^n-1][i])$
$0 \leq i \leq n$

Для всех нулей ответ 0, для одной единицы ответ 0 (только начали путь).
Для двух единиц расстояние...


Считаем $dp[mask][i]$

mask = 0110010
011000

$dp[mask][i]=dp[mask$ ^ $(1 < < i)][j] + dist(i, j)$


for (mask=0; mask < (1<<n); mask++) {
	for (i=0; i < n; i++) {
		if (mask & (1 << i) != 0 )
			for (j=0; j<n; j++)
				if (mask & (1<<j) != 0) && (i != j)
					dp\[mask]\[i] = min(dp\[mask]\[i], dp\[mask^(i<<i))]\[j] + dist(i, j));
	}
}

Работает за $O(2^n * n^2)$
