6. *Черепашка-2. В этот раз у черепашки есть возможность прыгать по DAG. Найдите путь минимального веса из старта до финиша.*
 $dp[v]$ - минимальный вес пути от этой вершины до финиша.
 Идём с конца.
Как считать dp во время DFS?

```
dfs(v):
	ans = infinity;
	if v==finish:
		return 0;
	for (v, to):
		if (!is_visited(to))
			ans = min(ans, weight(v, to)+dp[v])
			dfs(to)
	return ans;
```

10. *Дано подвешенное дерево на N вершинах. Каждая вершина покрашена в какой-то цвет. Для каждой вершины найдите, сколько различных цветов в её поддереве, за $O(N*\log N)$*
Проходим через DFS. Для каждой вершины храним множество цветов в поддереве. Объединение множеств от детей размером N и M возможно за $O(N*\log(N+M))$. Перекладываем из множества меньшего размера в множество большего размера.
Общая асимптотика решения: $O(N*\log^2(N))$
Введём ранг множества: это количество вершин в поддереве.
Посмотрим, сколько раз переходит один цвет. Мы из множества с меньшим рангом перекладываем в множество с большим рангом. Ранг после слияния как минимум удвоится (относительно меньшего ранга).
Было множество с рангом A и с рангом B. $|A|\leq|B|$
$|A+B|\leq 2|A|$

Если вместо множеств использовать отсортированные двусвязные списки, слияние как в merge sort делать, тогда каждое перекладывание за $O(1)$.
Итоговая асимптотика: $O(N*\log(N))$
