Математическая логика (и не только она) состоит из двух частей:

*   **Синтаксис** — запись, форма.
*   **Семантика** — смысл, содержание.

---

## Формальная система

Формальная система нужна для того, чтобы из истинного утверждения получать истинное на этапе синтаксиса (т.е. манипулируя только формой, без обращения к смыслу).

Это набор из 4 множеств:
1.  **Алфавит** ($\sum$)
2.  **Формулы** ($F$)
3.  **Аксиомы** ($A$)
4.  **Правила вывода** ($R$)

### 1. Алфавит ($\sum$)
Как правило, это счётное множество.

### 2. Формулы ($F$)
Некоторое подмножество множества $\sum^*$ (где $\sum^*$ — множество всех конечных слов в алфавите $\sum$).

### 3. Аксиомы ($A$)
Некоторое подмножество множества формул ($A \subset F$).

### 4. Правила вывода ($R$)
Отображение из множества формул в новую формулу. Из $k$ формул получают одну новую.
$R: F^k \to F$
Правила вывода определены частично (некоторым наборам формул может не соответствовать ничего).

## Пример формальной системы: Исчисление высказываний

Его естественная семантика — булевы функции.

### 1. Алфавит ($\sum$)
Состоит из:
а) Счётного количества символов переменных (например, $A, B, C, \dots$).
б) Символов связок и скобок: $\bar{}$ (отрицание), $\to$ (импликация), $($, $)$.

### 2. Формулы ($F$)
Строятся рекурсивно:
1.  Если $A$ — символ переменной, то $A$ — формула.
2.  Если $A = (\bar{B})$, где $B$ — формула, то $A$ — формула.
3.  Если $A = (B \to C)$, где $B, C$ — формулы, то $A$ — формула.
4.  Других формул нет.

### 3. Аксиомы ($A$)
Множество аксиом в исчислении высказываний бесконечно, но они задаются тремя **схемами аксиом** (для любых формул $A, B, C$):

а) **Схема 1:** $(A \to (B \to A))$
б) **Схема 2:** $(A \to (B \to C)) \to ((A \to B) \to (A \to C))$
в) **Схема 3:** $(((\bar{B}) \to (\bar{A})) \to (((\bar{B}) \to A) \to B))$

### 4. Правила вывода ($R$)
Правило вывода одно — **Modus Ponens** (сокращённо MP):
$$A, A \to B \vdash B$$
> **Примечание:** Символ $\vdash$ означает "выводится".

С помощью этой системы можно получить (вывести) любую тавтологию, и только их.
