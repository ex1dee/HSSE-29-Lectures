**Полином Жегалкина** — это представление функции в виде суммы $(\oplus)$ произведений $(\land)$ над полем $\mathbb{F}_2$.

$$P(x_1, \dots, x_n) = a_0 \oplus a_1 x_1 \oplus a_2 x_2 \oplus \dots \oplus a_n x_n \oplus a_{12} x_1 x_2 \oplus \dots \oplus a_{12\dots n} x_1 x_2 \dots x_n,$$
где $a_{i} \in \{  0, 1 \}$

**Свойства:**

- $\neg x = x \oplus 1$
- $x \land y = x \cdot y$
- $x\lor y = x \oplus y \oplus xy$
- $x \land x = x$
- $x \oplus x = 0$

**Примеры:**

1. **Импликация ($x \to y$):**
    
    $$x \to y = \neg x \lor y = (x \oplus 1) \oplus y \oplus (x \oplus 1)y = x \oplus 1 \oplus y \oplus xy \oplus y = xy \oplus x \oplus 1$$
    
2. **Стрелка Пирса ($x \downarrow y$):**
    
    $$x \downarrow y = \neg(x \lor y) = (x \oplus y \oplus xy) \oplus 1 = xy \oplus x \oplus y \oplus 1$$
    
3. **Функция от трех переменных:**
    
    Если СДНФ функции $f = x\bar{y}z \lor xyz$, то в полиноме это:
    
    $$x(y \oplus 1)z \oplus xyz = (xyz \oplus xz) \oplus xyz = xz$$
    
    _(Здесь мы использовали свойство $A \oplus A = 0$)_.

>**Теорема**
>Для каждой булевой функции полином Жегалкина **единственен**.

*Доказательство:*
Пусть для некоторой функции $f$ существуют два различных полинома Жегалкина: $P_1$ и $P_2$.
   
Рассмотрим их сумму по модулю 2: $R = P_1 \oplus P_2$. Так как $P_1$ и $P_2$ представляют одну и ту же функцию, их значения на любых наборах совпадают. Следовательно, на любом наборе аргументов:

$$R(x_1, \dots, x_n) = P_1 \oplus P_2 = f \oplus f \equiv 0$$
   
Поскольку $P_1 \neq P_2$, полином $R$ не может быть пустым. В нем должны быть слагаемые (мономы). Выберем среди них слагаемое **наименьшей степени** $k$. Пусть это моном вида:
   
 $$x_{i_1} x_{i_2} \dots x_{i_k}$$
_(Если таких слагаемых несколько, выбираем любое из них с минимальной степенью)._

Рассмотрим набор значений переменных $\alpha$, в котором:
- $x_{i_1} = x_{i_2} = \dots = x_{i_k} = 1$
- Все остальные переменные $x_j = 0$


- **Анализ результата:**
    
    - Наше выбранное слагаемое на этом наборе равно **1**.
        
    - Любое другое слагаемое в $R$ либо имеет бóльшую степень, либо содержит другие переменные. Так как мы выбрали слагаемое _минимальной_ степени, все остальные мономы в $R$ обязательно содержат хотя бы одну переменную $x_j$, не входящую в наш набор $\{i_1, \dots, i_k\}$.
        
    - Поскольку все переменные вне этого набора равны **0**, все остальные слагаемые обращаются в **0**.
        

Получаем, что на выбранном наборе $\alpha$:
   
   $$R(\alpha) = 1 \oplus 0 \oplus 0 \dots = 1$$
**Противоречие.**
