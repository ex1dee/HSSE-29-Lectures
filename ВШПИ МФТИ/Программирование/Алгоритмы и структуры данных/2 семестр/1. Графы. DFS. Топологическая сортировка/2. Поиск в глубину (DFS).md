##### Алгоритм:

```cpp
vector<bool> used(n, false); // массив посещённых вершин

void dfs(const vector<vector<int>>& graph, int v) {
    used[v] = true; // помечаем вершину как посещённую
    
    // обходим всех соседей
    for (int u : graph[v]) {
        if (!used[u]) {
            dfs(graph, u); // рекурсивный вызов для непосещённых соседей
        }
    }
}
```

**Время работы:** $O(|V| + |E|)$
