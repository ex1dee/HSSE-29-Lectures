### Суть

Кратчайший путь в графе с $V$ вершинами не может содержать более $V-1$ ребра (иначе в нем появится цикл).

1. На **первой** итерации алгоритм находит все кратчайшие пути длиной **минимум** в 1 ребро.
    
2. На **второй** — длиной от 2 ребер.
    
3. На **$(V-1)$-й** — гарантированно находит все кратчайшие пути любой возможной длины.
    

___

### Алгоритм

1. **Инициализация:** `dist[start] = 0`, все остальные `dist = ∞`.
    
2. **Релаксация:** Повторить $V-1$ раз цикл по **всем** ребрам $(u, v)$ графа:
    
    - Если `dist[u] + weight(u, v) < dist[v]`, то `dist[v] = dist[u] + weight(u, v)`.
        
3. **Проверка на отрицательный цикл:** Пройтись по всем ребрам еще один раз. Если какое-то расстояние всё еще можно уменьшить — в графе есть отрицательный цикл.
    

___

### Код
```Java
for (int i = 0; i < n - 1; i++) {
	for (Edge e : edges) {
		if (dist[e.from] + e.weight < dist[e.to]) {
			dist[e.to] = dist[e.from] + e.weight;
		}
	}
}

// Проверка на отрицательный цикл
for (Edge e : edges) {
	if (dist[e.from] + e.weight < dist[e.to]) {
		// ...
	}
}
```

**Асимптотика:** $O(V \cdot E)$
