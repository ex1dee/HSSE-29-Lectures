#### DFS (Поиск в глубину)

```cpp
void dfs(graph g, int v) {
	used[v] = true;

	for (auto u : neighbours) {
		if (!used[u]) 
			dfs(g, u);
	}
}
```

**Асимптотика:** $O(\textbar V \textbar + \textbar E \textbar)$

#### Топологическая сортировка

$$\sigma \in S_{\textbar V \textbar} (перестановка) : \ \forall u, v \in E \to \sigma(u) < \sigma(v)$$
>Топ. сорт существует $\iff$ граф ациклический

*Доказательство:*

**(=>)**
$u_{1}, u_{2}, \dots, u_{n}, u_{1}$ – топ. сорт.
$\sigma(u_{1}) < \dots. < \sigma(u_{n}) < \sigma (u_{1})$

**(<=)**
$t_{in}[v]$ – время входа в вершину $v$ (стала серой)
$t_{out}[v]$ – время выхода из вершины $v$ (стала чёрной)

$(u, v) \in E$
$t_{out}[u] > t_{out}[v]$

1. Пусть $t_{in}[u] > t_{in}[v]$. Т.к. граф ациклический, то из $v$ нет пути в $u$
	$t_{out}[v] < t_{in}[u] < t_{out}[u]$ 
2. $t_{in}[u]<t_{in}[v]$

Сортируем вершины по $t_{out}$ (по убыванию)
