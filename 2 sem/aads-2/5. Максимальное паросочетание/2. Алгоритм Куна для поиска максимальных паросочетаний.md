1. Ориентируем: слева направо из паросочетания, справа налево не из паросочетания


```pseudocode
while (true)
	Ищем дополняющий путь. 
	Если есть, +1 к ответу,
	Иначе break
	
	Ориентируем рёбра
```

> [!TIP] Асимптотика. $O(N*(|V|+|E|))$

> [!P] Инсайт 1.
Если вершина с чем-то в паре, то из неё нет смысла уже запускать DFS.

>[!P] Инсайт 2.
Не нашли дополняющий путь, запустив DFS по всем вершинам левой доли => невозможно найти дополняющий путь

Заменим тогда ```while (true)``` на 
```java
for v : V {
dfs(v);
}
```


Напишем DFS


```python
dfs(v):
	if (used[v])
		return False
	used[v] = 1;
	for v.connected_with_u:
		if (p[u] == -1) or (dfs(p[u]))
			return True
	return False;
```

p\[v] - массив, показывающий, с какой вершиной из левой доли находится в паре вершина из правой.


 ```cpp
 for (i=j; i<n; i++) {
	fill(used, 0);
	anst=dfs(i);
 }
 ```

>[!INFO] Теорема Холла о совершенном паросочетании
> $|M_{max}|=n$
> $\exists$ совершенное паросочетание <=> $\ \forall A: |A|\leq|N(A)|$

DFS n раз вернёт True.
