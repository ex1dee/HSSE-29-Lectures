Наименьшим общим предком (**LCA**) двух вершин $u$ и $v$ в подвешенном дереве называется самая глубокая вершина $w$, которая является предком как для $u$, так и для $v$.

> [!EXAMPLE] Пример
> ```mermaid
> graph TD
>     A((1)) --> B((2))
>     A --> C((3))
>     B --> D((4))
>     B --> E((5))
>     C --> F((6))
>     E --> G((7))
>     E --> H((8))
> ```
> 
>
> 
> Для вершин **7** и **4**:
> 
> - Предки 7: {5, 2, 1}
>     
> - Предки 4: {2, 1}
>     
> - Общие предки: {2, 1}
>     
> - **LCA(7, 4) = 2**
>     

---

## Примитивная реализация (метод «прыжков»)

Суть алгоритма заключается в постепенном подъёме вершин к корню до их встречи.

**Алгоритм:**

1. Предварительно обходим дерево (DFS), вычисляя глубину `depth[v]` и непосредственного родителя `p[v]` для каждой вершины.
    
2. Если `depth[u] < depth[v]`, меняем их местами (**swap**), чтобы $u$ всегда была глубже.
    
3. Пока `depth[u] > depth[v]`, заменяем $u$ на её родителя `p[u]`, выравнивая уровни.
    
4. Пока $u \neq v$, одновременно поднимаем обе вершины: `u = p[u]`, `v = p[v]`.
    
5. Когда вершины совпали, текущая вершина и есть **LCA**.
    

**Асимптотика:**

- **Preprocessing** (DFS): $O(V)$
    
- **Query** (запрос): $O(H)$, где $H$ — высота дерева (в худшем случае $O(V)$).

## Оптимизация: Двоичные подъёмы

Чтобы ускорить поиск, будем хранить не только первого предка, но и предков на расстояниях $2^k$.

Пусть `up[v][k]` — это $2^k$-й предок вершины $v$.

> [!INFO] **Рекуррентное соотношение**
> 
> $$up[v][k] = \begin{cases}p[v], & k = 0 \\ up[up[v][k-1]][k-1], & k > 0\end{cases}$$
> 
> _Идея:_ Чтобы прыгнуть на $2^k$, нужно сначала прыгнуть на $2^{k-1}$, а затем из полученной точки прыгнуть еще на $2^{k-1}$.

**Алгоритм поиска:**

1. Выравниваем глубины вершин. Пусть $D = depth[u] - depth[v]$. Мы можем разложить $D$ в двоичную систему счисления и совершить соответствующие прыжки вверх для $u$.
    
2. Если после выравнивания $u = v$, то LCA найдена.
    
3. Если $u \neq v$, перебираем $k$ от $\max\_log=\log_{2}(N)$ вниз до $0$. Если `up[u][k] != up[v][k]` (`up[root][k] = root`), то «прыгаем» обеими вершинами вверх: `u = up[u][k]`, `v = up[v][k]`.
    
4. В итоге ответом будет `up[u][0]`.
    

**Асимптотика:**

- **Preprocessing:** $O(N \log N)$
    
- **Query:** $O(\log N)$
    

```cpp
int get_lca(int u, int v) {
    // 1. Гарантируем, что u глубже или на том же уровне
    if (depth[u] < depth[v]) swap(u, v);

    // 2. Выравнивание уровней (используем D)
    int D = depth[u] - depth[v];
    for (int k = MAXLOG; k >= 0; k--) {
        if ((D >> k) & 1) { // Если k-й бит D равен одному
            u = up[u][k];
        }
    }

    if (u == v) return u;

    // 3. Совместный прыжок
    for (int k = MAXLOG; k >= 0; k--) {
        if (up[u][k] != up[v][k]) {
            u = up[u][k];
            v = up[v][k];
        }
    }

    return up[u][0];
}
```
