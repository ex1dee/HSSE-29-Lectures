Обозначим $\circ: M \times M \mapsto M$ — алгебраическая операция (замкнутая)

___

>**Полугруппа** ($M, \circ$)  – Множество $M$ и бинарная операция $\circ$ (обозначается $(M, \circ)$), для которой выполняется ассоциативность: $a \circ (b \circ c) = (a \circ b) \circ c$
>**Моноид** ($M, \circ$) – полугруппа, у которой $\ \exists! e \text{ - нейтральный элемент} : a \circ e = e \circ a = a$
> **Группа** ($M, \circ$) – моноид, у которого $\ \forall x \ \exists!y \text{ - обратный элемент}: x \circ y = y \circ x = e$

>**Порядок группы** - количество элементов в ней
>Пример группы порядка $k$: $(\mathbb{Z}_{k}, +)$

Для любой группы уравнение $x \circ a = b$ решается так:
$x \circ a = b \iff x \circ a \circ a^{-1} = b a^{-1} \iff x \circ e= ba^{-1} \iff x = b a^{-1}$

*Примеры:*
Далее $\mathbb{Z}_{m}$ - целые числа по модулю $m\in \mathbb{Z}$
1. Операция $+_{m}$ - сложение по модулю $\to (\mathbb{Z}_{m}, +_{m})$ - группа
$a +_{m} (b +_{m}c) = (a +_{m}b) +_{m}c$
$\ \exists!0: a +_{m}0 = 0 +_{m} a = a$
$\ \forall a \ \exists (m-a) : a +_{m}(m - a) = 0$
2. Пусть $p \in \mathbb{N}, p$ - простое. $\mathbb{Z}_{p} \setminus \{ 0 \}$ = ${1, 2, \dots, p-1}$, операция $\times_{p}$ - умножение по модулю
$a \times_{p} (b \times_{p}c) = (a \times_{p}b) \times_{p}c$
По малой теореме Ферма у каждого числа $a \ \exists a^{p-2} : a*a^{p-2} \equiv_{p} a^{p-1}\equiv_{p}1$ 
Нейтральный элемент $- \ 1$
Тогда $(\mathbb{Z}_{p}\setminus \{ 0 \}, \times_{p})$ - группа
3. $M$ - множество перестановок $\{1, \dots, n\}$
$$
\pi=
\begin{pmatrix}
1, 2, \dots, n \\
i_{1}, i_{2},\dots, i_{n}
\end{pmatrix}, \pi(j) = i_{j}
$$
$$
\pi_{2}\circ\pi_{1} =
\begin{pmatrix}
 1 \ 2 \ 3 \ 4 \\
4 \ 1\ 3\ 2
\end{pmatrix} \circ
\begin{pmatrix}
1 \ 2 \ 3 \ 4 \\
2 \ 1 \ 4 \ 3
\end{pmatrix}
=
\begin{pmatrix}
1 \ 2 \ 3 \ 4 \\
1 \ 4 \ 2 \ 3
\end{pmatrix} = \pi,
\pi(j) = \pi_{2}(\pi_{1}(j))
$$
$$
x =
\begin{pmatrix}
1 \ 2 \ 3 \ 4 \\
4 \ 1 \ 2 \ 3
\end{pmatrix},
y = x^{-1} = 
\begin{pmatrix}
1 \ 2 \ 3 \ 4 \\
2 \ 3 \ 4 \ 1
\end{pmatrix},
x^{-1} \circ x = e = 
\begin{pmatrix}

$$

>**Мультипликативная запись группы**
>$(a * b) * c = a * (b * c)$
>$\ \exists! e = 1$ - нейтральный элемент
>$\ \forall x \ \exists!x^{-1}:x x^{-1} = x^{-1} x = 1$ - обратный элемент

>**Аддитивная запись группы**
>$(a +b) + c = a + (b + c)$
>$\ \exists! e = 0$ - нейтральный элемент
>$\ \forall x \ \exists!(-x):x + (-x) = (-x) + x = 0$
