Пусть $H \triangleleft G$ – нормальная подгруппа

>**Факторгруппа** $(G / H, \cdot)$ – это множество всех левых (правых) смежных классов по нормальной подгруппе $H$
>$G / H = \{ gH \ |\  g \in G \}$, $|G / H| = [G : H] = \frac{|G|}{|H|}$
>с операцией умножения: $(aH)(bH) = (ab)H$

*Пример:*
$G = \mathbb{Z}$ по сложению
$H = h\mathbb{Z}$ – числа, кратные $h$
$G / H$ = $\mathbb{Z}_{h}$ – циклическая группа порядка $h$
Элементы: $0 + h\mathbb{Z}, 1 + h\mathbb{Z}, \dots, (h - 1) + h\mathbb{Z}$

___

>Операция умножения **корректно определена**, т.е. результат 
>умножения не зависит от выбора представителя в смежных классах $aH$ и $bH$
>
>*Иначе говоря:* 
>Пусть $aH = a'H, bH = b'H$. 
>Тогда $(ab)H = (a'b')H$

*Доказательство:*
$aH = a'H \implies \ \exists h_{1}\in H: a'=ah_{1}$ 
$bH = b'H \implies \ \exists h_{2} \in H : b'=bh_{2}$

Тогда $a'b' = (ah_{1})(bh_{2}) = a(h_{1}b)h_{2}$
Т.к. $H$ – **нормальна**, то $\ \exists h_{3}\in H: h_{1}b=bh_{3}$
Подставляем: $a'b' = a(bh_{3})h_{2} = (ab)(h_{3}h_{2})$
Но $h_{3}h_{2}\in H \implies a'b'\in(ab)H$

>**Теорема о гомоморфизме**
>Пусть $\phi: G \to G'$ – гомоморфизм групп.
>Тогда $G / ker \ \phi \cong Im \ \phi$

*Доказательство:*
Определим отображение $f: G / ker \ \phi \to \mathrm{Im} \ \phi$ по правилу: $f(g \cdot ker \ \phi) = \phi(g)$

_**1. Корректность**:_
1. Если $g_{1} ker \ \phi = g_{2} ker \ \phi$, то, т.к. $e \in ker \ \phi$, то $g_{1} \cdot e = g_{1} \in g_{2} ker \ \phi$
2. Тогда $\ \exists k \in ker \ \phi : g_{1} = g_{2}k \implies g_{2}^{-1}g_{1} \in ker \ \phi$
3. Следовательно, $\phi(g_{2}^{-1}g_{1}) = e' \implies \phi(g_{1}) = \phi(g_{2})$
4. Значит, $f$ корректно определено

***2. Гомоморфность***:
$f((g_{1}ker \ \phi)(g_{2} ker \ \phi)) = f(g_{1}g_{2} ker \ \phi) = \phi(g_{1}g_{2}) = \phi(g_{1})\phi(g_{2}) = f(g_{1}ker \ \phi)f(g_{2}ker \ \phi)$

***3. Инъективность***:
Если $f(g_{1} ker \ \phi) = f(g_{2}ker \ \phi)$, то $\phi(g_{1}) = \phi(g_{2})$. Умножим на $\phi(g_{2})^{-1}$ слева:
$\phi(g_{2}^{-1})\phi(g_{1}) = e' \implies \phi(g_{2}^{-1}g_{1}) = e'$. Тогда $g_{2}^{-1}g_{1} \in ker \ \phi$ $\implies$ по теоремке, доказанной ранее, $g_{1}ker \ \phi = g_{2} ker \ \phi$ ([[6. Смежный класс]])

_**4. Сюрьективность**:_
Любой элемент $\mathrm{Im} \ \phi$ имеет вид $\phi(g) = f(g ker \ \phi)$

Значит, $f$ **биективно**, ч.т.д.
