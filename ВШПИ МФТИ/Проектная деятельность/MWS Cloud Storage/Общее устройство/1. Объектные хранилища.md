##### Сравнение с обычными файловыми системами:

| Объектные хранилища                                                                                                                                                   | Традиционные файловые системы                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Неструктурированные                                                                                                                                                   | Структурированы по папкам, имеют строгую иерархию                            |
| Хорошо подходят для больших объёмов данных, большого числа пользователей, т. к. не затрачиваются ресурсы на поиск по подпапкам и многочисленные проверки прав доступа | Хорошо подходят для небольших объёмов данных, небольшого числа пользователей |
| Поиск объекта по уникальному ключу                                                                                                                                    | Поиск данных по пути                                                         |
| Легко расширяется, можно хранить данные децентрализовано                                                                                                              | Требует форматирование диска или монтирование раздела для расширения         |


---


##### Применение облачных хранилищ

1. **Резервное копирование и архивирование**.  (Долгосрочное хранение бэкапов)
2. **Хранение медиафайлов.** ("Файлопомойка")
3. **Облачные приложения.** (Хранение пользовательских данных, логов, отчётов)
4. **Контейнеры и микросервисы.** (Передача данных между различными сервисами в контейнеризованной среде)
