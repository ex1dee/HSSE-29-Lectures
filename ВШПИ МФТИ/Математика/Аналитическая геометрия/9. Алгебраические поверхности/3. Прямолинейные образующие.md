#### Простой алгоритм нахождения прямолинейных образующих
Работает только для тех поверхностей, в уравнении которых есть разность квадратов
Разберём на примере однополостного гиперболоида:
$\frac{x^2}{a^2}+ \frac{y^2}{b^2}-\frac{z^2}{c^2}=1$

1. Перепишем уравнение в виде разности квадратов
$\frac{x^2}{a^2}-\frac{z^2}{c^2}=1-\frac{y^2}{b^2}$
$\left( \frac{x}{a}-\frac{z}{c} \right)\left( \frac{x}{a} +\frac{z}{c}\right)=\left( 1-\frac{y}{b} \right)\left( 1+\frac{y}{b} \right)$
2. Любое решение системы $\begin{cases} \alpha\left( \frac{x}{a} - \frac{z}{c} \right) = \beta\left( 1-\frac{y}{b} \right)  \\ \beta\left( \frac{x}{a}+\frac{z}{c} \right) =\alpha\left( 1+\frac{y}{b} \right) \end{cases}$ является решением полученного уравнения

3. Оба этих уравнения в системе задают плоскость. Значит, решением системы является прямая их пересечения. Но эта же прямая является решением уравнения поверхности $\implies$ она целиком лежит на поверхности.
4. Второе семейство образующих можно найти из аналогичной системы $\begin{cases} \alpha\left( \frac{x}{a} - \frac{z}{c} \right) = \beta\left( 1+\frac{y}{b} \right)  \\ \beta\left( \frac{x}{a}+\frac{z}{c} \right) =\alpha\left( 1-\frac{y}{b} \right) \end{cases}$

#### Общий алгоритм нахождения прямолинейных образующих

Возьмём точку $(x_{0}, y_{0}, z_{0}) \in$ поверхности 
Запишем параметрическое уравнение прямой, проходящей через эту точку:

$\begin{cases} x = x_{0}+a_{1}t \\ y = y_{0} + a_{2}t  \\ z = z_{0} + a_{3}t \end{cases}$

Подставляем уравнение прямой в уравнение поверхности.
После подстановки получаем квадратное уравнение
$At^2+Bt+C=0$

Чтобы вся прямая лежала на поверхности, это уравнение
должно выполняться для всех $t$. Это возможно только если $A = B = C = 0$

Но $C=0$, т.к. при $t = 0$ мы попадаем в точку $(x_{0}, y_{0}, z_{0})$, которая $\in$ поверхности
Решаем систему $\begin{cases} A = 0  \\ B = 0\end{cases}$ относительно $(a_{1}, a_{2}, a_{3})$

####  Корректное доказательство отсутствия прямолинейных образующих у двуполостного гиперболоида

**Неправильно:** 
Двуполостный гиперболоид состоит из двух частей
**Контрпример**: пара параллельных плоскостей)

**Правильно:** 
Плоскость $z=0$ не пересекает двуполостный гиперболоид. 
Чтобы прямая была прямолинейной образующей, она должна 
целиком лежать в поверхности, т.е. все её точки должны $\in$ гиперболоиду.
Тогда и точка пересечения с $z=0$ должна $\in$ гиперболоиду – противоречие
