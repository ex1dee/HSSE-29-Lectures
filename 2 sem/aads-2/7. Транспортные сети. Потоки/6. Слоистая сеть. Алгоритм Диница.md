Алгоритм развивает идеи Эдмондса — Карпа, используя концепцию **слоистых сетей** и **блокирующего потока**, что позволяет проталкивать поток сразу по нескольким путям за одну итерацию BFS.

---

### Основные понятия

- **Слоистая сеть ($L$)** — вспомогательный ориентированный граф, в который включаются только те ребра $(u, v)$ из остаточной сети $G_f$, для которых выполняется условие $dist(v) = dist(u) + 1$, где $dist(x)$ — кратчайшее расстояние от истока в ребрах.
    
- **Блокирующий поток** — поток в слоистой сети, после проталкивания которого в слоистой сети больше не остается путей из $s$ в $t$. Важно: блокирующий поток не обязательно является максимальным.
    

---

### Суть алгоритма

Каждая фаза состоит из двух этапов, которые «срезают» текущий слой кратчайших путей:

1. **Построение «каркаса» (BFS):**
    
    Мы запускаем BFS, чтобы разметить уровни вершин (расстояние от $s$). Это нужно, чтобы отфильтровать только те ребра, которые ведут **строго в сторону стока** кратчайшим путем ($dist[v] = dist[u] + 1$). Все остальные ребра на эту итерацию «выключаются».
    
2. **Массовая откачка (DFS + блокирующий поток):**
    
    Вместо того чтобы искать один путь, как в Эдмондсе — Карпе, мы запускаем DFS многократно по построенному каркасу.
    
    - Он «выжимает» все параллельные пути текущей длины.
        
    - Благодаря **указателю на текущее ребро** (`ptr`), DFS не заходит дважды в тупики или насыщенные ребра.
        
    - Когда DFS больше не может найти ни одного пути из $s$ в $t$ в рамках этой слоистой сети, говорят, что найден **блокирующий поток**.
	

---


> [!INFO] **Лемма (о росте расстояния)**
> 
> После каждой итерации (нахождения блокирующего потока) расстояние $dist(t)$ в следующей слоистой сети строго увеличивается: $dist_{i+1}(t) > dist_i(t)$.

Доказательство:

В процессе нахождения блокирующего потока используются только ребра слоистой сети $(u, v)$, где $dist(v) = dist(u) + 1$. Все новые ребра, появляющиеся в остаточной сети (обратные ребра), ведут из слоя $k+1$ в слой $k$. Следовательно, они не могут создать более короткий путь в сток, а все старые кратчайшие пути в слоистой сети были заблокированы.

___

### Асимптотика

> [!NOTE] **Обоснование сложности**
> 
> Общая сложность алгоритма: **$O(V^2 E)$**.
> 
> 1. **Количество итераций BFS:** Не более $V$. После каждой итерации (нахождения блокирующего потока) кратчайшее расстояние от $s$ до $t$ в остаточной сети строго увеличивается.
>     
> 2. **Поиск блокирующего потока:** Использование DFS с оптимизацией «удаления» тупиковых вершин и указателем на текущее ребро (ptr) позволяет найти блокирующий поток за $O(VE)$.
>     
> 
> На специальных графах алгоритм работает быстрее:
> 
> - В сетях с единичными пропускными способностями: $O(E \sqrt{V})$.
>     
> - В сетях с единичными пропускными способностями и отсутствием кратных ребер (сеть единичных мощностей): $O(E \cdot \min(V^{2/3}, E^{1/2}))$.
>     


> [!TIP] **Улучшение: Указатель на текущее ребро (Current Edge)**
> 
> Чтобы DFS работал за $O(VE)$, необходимо использовать массив `ptr`, который хранит индекс первого ребра в списке смежности вершины, через которое еще можно попробовать пропихнуть поток. Это предотвращает повторный просмотр ребер, которые уже были насыщены или ведут в "тупиковые" вершины в рамках текущей фазы.


---

### Пример кода (C++)


```python
 def dinic(n, s, t, edges_input):
    # adj[u] хранит списки [v, capacity, reverse_edge_index]
    adj = [[] for _ in range(n)]
    for u, v, cap in edges_input:
        adj[u].append([v, cap, len(adj[v])])
        adj[v].append([u, 0, len(adj[u]) - 1])

    def bfs():
        """Размечает уровни вершин (расстояния от s)"""
        levels = [-1] * n
        levels[s] = 0
        queue = [s]
        for u in queue:
            for v, cap, rev in adj[u]:
                if cap > 0 and levels[v] == -1:
                    levels[v] = levels[u] + 1
                    queue.append(v)
        return levels

    def dfs(u, flow, ptr, levels):
        """Ищет блокирующий поток"""
        if u == t or flow == 0:
            return flow
        
        # ptr[u] помогает не проверять ребра, которые уже не пропустят поток
        for i in range(ptr[u], len(adj[u])):
            ptr[u] = i
            v, cap, rev = adj[u][i]
            
            if levels[v] == levels[u] + 1 and cap > 0:
                pushed = dfs(v, min(flow, cap), ptr, levels)
                if pushed > 0:
                    adj[u][i][1] -= pushed
                    adj[v][rev][1] += pushed
                    return pushed
        return 0

    max_flow = 0
    while True:
        levels = bfs()
        if levels[t] == -1: # Сток недостижим
            break
        
        ptr = [0] * n
        while True:
            pushed = dfs(s, float('inf'), ptr, levels)
            if pushed == 0:
                break
            max_flow += pushed
            
    return max_flow
```
