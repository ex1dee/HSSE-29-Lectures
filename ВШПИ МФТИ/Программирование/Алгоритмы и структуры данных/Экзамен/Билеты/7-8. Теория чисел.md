## **1. Арифметика по модулю $m$ ($\mathbb{Z}_{m}$)**

Это арифметика с числами `0, 1, 2, ..., m-1`, где после операций берётся **остаток от деления на m**.

**Пример для m=7** ($\mathbb{Z}_{7}$):

```text
5 + 4 = 9 ≡ 2 (mod 7)   ← 9 % 7 = 2
3 × 6 = 18 ≡ 4 (mod 7)  ← 18 % 7 = 4
```

---

## **2. Обратный элемент по модулю**

В обычной арифметике: обратный к `a` = `1/a` или `a⁻¹`, где `a × a⁻¹ = 1`.

**По модулю m**: обратный к `a` — такое число `x`, что:

```text
a * x ≡ 1 (mod m)
```

Обозначается `a⁻¹ mod m`.

**Пример в Z₇**:

- Обратный к 3: `3 × 5 = 15 ≡ 1 (mod 7)` → `3⁻¹ ≡ 5 mod 7`
    
- Обратный к 2: `2 × 4 = 8 ≡ 1 (mod 7)` → `2⁻¹ ≡ 4 mod 7`
    

---

## **3. Критерий существования обратного**

**Теорема**: Обратный к `a` по модулю `m` существует **тогда и только тогда**, когда:

```text
НОД(a, m) = 1
```

(числа взаимно просты)

**Примеры для m=8**:

- `a=3`: НОД(3,8)=1 → обратный существует (3⁻¹ ≡ 3 mod 8)
    
- `a=2`: НОД(2,8)=2 ≠ 1 → обратного **нет**
    
- `a=5`: НОД(5,8)=1 → обратный существует (5⁻¹ ≡ 5 mod 8)
    

**Почему?** Если `d = НОД(a,m) > 1`, то `a = d·a₁`, `m = d·m₁`.  
Тогда `a × x ≡ 1 (mod m)` ⇒ `d·a₁·x ≡ 1 (mod d·m₁)` ⇒ `1 делится на d` → противоречие.

## **4. Поиск обратного: расширенный алгоритм Евклида**

### **Классический алгоритм Евклида** (НОД)

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a
```
**Идея**: `НОД(a, b) = НОД(b, a mod b)`
**Пример**: `НОД(30, 18)`
```
30 = 18 × 1 + 12  → НОД(30,18) = НОД(18,12)
18 = 12 × 1 + 6   → НОД(18,12) = НОД(12,6)
12 = 6 × 2 + 0    → НОД(12,6) = 6
```
### **Расширенный алгоритм Евклида**

Находит `x, y` такие, что:

```text
a·x + b·y = НОД(a, b)
```

**Если НОД(a,m)=1**, то:

```text
a·x + m·y = 1 ⇒ a·x ≡ 1 (mod m) ⇒ x = a⁻¹ mod m
```

**Алгоритм**:

```python
def extended_gcd(a, b):
    if b == 0:
        return a, 1, 0  # a = a×1 + b×0
    gcd, x1, y1 = extended_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return gcd, x, y
```

**Пример**: найти `3⁻¹ mod 7`

```text
НОД(7, 3):
7 = 3×2 + 1      → 1 = 7 - 3×2
3 = 1×3 + 0

Из 1 = 7 - 3×2:
1 = 7×1 + 3×(-2)
Значит, 3×(-2) ≡ 1 mod 7
-2 ≡ 5 mod 7
→ 3⁻¹ ≡ 5 mod 7 ✓
```

**Почему это работает?**

Пусть мы посчитали нужные коэффициенты $x’$ и $y’$, когда
рекурсивно считали $gcd(b,a \ mod \ b)$. Иными словами, у нас есть решение $(x’,y’)$ для пары $(b,a\ mod\ b)$:

$$b⋅x′+(a \ mod \ b)⋅y′=g$$Чтобы получить решение для исходной пары, запишем выражение $(a\ mod \ b)$ по определению как $\left( a−\lfloor \frac{a}{b}  \rfloor b \right)$ и подставим в приведенное выше равенство:
$$b⋅x′+\left( a−⌊\frac{a}{b}⌋⋅b \right)⋅y′=g$$

Теперь выполним перегруппировку слагаемых и получим:

$$a⋅y′+b⋅\left( x′−⌊\frac{a}{b}⌋⋅y′ \right)=g$$

Сравнивая это с исходным выражением, получаем, что для исходных $x$ и $y$ подходят коэффициенты при $a$ и $b$:
$$
\begin{array}{l}
x = y' \\
y = x' - \left\lfloor  \frac{a}{b}  \right\rfloor y'
\end{array}
$$

## **5. Малая теорема Ферма**

Если `p` — простое и `a` не делится на `p`, то:

$$a^{p-1} ≡ 1 \ (mod \ p)$$

**Следствие**: $a⁻¹ ≡ a^{p-2} \ (mod \ p)$

**Пример**: `3⁻¹ mod 7`  
`3^(7-2) = 3^5 = 243 ≡ 5 mod 7` ✓

### **6. Теорема Эйлера**

Обобщение для любого `m`.  
`φ(m)` — функция Эйлера (количество чисел от 1 до m-1, взаимно простых с m).

Если `НОД(a, m) = 1`, то:

$$a^{φ(m)} ≡ 1 \ (mod \ m)$$

**Следствие**: $a⁻¹ ≡ a^{φ(m)-1} \ (mod \ m)$

**Пример**: `3⁻¹ mod 8`  
`φ(8) = 4` (числа 1,3,5,7)  
`3^(4-1) = 3^3 = 27 ≡ 3 mod 8` → `3⁻¹ ≡ 3 mod 8` ✓
