>**Критерий параллельности вектора и плоскости**
>Дано: плоскость $P: Ax + By + Cz + D = 0$ и $\bar{a}(\alpha + \beta+\gamma)$
>$P \parallel \bar{a} \iff A\alpha+B\beta+C\gamma = 0$

*Доказательство*
Возьмём точку $M_{0}(x_{0}, y_{0}, z_{0})\in P$ с радиус-вектором $\bar{r}_{0}$.
$\bar{r}_{1} = \bar{r}_{0} + \bar{a}$. $M_{1}(x_{0}+\alpha, y_{0}+\beta, z_{0}+\gamma)$
$\bar{a}\parallel P\iff M_{1}\in P$
$A(x_{0}+\alpha) + B(y_{0}+\beta) + C(z_{0}+\gamma) + D= 0$
$Ax_{0} + By_{0}+Cz_{0}+D=0 \implies A\alpha+B\beta+C\gamma =0$

>**Критерий параллельности двух плоскостей**
>$P_{1}: A_{1}x + B_{1}y + C_{1}z + D_{1} = 0$ 
>$P_{2}:A_{2}x + B_{2}y + C_{2}z + D_{2} = 0$
>
>$P_{1} \ || \ P_{2} \iff (A_{1}, B_{1}, C_{1}) = \lambda(A_{2}, B_{2}, C_{2}), \lambda \neq 0  \text{ (т.е. нормали коллинеарны))}$
>$\iff [(A_{1}, B_{1}, C_{1}), (A_{2}, B_{2}, C_{2})] = 0$

>**Критерий совпадения плоскостей**
>$P_{1}: A_{1}x + B_{1}y + C_{1}z + D_{1} = 0$
>$P_{2}:A_{2}x + B_{2}y + C_{2}z + D_{2} = 0$
>
>$P_{1} = P_{2} \iff (A_{1}, B_{1}, C_{1}, D_{1}) = \lambda(A_{2}, B_{2}, C_{2}, D_{2}), \lambda \neq 0$

(**<=**) 
$A_{1}x+B_{1}y+C_{1}z+D = 0 \ (*), \ A_{1} = \lambda A_{2}, B_{1}=\lambda B_{2}, C_{1}=\lambda C_{2}, D_{1}=\lambda D_{2}$
Тогда $(*) \iff \lambda(A_{2}x + B_{2}y+C_{2}z+D_{2})=0 \implies$ т.к $\lambda\neq 0$, то $A_{2}x+B_{2}y+C_{2}z+D_{2}=0$
Т.е. множество решений $(x, y, z)$ для первой плоскости совпадает с множеством второй плоскости

(**=>**) 
$(A_{1}, B_{1}, C_{1}) = \lambda(A_{2}, B_{2}, C_{2})$, т.к. $P_{1} \parallel P_{2}$

Возьмём точку $P(x_{0}, y_{0},z_{0}) \in P_{1}=P_{2}$
$A_{1}x_{0}+B_{1}y_{0}+C_{1}z+D_{1} = 0, A_{2}x_{0}+B_{2}y_{0}+C_{2}z+D_{2} = 0$

Тогда $A_{1}x_{0}+B_{1}y_{0}+C_{1}z+D_{1} - \lambda(A_{2}x_{0} + B_{2}y_{0} + C_{2}z+D_{2}) = 0$
$(A_{1}-\lambda A_{2})x_{0} + (B_{1} - \lambda B_{2})y_{0} + (C_{1}-\lambda C_{2})z_{0} + D_{1}-\lambda D_{2} = 0$, 
но $A_{1}=\lambda A_{2}, B_{1}=\lambda B_{2}, C_{1}=\lambda C_{2} \implies D_{1}=\lambda D_{2}$ 

Итого: $(A_{1}, B_{1}, C_{1}, D_{1}) = \lambda(A_{2}, B_{2}, C_{2}, D_{2})$

$$

>1. Расстояние от точки до проекции прямой в плоскости, перпендикулярной ей и проходящей через точку
>2. Ортогональная составляющая
>3. Как высота параллелограмма: $\frac{|[\bar{a}, \bar{b}]|}{|\bar{a}|}$

>Расстояние между двумя прямыми $\bar{a}_{1}, \bar{a}_{2}$:
>1. Если параллельны, то расстояние от точки первой прямой до второй прямой
