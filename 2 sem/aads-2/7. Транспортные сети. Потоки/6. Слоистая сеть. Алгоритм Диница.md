Алгоритм развивает идеи Эдмондса — Карпа, используя концепцию **слоистых сетей** и **блокирующего потока**, что позволяет проталкивать поток сразу по нескольким путям за одну итерацию BFS.

---

### Основные понятия

- **Слоистая сеть ($L$)** — вспомогательный ориентированный граф, в который включаются только те ребра $(u, v)$ из остаточной сети $G_f$, для которых выполняется условие $dist(v) = dist(u) + 1$, где $dist(x)$ — кратчайшее расстояние от истока в ребрах.
    
- **Блокирующий поток** — поток в слоистой сети, после проталкивания которого в слоистой сети больше не остается путей из $s$ в $t$. Важно: блокирующий поток не обязательно является максимальным.
    

---

### Суть алгоритма

- **Инициализация:** Установить начальный поток $f(u, v) = 0$ для всех $(u, v) \in V \times V$.
    
- **Цикл фаз:** Пока в остаточной сети $G_f$ существует путь из $s$ в $t$:
    
    - **Шаг А. Построение слоистой сети ($L$):**
        
        1. Запустить BFS из вершины $s$ в графе $G_f$.
            
        2. Для каждой вершины $v$ определить $dist(v)$ — кратчайшее расстояние от $s$ в ребрах.
            
        3. Если $dist(t) = \infty$, алгоритм завершен.
            
        4. Сформировать слоистую сеть $L = (V, E_L)$, где ребро $(u, v) \in E_L \iff (u, v) \in E_f$ и $dist(v) = dist(u) + 1$.
            
    - **Шаг Б. Поиск блокирующего потока ($f'$):**
		
        1. Найти блокирующий поток $f'$ в сети $L$ с помощью серии вызовов DFS:
            
            - DFS ищет пути из $s$ в $t$, используя только ребра из $E_L$.
                
            - При нахождении пути поток вдоль него проталкивается, а емкости $c_f$ обновляются в $G_f$.
                
            - Если DFS вернулся из вершины $u$ с нулевым результатом (тупик), мы никак это не запоминаем и при следующем вызове DFS снова пойдем проверять те же самые ребра.
                
        2. Обновить общий поток: $f \leftarrow f + f'$.

---


> [!INFO] **Лемма (о росте расстояния)**
> 
> После каждой итерации (нахождения блокирующего потока) расстояние $dist(t)$ в следующей слоистой сети строго увеличивается: $dist_{i+1}(t) > dist_i(t)$.

Доказательство:

В процессе нахождения блокирующего потока используются только ребра слоистой сети $(u, v)$, где $dist(v) = dist(u) + 1$. Все новые ребра, появляющиеся в остаточной сети (обратные ребра), ведут из слоя $k+1$ в слой $k$. Следовательно, они не могут создать более короткий путь в сток, а все старые кратчайшие пути в слоистой сети были заблокированы.

___

### Асимптотика

#### Анализ DFS без оптимизации `ptr`

Когда мы запускаем DFS в слоистой сети $L$ без указателя на текущее ребро, каждый новый вызов функции начинает перебор списка смежности вершины $u$ с **самого первого ребра** (индекс 0).

##### Почему это плохо:

1. **Повторные посещения:** Пусть из вершины $u$ ведут 100 ребер. Первые 99 из них либо уже насыщены ($c_f = 0$), либо ведут в «тупики» (вершины, из которых невозможно дойти до стока $t$).
    
2. **Бесполезная работа:** Каждый раз, когда алгоритм будет искать новый путь через вершину $u$, DFS будет заново заходить в эти 99 ребер, тратить время на проверку условий и только потом переходить к 100-му ребру.
    
3. **Количество итераций:** В худшем случае каждый запуск DFS находит путь, который увеличивает общий поток всего на **1 единицу**.
    

#### Сложность без `ptr`:

Если величина блокирующего потока в текущей фазе равна $f'_{phase}$, а количество ребер в списке смежности — $|E|$, то в худшем случае DFS может совершить до $O(f'_{phase} \cdot |E|)$ операций

#### DFS с `ptr`

Массив `ptr[u]` хранит индекс первого ребра в списке смежности вершины $u$, которое **еще может** быть частью пути до стока.

> [!INFO] **Лемма**
> 
> С использованием `ptr`, суммарная сложность поиска блокирующего потока за одну фазу BFS составляет **$O(VE)$**.

**Доказательство:**

В рамках одной фазы (между построениями слоев) рассмотрим каждое ребро $(u, v) \in E_L$.

1. **Сдвиг указателя (Retreat):** Если DFS зашел в ребро $(u, v)$ и не смог через него найти путь до стока, мы делаем `ptr[u]++`. Это ребро **больше никогда** не будет посещено в этой фазе. Всего таких операций во всей фазе — $O(E)$.
    
2. **Насыщение ребра (Augmentation):** Если путь найден, как минимум одно ребро на этом пути насыщается. Мы также делаем `ptr[u]++` для этого ребра. Всего таких событий — $O(E)$.
    
3. **Проход по пути (Advance):** Каждый успешный или безуспешный поиск пути проходит не более $|V|$ вершин.
    
    - Суммарно "неудачные" заходы в ребра стоят нам $O(E)$.
        
    - Суммарно "удачные" проходы до стока стоят нам $O(V \cdot (\text{кол-во путей}))$. Так как каждый путь насыщает хотя бы одно ребро, путей не более $E$. Итого $O(VE)$.

### Итоговая асимптотика

Общая сложность алгоритма Диница: **$O(V^2 E)$**.

Это произведение двух факторов:

1. **Количество фаз — $O(V)$**: за счет того, что после каждого блокирующего потока кратчайшее расстояние $dist(s, t)$ строго растет (не более $V$ раз).
    
2. **Сложность одной фазы — $O(VE)$**: обеспечивается использованием **`ptr[u]++`**.

### Пример кода


```python
 def dinic(n, s, t, edges_input):
    # adj[u] хранит списки [v, capacity, reverse_edge_index]
    adj = [[] for _ in range(n)]
    for u, v, cap in edges_input:
        adj[u].append([v, cap, len(adj[v])])
        adj[v].append([u, 0, len(adj[u]) - 1])

    def bfs():
        """Размечает уровни вершин (расстояния от s)"""
        levels = [-1] * n
        levels[s] = 0
        queue = [s]
        for u in queue:
            for v, cap, rev in adj[u]:
                if cap > 0 and levels[v] == -1:
                    levels[v] = levels[u] + 1
                    queue.append(v)
        return levels

    def dfs(u, flow, ptr, levels):
        """Ищет блокирующий поток"""
        if u == t or flow == 0:
            return flow
        
        # ptr[u] помогает не проверять ребра, которые уже не пропустят поток
        for i in range(ptr[u], len(adj[u])):
            ptr[u] = i
            v, cap, rev = adj[u][i]
            
            if levels[v] == levels[u] + 1 and cap > 0:
                pushed = dfs(v, min(flow, cap), ptr, levels)
                if pushed > 0:
                    adj[u][i][1] -= pushed
                    adj[v][rev][1] += pushed
                    return pushed
        return 0

    max_flow = 0
    while True:
        levels = bfs()
        if levels[t] == -1: # Сток недостижим
            break
        
        ptr = [0] * n
        while True:
            pushed = dfs(s, float('inf'), ptr, levels)
            if pushed == 0:
                break
            max_flow += pushed
            
    return max_flow
```
