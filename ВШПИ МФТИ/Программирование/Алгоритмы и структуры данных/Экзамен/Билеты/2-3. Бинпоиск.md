- **Классический бинарный поиск:**
    - **Условие:** Массив отсортирован.
    - **Идея:** На каждом шаге сравниваем искомый элемент `x` с элементом в середине текущего отрезка `mid`. В зависимости от результата, отбрасываем левую или правую половину.
    - **Сложность:** `O(log n)`, так как на каждом шаге размер задачи уменьшается вдвое.

- **Бинарный поиск по ответу:**
    - **Идея:** Мы ищем не элемент в массиве, а **минимальное (или максимальное)** значение некоторого параметра `ans`, при котором выполняется заданное условие (предикат) `check(ans)`.
    - **Область применения:** Задачи вида "найти минимальное значение X, при котором можно...". Например: разрезать канат на K кусков не короче L, упаковать товары в минимальное количество контейнеров и т.д.
    - **Алгоритм для поиска минимального значения верного ответа:**
        1. Определяем границы поиска `[l, r]`, в которых точно лежит ответ.
        2. `while (l < r):`
        3. `mid = (l + r) / 2`
        4. Если `check(mid) == true`, то ответ `<= mid`, ищем слева: `r = mid`.
        5. Иначе (`check(mid) == false`), ответ `> mid`, ищем справа: `l = mid + 1`.
        6. По окончании цикла `l == r` — это искомый ответ
    - **Сложность:** `O(log(Range) * C)`, где `Range = r - l + 1`, `C` — сложность функции `check`. Обычно это `O(n)` или `O(1)`.

- **Вещественный бинпоиск**
	- **Отличия от целочисленного:**
	    - Ищем вещественное число (например, корень уравнения, оптимальное время).
	    - Цикл завершается не по равенству границ, а по **достижению требуемой точности** `ε` (эпсилон).
	- **Алгоритм:**
	    1. Задаем границы `[l, r]` и требуемую точность `ε` (например, `1e-7`).
	    2. `while (r - l > ε):`
	    3. `mid = (l + r) / 2`
	    4. Если `check(mid) == true`, то `r = mid`.
	    5. Иначе `l = mid`.
	    6. Ответ: `(l + r) / 2`.
	- **Важные замечания:**
	    - Важно выбрать `ε` соразмерно точности задачи (слишком маленький `ε` может привести к зацикливанию из-за погрешностей).
	    - Иногда используют фиксированное число итераций (например, 100), что гарантированно сужает отрезок в `2¹⁰⁰` раз.
	- **Сложность:** `O(log((r-l)/ε))`, но на практике считается константой, зависящей от требуемой точности.
