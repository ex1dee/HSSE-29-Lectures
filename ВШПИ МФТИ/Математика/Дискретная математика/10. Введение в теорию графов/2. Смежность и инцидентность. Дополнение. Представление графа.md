>**Смежность**
>Две вершины $u, v \in V$ называются смежными, если пара $(u, v) \in E$
>Два ребра $e_{1}, e_{2}$ называются смежными, если имеют общую вершину

>**Дополнение $\bar{G}(V, \bar{E})$ графа $G(V, E)$** — это граф с тем же множеством вершин, что и в $G$, в которым две различные вершины смежны тогда и только тогда, когда они **не смежны** в $G$: $\bar{E} = \{ uv  \ | \ u, v \in V, u \neq v, uv \not\in E \}$

___

**Матрица смежности** — матрица $N \times N$, у которой столбцы и строки — вершины графа и значение в клетке равно 1, если есть ребро <строка> $\leftrightarrow$ <столбец>, иначе – 0

|     | 1   | 2                | ... | n   |
| --- | --- | ---------------- | --- | --- |
| 1   | 0   | 1 (ребро (1, 2)) |     |     |
| 2   |     | 0                |     |     |
| ... |     |                  |     |     |
| n   |     |                  |     | 0   |

Для неориентированных графов матрица симметричная

___

>Вершина $v$ и ребро $(u, v)$ называются **инцидентными**

**Матрица инцидентности** — матрица $N \times M$, где $N=|V|$, $M=|E|$, у которой строки – вершины, столбцы – рёбра и значение в клетке равно 1, если вершина инцидентна ребру

|         | $e_{1}$ | $e_{2}$ | ... | $e_{m}$ |
| ------- | ------- | ------- | --- | ------- |
| $v_{1}$ | 1       | 0       |     |         |
| $v_{2}$ | 1       | 1       |     |         |
| ...     | 0       | 0       |     |         |
| $v_{n}$ | 0       | 1       |     |         |


___

>**Список смежности** — список, каждый элемент которого хранит вершины, соседние данной
