## Принцип

1. Инициализировать расстояния до всех вершин как $\infty$, до стартовой — $0$.
    
2. Выбрать непосещенную вершину $u$ с минимальным текущим расстоянием.
    
3. Для всех соседей $v$ вершины $u$ провести **релаксацию**: если путь через $u$ короче текущего известного пути до $v$ ($dist[u] + weight(u, v) < dist[v]$), обновить $dist[v]$.
    
4. Пометить $u$ как посещенную.
    
5. Повторять, пока остаются достижимые непосещенные вершины.

---

## Реализация на массиве

Подходит для **плотных графов** ($E \approx V^2$). Сложность: $O(V^2)$.

```java
// Матрица смежности: graph[u][v] = вес ребра (0 если ребра нет)
public void dijkstra(int[][] graph, int start) {
    int n = graph.length;
    int[] dist = new int[n]; 
    boolean[] visited = new boolean[n];

    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    for (int i = 0; i < n - 1; i++) {
        // Находим u с минимальным dist среди непосещенных
        int u = -1;
        for (int v = 0; v < n; v++) {
            if (!visited[v] && (u == -1 || dist[v] < dist[u])) {
                u = v;
            }
        }

        if (u == -1 || dist[u] == Integer.MAX_VALUE) break; 
        visited[u] = true;

        // Релаксация
        for (int v = 0; v < n; v++) {
            int weight = graph[u][v];
            if (weight > 0 && !visited[v]) {
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                }
            }
        }
    }
}
```

## Реализация на куче (Priority Queue)

Оптимальна для **разреженных графов**. Сложность: $O(E \log V)$.


```java
public void dijkstraWithPQ(List<List<Edge>> adj, int start) {
    int n = adj.size();
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    PriorityQueue<Node> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a.distance));
    pq.add(new Node(start, 0));

    while (!pq.isEmpty()) {
        Node current = pq.poll();
        int u = current.id;

        // Важная проверка: игнорируем устаревшие записи в куче
        if (current.distance > dist[u]) continue;

        for (Edge edge : adj.get(u)) {
            if (dist[u] + edge.weight < dist[edge.to]) {
                dist[edge.to] = dist[u] + edge.weight;
                pq.add(new Node(edge.to, dist[edge.to]));
            }
        }
    }
}
```

## Двухсторонний алгоритм Дейкстры

Вместо того чтобы раздувать один "пузырь" поиска из старта, мы запускаем два одновременных поиска:

1. **Прямой поиск** (Forward search) — от стартовой вершины $s$.
    
2. **Обратный поиск** (Backward search) — от целевой вершины $t$ (по реверсированным ребрам).
    

Поиск останавливается, когда какая-то вершина оказывается **посещенной в обоих поисках**, но **не** прекращается в момент первой «встречи». Мы продолжаем до тех пор, пока сумма минимальных расстояний в обеих очередях не станет больше или равна длине уже найденного пути $\mu$.

### Почему это быстрее?

В обычном алгоритме область поиска — это круг с площадью $\pi r^2$. В двустороннем — это два круга с радиусами $r/2$.

Суммарная площадь: $\pi (r/2)^2 + \pi (r/2)^2 = \frac{1}{2} \pi r^2$.

**Математически: мы сокращаем объем просматриваемых вершин примерно в 2 раза.**


```java
public int bidirectionalDijkstra(List<List<Edge>> adj, int s, int t) {
    // Две очереди и два массива расстояний
    PriorityQueue<Node> pqF = new PriorityQueue<>(Comparator.comparingInt(a -> a.distance));
    PriorityQueue<Node> pqB = new PriorityQueue<>(Comparator.comparingInt(a -> a.distance));
    
    int[] distF = new int[n]; // Прямые расстояния
    int[] distB = new int[n]; // Обратные расстояния
    Arrays.fill(distF, Integer.MAX_VALUE);
    Arrays.fill(distB, Integer.MAX_VALUE);
    
    distF[s] = 0; distB[t] = 0;
    pqF.add(new Node(s, 0)); pqB.add(new Node(t, 0));

    int shortestPath = Integer.MAX_VALUE;

    while (!pqF.isEmpty() && !pqB.isEmpty()) {
        // Шаг вперед
        Node currF = pqF.poll();
        int u = currF.id;
        
        if (distB[u] != Integer.MAX_VALUE) { // Защита от переполнения
	        if (distF[currF.id] + distB[currF.id] < shortestPath) {
	             shortestPath = distF[u] + distB[u];
	        }
        }
        // ... релаксация соседей currF ...

        // Шаг назад
        Node currB = pqB.poll();
        // ... релаксация соседей currB (по инвертированным ребрам) ...
        
        // Условие остановки: если минимальные элементы в PQ в сумме больше 
        // уже найденного пути, лучше мы уже не найдем.
        if (pqF.peek().distance + pqB.peek().distance >= shortestPath) break;
    }
    return shortestPath;
}
```
