у## 1. Изменяемые и неизменяемые типы

Это фундаментальное деление, определяющее, как данные ведут себя в памяти.

- **Immutable (Неизменяемые):** `int`, `float`, `str`, `tuple`, `frozenset`, `bytes`. При любом изменении создается новый объект.
    
- **Mutable (Изменяемые):** `list`, `dict`, `set`, `bytearray`. Можно менять содержимое объекта, не меняя его `id`.
    

### Замороженные коллекции:

- **`frozenset`**: Аналог `set`, но его нельзя менять после создания. Благодаря этому его можно использовать как ключ словаря.
    
- **`frozendict`**: Не входит в стандартную библиотеку (нужен `pip install frozendict`), но часто используется в функциональном стиле для гарантии целостности данных.

## 2. Копирование: `copy` vs `deepcopy`

Когда ты копируешь изменяемый объект (например, вложенный список), важно понимать глубину процесса:

- **Поверхностное копирование (`copy.copy()`):** Создает новый объект-контейнер, но вложенные элементы остаются ссылками на оригиналы.
    
- **Глубокое копирование (`copy.deepcopy()`):** Рекурсивно создает копии всех объектов, найденных внутри. Независимость полная.
    

```python
import copy
a = [[1], [2]]
b = copy.copy(a)     # b[0] всё еще ссылается на тот же список, что и a[0]
c = copy.deepcopy(a)  # c полностью независим
```

## 3. Моржовый оператор (`:=`)

Официально называется **Assignment Expression**. Позволяет одновременно вычислить выражение, присвоить его значение переменной и использовать его в условии.

```python
# Без моржа:
data = get_data()
if data:
    process(data)

# С моржом:
if data := get_data():
    process(data)
```

## 4. Области видимости: LEGB

В Python поиск переменной идет по цепочке: **L**ocal → **E**nclosing → **G**lobal → **B**uilt-in.

#### 1. **L**ocal (Локальная)

Это переменные, объявленные **внутри текущей функции**.

#### 2. **E**nclosing (Охватывающая)

Актуально только для **вложенных функций**. Это область видимости внешней функции по отношению к внутренней.   

#### 3. **G**lobal (Глобальная)

Это уровень **всего файла (модуля)**.

- Переменные, которые объявлены в коде без отступов (на главной ветке).
- Доступны из любой функции модуля (но для изменения внутри функции нужен `global`).

#### 4. **B**uilt-in (Встроенная)

Самый верхний уровень. Это всё, что вшито в сам Python «из коробки».

- Сюда входят стандартные функции и исключения: `print()`, `len()`, `range()`, `int`, `ValueError`.
    
- Ты всегда имеешь к ним доступ без импорта.

#### Операторы

- **`global`**: Позволяет изменять переменную, объявленную на уровне модуля, внутри функции.
    
- **`nonlocal`**: Используется в замыканиях (nested functions). Позволяет менять переменную из внешней («охватывающей») функции.
```python
def create_counter():
    count = 0  # Область видимости Enclosing (внешняя функция)

    def increment():
        nonlocal count  # используем count из create_counter
        count += 1
        return count

    return increment
```

## 5. Аргументы функций

Python гибко сопоставляет аргументы при вызове:

1. **Позиционные**: `func(1, 2)`
    
2. **Именованные (keyword)**: `func(a=1, b=2)`
    
3. **`*args`**: Собирает лишние позиционные аргументы в кортеж.
    
4. `**kwargs`: Собирает лишние именованные аргументы в словарь.

## 6. Чистые функции и их свойства

В функциональном программировании функция — это «черный ящик» с определенными правилами:

- **Детерминированность**: При одних и тех же входных данных функция **всегда** возвращает один и тот же результат. (Функция с `random` или `datetime.now()` — недетерминирована).
    
- **Побочные эффекты (Side Effects)**: Когда функция меняет что-то за своими пределами (меняет глобальную переменную, пишет в файл, выводит в консоль).
    
- **Чистая функция (Pure Function)**: Детерминирована + нет побочных эффектов. С ними проще всего проводить модульное тестирование.

## 7. Функции высшего порядка и Lambda

- **Функции высшего порядка**: Функции, которые принимают другие функции как аргументы или возвращают их (примеры: `map()`, `filter()`, `sorted()`).
    
- **Лямбда-функции**: Анонимные функции в одну строку.
```python
# lambda аргументы: выражение
square = lambda x: x**2    
```
