>**Критерий параллельности вектора и прямой**
>$\bar{a}(a_{1}, a_{2}) \parallel l : Ax + By + C = 0 \iff Aa_{1} + Ba_{2} = 0$ 

*Доказательство*
(**=>**) Пусть $\bar{a} \parallel l$. Возьмём точки $P(x_{0}, y_{0}), Q(x_{1}, y_{1})$ 
на прямой $l$ такие, что $\bar{a} = PQ(x_{1} - x_{0}, y_{1} - y_{0})$.
Т.к. $P$ и $Q$ лежат на одной прямой, то $A(x_{1} - x_{0}) + B(y_{1} - y_{0})  = Aa_{1} + Ba_{2}= 0$

(**<=**) Пусть $Aa_{1} + Ba_{2} = 0$. 
Возьмём произвольную точку $P(x_{0}, y_{0}) \in l$.
Рассмотрим точку $Q = P + \bar{a} = (x_{0} + a_{1}, y_{0} + a_{2})$
$A(x_{0}+a_{1}) + B(y_{0}+a_{2}) +C = 0$ 
$Ax_{0}+By_{0}+C + Aa_{1} + Ba_{2}=0$ 
$0 + 0 = 0$ - верно $\implies Q \in l \implies PQ \parallel \bar{a}, PQ \in l \implies l\parallel \bar{a}$ 

>**Критерий параллельности двух прямых**
>$l_{1}: A_{1}x + B_{1}y + C = 0$ 
>$l_{2}:A_{2}x + B_{2}y + C = 0$
>
>$l_{1} \ || \ l_{2} \iff (A_{1}, B_{1}) = \lambda(A_{2}, B_{2}), \lambda \neq 0  \text{ (т.е. нормали коллинеарны))}$ 
>$\iff [(A_{1}, B_{1}), (A_{2}, B_{2})] = 0 \iff A_{2}(-B_{1}) + B_{2}A_{1} = 0$

>**Критерий совпадения прямых**
>$l_{1}: A_{1}x + B_{1}y + C = 0$
>$l_{2}:A_{2}x + B_{2}y + C = 0$
>
>$l_{1} = l_{2} \iff (A_{1}, B_{1}, C_{1}) = \lambda(A_{2}, B_{2}, C_{2}), \lambda \neq 0$

(**<=**) 
$A_{1}x+B_{1}y+C_{1} = 0 \ (*), \ A_{1} = \lambda A_{2}, B_{1}=\lambda B_{2}, C_{1}=\lambda C_{2}$
Тогда $(*) \iff \lambda(A_{2}x + B_{2}y+C_{2})=0 \implies$ т.к $\lambda\neq 0$, то $A_{2}x+B_{2}y+C_{2}=0$
Т.е. множество решений $(x, y)$ для первой прямой совпадает с множеством второй прямой

(**=>**) 
$(A_{1}, B_{1}) = \lambda(A_{2}, B_{2})$, т.к. $l_{1} \parallel l_{2}$

Возьмём точку $P(x_{0}, y_{0}) \in l_{1}=l_{2}$
$A_{1}x_{0}+B_{1}y_{0}+C_{1} = 0, A_{2}x_{0}+B_{2}y_{0}+C_{2} = 0$

Тогда $A_{1}x_{0}+B_{1}y_{0}+C_{1} - \lambda(A_{2}x_{0} + B_{2}y_{0} + C_{2}) = 0$
$(A_{1}-\lambda A_{2})x_{0} + (B_{1} - \lambda B_{2})y_{0} + C_{1}-\lambda C_{2} = 0$, 
но $A_{1}=\lambda A_{2}, B_{1}=\lambda B_{2} \implies C_{1}=\lambda C_{2}$ 

Итого: $(A_{1}, B_{1}, C_{1}) = \lambda(A_{2}, B_{2}, C_{2})$
