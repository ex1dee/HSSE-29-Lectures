##### Предел по совокупности переменных

Пусть функция $f$ определена в проколотой окрестности точки $x_0 \in \mathbb{R}^n$, то есть $f: \dot{B}_\delta(x_0) \to \mathbb{R}$.
$A \in \overline{\mathbb{R}}$ называется пределом функции $f$ в точке $x_0$, если:

$$\forall \varepsilon > 0 \quad \exists \delta' \in (0, \delta] : \forall x \in \dot{B}_{\delta'}(x_0) \implies f(x) \in U_\varepsilon(A)$$
**По Гейне**, это эквивалентно тому, что для любой последовательности $\{x_n\} \subset E \setminus \{x_0\}$, такой что $x_n \to x_0$, выполнено $f(x_n) \to C$.

Также это эквивалентно **сходимости по норме**: 
$$\lim_{k \to \infty} \|x^{(k)} - a\| = 0$$

___
##### Предел по направлению

Пусть направление задано единичным вектором $l \in \mathbb{R}^n, \|l\| = 1$.
Пределом функции $f$ в точке $x_0$ **по направлению $l$** называется:

$$\lim_{t \to 0, t > 0} f(x_0 + t \cdot l)$$

___

> [!INFO] **Лемма**
> 
> Пусть $f : \dot{B}_\delta(x_0) \to \mathbb{R}$. Тогда:
> 
> $$\exists \lim_{x \to x_0} f(x) = C \in \mathbb{R} \implies \forall l \neq 0 \ \exists \lim_{t \to +0} f(x_0 + tl) = C \in \mathbb{R}$$
> 
> Обратное неверно.

**Доказательство:**

Отнормируем произвольный вектор, чтобы получить направление:

$x_0 + tl = x_0 + t' \frac{l}{\|l\|}$

Возьмем $t' = t\|l\|$. Получаем:

$x_0 + tl = x_0 + t' \frac{l}{\|l\|}$

Следовательно, достаточно доказать следующее утверждение:

$\exists \lim_{x \to x_0} f(x) = C \in \mathbb{R} \implies \forall l \in \mathbb{R}^n, \|l\| = 1 : \exists \lim_{t \to +0} f(x_0 + tl) = C$

Левая часть импликации по Коши означает:

$\forall \epsilon > 0 \ \exists \delta(\epsilon) > 0 : \forall x \in \dot{B}_{\delta(\epsilon)}(x_0) \implies f(x) \in U_\epsilon(C)$

Правая часть, в свою очередь, равносильна следующему:

$\forall l \in \mathbb{R}^n (\|l\| = 1) \ \forall \epsilon > 0 \ \exists \delta(\epsilon, l) > 0 : \forall t \in (0, \delta(\epsilon, l)) \implies f(x_0 + tl) \in U_\epsilon(C)$

Для того чтобы в проколотый шар $\dot{B}_\delta(x_0)$ попала точка $x_0 + tl$, в силу $\|l\| = 1$ необходимо взять $t \in (0, \delta)$. Положим $\delta(\epsilon, l) := \delta(\epsilon)$ и получим:

$x_0 + tl \in \dot{B}_{\delta(\epsilon, l)}(x_0) = \dot{B}_{\delta(\epsilon)}(x_0)$

Коль скоро $(x_0 + tl) \in \dot{B}_{\delta(\epsilon)}(x_0)$, значение $f(x_0 + tl) \in U_\epsilon(C)$. Что и требовалось доказать.

> [!EXAMPLE] **Пример (почему обратное неверно)**
> 
> Рассмотрим функцию:
> 
> $f(x, y) = \begin{cases} 1, & y = x^2 \text{ и } x \neq 0 \\ 0, & \text{иначе} \end{cases}$

**Обоснование примера:**

Любое направление $l \in \mathbb{R}^2$ можно задать углом $\phi \in (0, 2\pi]$ как $l = (\cos \phi, \sin \phi)$. Рассмотрим предел функции по направлению в точке $(0, 0)$:

1. Если $\phi \in [\pi, 2\pi] \cup \{ \frac{\pi}{2} \}$, то $\forall t > 0 \implies f(t \cos \phi, t \sin \phi) = 0$, а значит, предел равен $0$.
    
2. Пусть теперь $\phi \in (0, \frac{\pi}{2}) \cup (\frac{\pi}{2}, \pi)$. Значение функции равно $1$ тогда и только тогда, когда точка попадает на параболу:
    
    $t^2 \cos^2 \phi = t \sin \phi \implies t(\phi) = \frac{\sin \phi}{\cos^2 \phi}$
    
    То есть существует ровно одна точка пересечения луча направления с параболой. Для всех остальных значений $t \in (0, t(\phi))$ выполнено $f(t \cos \phi, t \sin \phi) = 0$. Рассматривая достаточно малую окрестность нуля $0 < t < t(\phi)$, по определению предела получаем:
    
    $\lim_{t \to +0} f(t \cos \phi, t \sin \phi) = 0$
    

Итого, предел функции по **любому** направлению равен $0$.

Однако предела по совокупности переменных $\lim_{(x,y) \to (0,0)} f(x, y)$ не существует. Рассмотрим две последовательности Гейне, стремящиеся к $(0, 0)$:

1. $\{x^{(1)}_n\} = (0, \frac{1}{n}) \implies f(0, \frac{1}{n}) = 0 \to 0$
    
2. $\{x^{(2)}_n\} = (\frac{1}{n}, \frac{1}{n^2}) \implies f(\frac{1}{n}, \frac{1}{n^2}) = 1 \to 1$
    

Пределы по последовательностям разные, следовательно, предела в точке $(0, 0)$ не существует.
