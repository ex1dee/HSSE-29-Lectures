- **Выборка**: пусть $T = \{x_i\}_{i=0}^{N_T}$ — разбиение отрезка $[a, b]$. **Выборкой**, соответствующей разбиению $T$, называется набор точек $\xi_T = \{\xi_i\}_{i=1}^{N_T}$ такой, что:
    
    $$\xi_i \in [x_{i-1}, x_i] \quad \forall i \in \{1, \dots, N_T\}$$
    
- **Интегральная сумма Римана**: пусть $f : [a, b] \to \mathbb{R}$, $T$ — разбиение, а $\xi_T$ — соответствующая ему выборка. Тогда интегральной суммой Римана называется:
    
    $$\sigma(f, T, \xi_T) := \sum_{i=1}^{N_T} f(\xi_i)(x_i - x_{i-1})$$
    

---

> [!INFO] **Теорема (критерий интегрируемости в терминах интегральных сумм Римана)**
> 
> Пусть $f : [a, b] \to \mathbb{R}$. Следующие условия эквивалентны:
> 
> 1. $f \in \mathcal{R}([a, b])$ и $J = \int_a^b f(x) \, dx$.
>     
> 2. $\lim_{l(T) \to 0} \sigma(f, T, \xi_T) = J$.
>     
> 
> _Формально для (2):_ $\forall \varepsilon > 0 \ \exists \delta(\varepsilon) > 0 : \forall T \in \mathcal{T}([a, b])$ при $l(T) < \delta(\varepsilon)$ и $\forall \xi_T \implies |\sigma(f, T, \xi_T) - J| < \varepsilon$.

**Доказательство:**

Рассмотрим условие (2) в виде неравенства: $J - \varepsilon \le \sigma(f, T, \xi_T) \le J + \varepsilon$ для $l(T) < \delta(\varepsilon)$.

Так как неравенство выполняется для **любой** выборки $\xi_T$, мы можем взять инфимум и супремум по всем возможным выборкам при фиксированном разбиении $T$:

$$J - \varepsilon \le \inf_{\xi_T} \sigma(f, T, \xi_T) \le \sup_{\xi_T} \sigma(f, T, \xi_T) \le J + \varepsilon$$

Заметим, что $\inf_{\xi_T} \sigma(f, T, \xi_T) = s_f(T)$ (нижняя сумма Дарбу) и $\sup_{\xi_T} \sigma(f, T, \xi_T) = S_f(T)$ (верхняя сумма Дарбу). Это следует из того, что:

$$\inf_{\xi_T} \sum f(\xi_i) \Delta x_i = \sum (\inf_{\xi_i \in [x_{i-1}, x_i]} f(\xi_i)) \Delta x_i = \sum m_i \Delta x_i = s_f(T)$$

Таким образом, имеем:

$$J - \varepsilon \le s_f(T) \le S_f(T) \le J + \varepsilon$$

Поскольку это верно для любого $\varepsilon$, разность $S_f(T) - s_f(T)$ может быть сделана сколь угодно малой при $l(T) \to 0$, что по критерию Дарбу эквивалентно интегрируемости $f$ и равенству интеграла числу $J$.

---

> [!INFO] **Теорема (линейность интеграла Римана)**
> 
> Множество $\mathcal{R}([a, b])$ является линейным пространством. То есть для любых $\alpha, \beta \in \mathbb{R}$ и $f, g \in \mathcal{R}([a, b])$ выполняется:
> 
> 1. $\alpha f + \beta g \in \mathcal{R}([a, b])$
>     
> 2. $\int_a^b (\alpha f + \beta g)(x) \, dx = \alpha \int_a^b f(x) \, dx + \beta \int_a^b g(x) \, dx$
>     

**Доказательство:**

Для любого разбиения $T$ и выборки $\xi_T$ справедливо равенство для сумм:

$$\sigma(\alpha f + \beta g, T, \xi_T) = \alpha \sigma(f, T, \xi_T) + \beta \sigma(g, T, \xi_T) \quad (\star\star)$$

Пусть $J_1 = \int_a^b f$ и $J_2 = \int_a^b g$. По критерию из предыдущей теоремы, для любого $\varepsilon > 0$ существуют $\delta_1, \delta_2$ такие, что при $l(T) < \delta = \min\{\delta_1, \delta_2\}$ суммы $f$ и $g$ близки к $J_1, J_2$ с точностью $\frac{\varepsilon}{2(|\alpha| + |\beta|)}$.

Используя неравенство треугольника и $(\star\star)$:

$$|\sigma(\alpha f + \beta g, T, \xi_T) - (\alpha J_1 + \beta J_2)| = |\alpha(\sigma(f) - J_1) + \beta(\sigma(g) - J_2)| \le$$

$$\le |\alpha| \cdot |\sigma(f) - J_1| + |\beta| \cdot |\sigma(g) - J_2| < |\alpha| \frac{\varepsilon}{2(|\alpha| + |\beta|)} + |\beta| \frac{\varepsilon}{2(|\alpha| + |\beta|)} \le \varepsilon$$

Следовательно, по критерию интегрируемости, линейная комбинация функций интегрируема, а её интеграл равен $\alpha J_1 + \beta J_2$.
