##### 2. Цель проекта
Целью нашего проекта является создание **облачного хранилища файлов на Java**, упрощённого аналога Google Drive или Яндекс.Диск.

Мы решаем 4 основные проблемы пользователей:

1. **Безопасность и контроль данных** — пользователь получает собственное защищённое пространство
2. **Упрощение совместной работы** — возможность управлять доступом к файлам и папкам для других пользователей
3. **Доступность файлов с любого устройства** — загрузил файл с ноутбука, открыл с телефона — всё работает через единое API
4. **Структурирование данных** — система папок, тегов и поиска помогает организовать даже большой объём файлов.

==Личная цель==
==Про безопасность==

##### 7. Схема БД
База данных состоит из трёх связанных таблиц:
1. Пользователи
2. Файлы (директории здесь же, так как они имеют схожие поля для метаданных) 
3. Refresh-токены
Files и Refresh Tokens зависят от Users.
##### 8. Стек технологий.
Backend написан полностью на языке Java. Для хранения данных мы используем S3-подобное хранилище MinIO. Метаданные и данные о пользователях хранятся в реляционной БД PostgreSQL. Для взаимодействия с базой данных используется JDBC. 

Для работы с соединениями, обработки HTTP-запросов и отправки ответов используется Netty Server, для генерации токенов используем JWT. ==Все компоненты системы развертываются на Docker-контейнерах.== ==Для тестирования используем TestContainers.==
