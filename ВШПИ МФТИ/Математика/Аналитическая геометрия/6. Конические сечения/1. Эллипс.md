>**Основные параметры**
>Фокусы: $F_{1}(-c, 0), F_{2}(c, 0)$, где $c = \sqrt{ a^2 - b^2 }$
>Эксцентриситет: $\epsilon = \frac{c}{a}, 0 \leq \epsilon < 1$
>Директрисы: $x = \pm \frac{a}{\epsilon}$ — внутри эллипса
>Вершины: $(\pm a, 0)$ и $(0, \pm b)$

___

>**Фокальное свойство**
>Пусть $M$ – точка на эллипсе в $I$ четверти
>$MF_{1} = a + \epsilon x$
>$MF_{2} = a - \epsilon x$
>$MF_{1} + MF_{2} = 2a$

*Доказательство:*
$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \iff y^2 = b^2\left( 1 - \frac{x^2}{a^2} \right)$
$c^2 = a^2 - b^2 \iff c^2 + b^2 = a^2$
$1 - \frac{b^2}{a^2} = \frac{a^2 - b^2}{a^2} = \frac{c^2}{a^2}$
$\epsilon = \frac{c}{a} \iff c = \epsilon a$

$MF_{2}^2 = (x - c)^2 + y^2 = (x-c)^2 + b^2 - \frac{b^2}{a^2}x^2= x^2 - 2cx + c^2+ b^2 - \frac{b^2}{a^2}x^2$
$= \left( 1 - \frac{b^2}{a^2} \right)x^2 - 2cx + c^2 + b^2 = \frac{c^2}{a^2}x^2 -2c x + a^2 = \left( \frac{c}{a}x - a \right)^2 = (a - \epsilon x)^2$
Аналогично $MF_{1}^2 = (x + c)^2 + y^2 = (a + \epsilon x)^2$

$MF_{1} = |a + \epsilon x|$
$MF_{2} = |a - \epsilon x|$ 

Но $|\epsilon x| = \epsilon|x| \leq \epsilon a = \frac{c}{a}a = c$
$a + \epsilon x \geq a - |\epsilon x| \geq a - c > 0$, т.к. $c = \sqrt{ a^2 - b^2 } < \sqrt{ a^2 } = a$
$a-\epsilon x \geq a - |\epsilon x| \geq a -c > 0$

Тогда $MF_{1} =  a+\epsilon x, MF_{2} = a - \epsilon x \implies MF_{1} + MF_{2} =2a$

>**Уравнение касательной**
$$\frac{x x_{0}}{a^2} + \frac{y y_{0}}{b^2} = 1$$

*Для вертикальных касательных* в точках $(\pm a, 0) \to x =\pm a$ верно:
$\pm\frac{ax}{a^2}  = \pm\frac{x}{a} = 1 \iff x = \pm a$ 

*Для остальных касательных:*
Продифференцируем обе части уравнения эллипса:
$\frac{2x}{a^2} + \frac{2yy'}{b^2} = 0 \implies y'(x_{0})=-\frac{x_{0}b^2}{a^2y_{0}}$

Уравнение касательной в точке: $y - y_{0} = y'(x_{0}) \cdot(x - x_{0})$
Тогда $y - y_{0} = \frac{x_{0}b^2}{a^2y_{0}}(x_{0} - x) \iff \frac{y_{0}(y -y_{0})}{b^2}= \frac{x_{0}(x_{0} - x)}{a^2} \iff \frac{x x_{0}}{a^2} + \frac{yy_{0}}{b^2} = \frac{x_{0}^2}{a^2}+\frac{y_{0}^2}{b^2} = 1$
