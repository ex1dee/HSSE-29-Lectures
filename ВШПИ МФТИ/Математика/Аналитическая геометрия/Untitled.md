##### Эллипс
$$
\begin{array}{}
\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \\
a \geq b > 0 \\
|x| \leq a, |y| \leq b
\end{array}
$$

$c = \sqrt{ a^2 - b^2 }$
$0 \leq \epsilon = \frac{c}{a} < 1$ – эксцентриситет

$y = \pm \frac{b}{a}\sqrt{ a^2-x^2}$

Точки пересечения с осями — вершины эллипса

>Пусть $M$ – точка на эллипсе, $F_{1} (-c, 0), F_{2}(c, 0)$ – его фокусы
>$MF_{1} + MF_{2} = 2a$

$MF_{1}^2 = (x - c)^2 + y^2 = (x-c)^2 + b^2 - \frac{b^2}{a^2}x^2= x^2 - 2x\epsilon a+\epsilon^2a^2 + b^2 - \frac{b^2}{a^2}x^2=(a - \epsilon x)^2$
$MF_{2}^2 = (a + \epsilon x)^2$

$MF_{1} = |a - \epsilon x|, MF_{2} = |a + \epsilon x|$
$MF_{1} + MF_{2} = 2a$

**Директрисы** - прямые, задающиеся уравнениями $x= \pm \frac{a}{\epsilon}$

>Пусть $M$ – точка на эллипсе, $D_{1}$ - проекция $M$ на $y = \frac{a}{\epsilon}$
>$MD_{1} = \frac{a}{\epsilon} - x \implies \frac{MF_{1}}{MD_{1}} = \epsilon$

>Пусть $(x_{0},y_{0})\in$ эллипсу. 
>Тогда уравнение касательной в этой точке:
>$\frac{x x_{0}}{a^2} + \frac{y y_{0}}{b^2} = 1$ 

Уравнение касательной: $y - y_{0} = y'(x_{0}) \cdot(x - x_{0})$

1. Для вертикальных касательных верно
2. Для остальных:

Продифференцируем обе части уравнения эллипса:
$\frac{2x}{a^2} + \frac{2yy'}{b^2} = 0 \implies y'(x_{0})=-\frac{x_{0}b^2}{a^2y_{0}}$

Тогда $y - y_{0} = \frac{b^2x_{0}}{a^2y_{0}}(x_{0} - x) \iff \frac{yy_{0}-y_{0}^2}{b^2}= \frac{x_{0}^2 - x x_{0}}{a^2} \iff \frac{x x_{0}}{a^2} + \frac{yy_{0}}{b^2} = \frac{x_{0}}{a^2}+\frac{y_{0}}{b^2} = 1$

$F_{1}M = (x_{0} - c, y_{0}), F_{2}M = (x_{0} + c, y_{0})$
