Пусть $G \subset \mathbb{R}^n, f : G \to \mathbb{R}$
График функции $f$ — это множество в $\mathbb{R}^{n+1}$, $\text{graph} f := \{(x, f(x)) : x \in G\}$
Пусть $n = (n_x, n_y, n_z)$ — нормальный вектор поверхности, проходящий через точку $(x_0, y_0, z_0)$

Будем считать, что плоскость «не вертикальна», то есть $n_z \neq 0$. Тогда уравнение имеет вид: $$n_x(x - x_0) + n_y(y - y_0) + n_z(z - z_0) = 0$$
$$z = z_0 - \frac{n_x}{n_z}(x - x_0) - \frac{n_y}{n_z}(y - y_0)$$

$\implies$ уравнение плоскости примет вид:
$$z = f(x_0, y_0) + N_x(x - x_0) + N_y(y - y_0). \quad (\star)$$
Плоскость вида $(\star)$ называется **касательной** к графику функции $f : G \to \mathbb{R}$ в точке $(x_0, y_0, f(x_0, y_0))$, если: $f(x, y) = z(x, y) + o\left(\sqrt{(x - x_0)^2 + (y - y_0)^2}\right), \quad (x, y) \to (x_0, y_0)$.
