**Асимптотика:** $O(V \cdot k + E)$.

**Суть:**

Вместо приоритетной очереди мы заводим массив бакетов (списков) размером $k+1$. В бакете `i` лежат вершины, расстояние до которых сейчас равно `i`.

- Мы просто сканируем бакеты по кругу.
    
- Когда мы находим более короткий путь до вершины (релаксация), мы просто перекладываем ее из одного списка в другой.

```python
def dial(graph, start, k):
    n = len(graph)
    dist = [math.inf] * n
    dist[start] = 0
    
    # Создаем k+1 бакетов (списков). 
    # buckets[i] хранит вершины v, у которых dist[v] % (k+1) == i
    buckets = [[] for _ in range(k + 1)]
    
    # Кладем стартовую вершину в бакет 0
    buckets[0].append(start)
    
    count = 1  # Количество вершин, которые осталось обработать
    pos = 0    # Текущая позиция в бакетах (текущее расстояние)
    
    while count > 0:
        # 1. Ищем ближайший непустой бакет, двигаясь по кругу
        while len(buckets[pos % (k + 1)]) == 0:
            pos += 1
            
        # 2. Берем вершину из текущего бакета
        v = buckets[pos % (k + 1)].pop()
        count -= 1
        
        # Если мы уже нашли путь короче, пропускаем (стандарт для Дейкстры)
        if dist[v] < pos:
            continue
            
        # 3. Релаксация ребер
        for u, weight in graph[v]:
            if dist[v] + weight < dist[u]:
                # Если вершина u уже была в каком-то бакете, 
                # мы её не удаляем (это долго), просто добавим в новый.
                # Условие dist[v] < pos выше отфильтрует старые записи.
                dist[u] = dist[v] + weight
                buckets[dist[u] % (k + 1)].append(u)
                count += 1
                
    return dist
```
