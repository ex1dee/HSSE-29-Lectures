**Матрица смежности** — матрица $N \times N$, у которой столбцы и строки — вершины графа и значение в клетке равно 1, если есть ребро <строка> $\leftrightarrow$ <столбец>, иначе – 0

|     | 1   | 2                | ... | n   |
| --- | --- | ---------------- | --- | --- |
| 1   | 0   | 1 (ребро (1, 2)) |     |     |
| 2   | 1   | 0                |     |     |
| ... |     |                  |     |     |
| n   |     |                  |     | 0   |

Для неориентированных графов матрица симметричная

___

**Матрица инцидентности** — матрица $N \times M$, где $N=|V|$, $M=|E|$, у которой строки – вершины, столбцы – рёбра и значение в клетке равно 1, если вершина инцидентна ребру

|         | $e_{1}$ | $e_{2}$ | ... | $e_{m}$ |
| ------- | ------- | ------- | --- | ------- |
| $v_{1}$ | 1       | 0       |     |         |
| $v_{2}$ | 1       | 1       |     |         |
| ...     | 0       | 0       |     |         |
| $v_{n}$ | 0       | 1       |     |         |


___

**Список смежности** — список, в котором каждой вершине сопоставляются смежные её вершины
