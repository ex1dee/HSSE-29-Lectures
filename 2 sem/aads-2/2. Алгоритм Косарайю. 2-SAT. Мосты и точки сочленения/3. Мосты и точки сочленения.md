**Дерево обхода DFS** — это остовное дерево (или лес), которое строится в процессе обхода графа в глубину. Ребра графа в контексте DFS делятся на:

- **Древесные ребра**: по которым мы впервые зашли в новую вершину.
    
- **Обратные ребра**: ведут из текущей вершины в уже посещенного предка в дереве DFS.
    

**Мост** — это ребро, при удалении которого количество компонент связности графа увеличивается.

**Точка сочленения** — это вершина, при удалении которой (вместе со всеми инцидентными ей ребрами) количество компонент связности увеличивается.

___

### Вспомогательные величины

Для поиска этих объектов используются два массива:

1. **`tin[v]`**: время входа в вершину
    
2. **`up[v]`**: минимальное `tin`, до которого можно добраться из $v$, используя ребра поддерева и не более одного обратного ребра.
    

___

### Алгоритм нахождения мостов

**Асимптотика:** $O(|V| + |E|)$ 

**Условие моста:** Ребро $(v, u)$ является мостом, если из поддерева $u$ нет обратных ребер в саму $v$ или выше нее:

$$tin[v] < up[u]$$

```python
def dfs_bridges(v, p=-1): # p - пред. вершина
    used[v] = True
    tin[v] = up[v] = timer++
    for u in graph[v]:
        if u == p: continue
        if used[u]:
            # Обратное ребро: подтягиваем up[v] через tin[u]
            up[v] = min(up[v], tin[u])
        else:
            # Древесное ребро
            dfs_bridges(u, v)
            up[v] = min(up[v], up[u])
            if tin[v] < up[u]:
                # Ребро (v, u) — мост
```

### Алгоритм нахождения точек сочленения

**Условие:**

1. Если $v$ — **корень** дерева DFS: она является точкой сочленения, если у нее $>1$ сына в дереве (именно по древесному ребру)
    
2. Если $v$ — **не корень**: она является точкой сочленения, если $\exists$ сын $u$ такой, что $tin[v] \leq up[u]$
