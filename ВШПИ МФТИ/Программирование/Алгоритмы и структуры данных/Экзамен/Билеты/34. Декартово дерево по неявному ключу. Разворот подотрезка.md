## **1. Область применимости**

Декартово дерево по **неявному ключу** — это декартово дерево (Treap), где:

- **Ключи не хранятся явно**
    
- **Позиция** элемента определяется его **порядком** в дереве
    

### **Решаемые задачи:**

1. **Разворот подотрезка** (главный пример)
    
2. **Циклический сдвиг**
    
3. **Вставка/удаление** в произвольную позицию
    
4. **Объединение/разделение** последовательностей
    
5. **Перенос** подотрезка в другое место
    

---

## **2. Основная идея**

### **Неявный ключ = размер поддерева**

Каждый узел хранит:

- `val` — значение
    
- `priority` — случайный приоритет
    
- `size` — размер поддерева
    
- `reverse` — флаг разворота (для задачи ниже)
    

### **Как найти k-й элемент:**

```text
size(left) = размер левого поддерева
if k < size(left): ищем в левом поддереве
if k == size(left): это текущий узел  
if k > size(left): ищем в правом поддереве с k' = k - size(left) - 1
```

## **3. Ленивое разворачивание**

### **Функция `push(node)`:**

```cpp
void push(Node* node) {
    if (!node || !node->reverse) return;
    
    // Меняем детей местами
    swap(node->left, node->right);
    
    // Проталкиваем флаг в детей
    if (node->left) node->left->reverse = !node->left->reverse;
    if (node->right) node->right->reverse = !node->right->reverse;
    
    // Сбрасываем флаг
    node->reverse = false;
}
```

## **4. Основные операции**

### **Функция `update(node)`:**

```cpp
void update(Node* node) {
    if (!node) return;
    node->size = 1;
    
    if (node->left) node->size += node->left->size;
    if (node->right) node->size += node->right->size;
}
```
### **Операция 1: `split(root, k)`**

Разделяет дерево на два:

- `left` — первые k элементов
    
- `right` — остальные
    

```cpp
void split(Node* root, int k, Node*& left, Node*& right) {
    if (!root) {
        left = right = nullptr;
        return;
    }
    push(root);  // проталкиваем разворот
    
    if (size(root->left) >= k) {
        split(root->left, k, left, root->left);
        right = root;
    } else {
        split(root->right, k - size(root->left) - 1, root->right, right);
        left = root;
    }
    update(root);  // пересчитываем size
}
```

### **Операция 2: `merge(left, right)`**

Объединяет два дерева:

```cpp

Node* merge(Node* left, Node* right) {
    if (!left) return right;
    if (!right) return left;
    
    push(left); 
    push(right);
    
    if (left->priority > right->priority) {
        left->right = merge(left->right, right);
        update(left);
        return left;
    } else {
        right->left = merge(left, right->left);
        update(right);
        return right;
    }
}
```

## **5. Разворот подотрезка [L, R]**

### **Алгоритм:**

1. `split(root, R+1, t1, t2)` → t1=[0..R], t2=[R+1..end]
    
2. `split(t1, L, t1, t3)` → t1=[0..L-1], t3=[L..R]
    
3. `t3->reverse = true` (помечаем разворот)
    
4. `merge(t1, t3)` → объединяем обратно
    
5. `merge(..., t2)` → полное дерево
    

```cpp
Node* reverse_segment(Node* root, int L, int R) {
    Node *t1, *t2, *t3;
    
    // 1. Отделяем всё после R
    split(root, R + 1, t1, t2);  // t1 = [0..R], t2 = [R+1..]
    
    // 2. Отделяем всё до L
    split(t1, L, t1, t3);  // t1 = [0..L-1], t3 = [L..R]
    
    // 3. Разворачиваем среднюю часть
    t3->reverse = true;
    
    // 4. Склеиваем обратно
    return merge(merge(t1, t3), t2);
}
```

## **6. Пример работы**

**Исходный массив:** `[1, 2, 3, 4, 5, 6, 7]`  
**Запрос:** развернуть отрезок [2, 5] (индексация с 0)

```text
Шаг 1: split(root, 6) → [1,2,3,4,5,6] и [7]
Шаг 2: split(первая часть, 2) → [1,2] и [3,4,5,6]
Шаг 3: t3->reverse = true (для [3,4,5,6])
Шаг 4: merge([1,2], развёрнутый [6,5,4,3]) → [1,2,6,5,4,3]
Шаг 5: merge(..., [7]) → [1,2,6,5,4,3,7]
```
