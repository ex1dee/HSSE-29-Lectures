## Полный список
### 1. Cloud Storage Backend (Основной сервис)

Самый нагруженный сервис, отвечающий за логику биллинга, хранение и API.

- **Core:** Java 21, Spring Boot 3.5.11.
    
- **Сетевой слой:** **Netty 4.2** (с BoringSSL для высокой производительности SSL/TLS).
    
- **База данных:** PostgreSQL, Flyway (миграции), Spring Data JPA (Hibernate).
    
- **Хранилище:** AWS SDK (S3) для работы с файлами.
    
- **Безопасность:** JWT (jjwt), jBCrypt (хэширование паролей).
    
- **Очереди:** Spring RabbitMQ (AMQP).
    
- **Мониторинг:** Micrometer + Prometheus, Spring Actuator.
    
- **Инструменты:** Lombok, OkHttp, Jackson, Failsafe (отказоустойчивость).
    

### 2. Antivirus Scanner Service (Сканер безопасности)

Микросервис для проверки загружаемых файлов.

- **Core:** Java 21, Spring Boot 3.5.11.
    
- **Антивирус:** **ClamAV Client**, **Apache Tika** (детектирование типов контента).
    
- **Кэширование:** Redis (через Spring Data Redis).
    
- **Интеграция:** AWS S3 SDK (для забора файлов на проверку).
    
- **Очереди:** Spring RabbitMQ.
    

### 3. Notification Service (Сервис уведомлений)

Сервис для связи с пользователями.

- **Core:** Java 21, Spring Boot 3.2.4.
    
- **Email:** Spring Mail (Jakarta Mail).
    
- **Шаблонизация:** **Thymeleaf** (для создания HTML-писем).
    
- **API:** Spring Web (REST).
