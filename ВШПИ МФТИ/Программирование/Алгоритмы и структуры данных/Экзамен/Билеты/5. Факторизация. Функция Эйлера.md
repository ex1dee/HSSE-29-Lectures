## 1. Факторизация

Это разложение натурального числа `n > 1` в произведение простых множителей (простых чисел) в натуральных степенях.

**Каноническая форма:**  
`n = p₁^{α₁} * p₂^{α₂} * ... * pₖ^{αₖ}`, где  
`pᵢ` — различные простые числа, `αᵢ ≥ 1`.

**Пример:**  
`84 = 2² * 3¹ * 7¹`

#### **Наивный алгоритм (для экза достаточно)**

``` python
def factorize(n):
    factors = {}
    d = 2
    
    while d * d <= n:
        while n % d == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 1 if d == 2 else 2  # после 2 проверяем только нечетные
    
    return factors
```

- **Сложность:** `O(√n)` в худшем случае (когда `n` — простое)

## 2. Функция Эйлера $\phi(n)$

### **Определение:**

`φ(n)` — это количество натуральных чисел от `1` до `n`, **взаимно простых** с `n` 

**Примеры:**
- `φ(1) = 1` (по определению).
- `φ(p) = p - 1`, если `p` — простое (все числа, кроме самого p).
- `φ(9) = 6` (числа 1, 2, 4, 5, 7, 8 — взаимно просты с 9).

### **Основные свойства функции Эйлера (важно!):**

1. **Мультипликативность:**  
    Если `gcd(a, b) = 1`, то `φ(ab) = φ(a) * φ(b)`.
    
2. **Формула для степени простого числа:**  
    `φ(pᵏ) = pᵏ - pᵏ⁻¹ = pᵏ⁻¹ * (p - 1)`.  
    
3. **Формула для общего случая** (вытекает из первых двух свойств):  
    Если `n = p₁^{α₁} * p₂^{α₂} * ... * pₖ^{αₖ}`, то
    
    $$\phi(n) = n \cdot \prod (1 - \frac{1}{p_{i}})$$

## **3. Сводимость вычисления φ(n) к факторизации**

Вычисление функции Эйлера `φ(n)` **сводится к факторизации** `n`
