$$
\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1
$$
$$
\text{Или явно: }y = \pm \frac{b}{a} \sqrt{ x^2 - a^2 }
$$

___

> Область определения: $|x| \geq a$

*Доказательство:*
$\frac{y^2}{b^2} = 1 - \frac{x^2}{a^2} \geq 0 \iff x^2 \geq a^2 \iff |x| \geq |a| \iff |x| \geq a$, т.к. $a \geq 0$

___

>**Основные параметры**:
>Асимптоты: $y = \pm \frac{b}{a}x$
>Эксцентриситет: $\epsilon = \frac{c}{a} > 1$, где $c = \sqrt{ a^2 + b^2 }$
>Директрисы: $x=\pm \frac{a}{\epsilon}$ — между ветками гиперболы

*Доказательство того, что $y = \pm \frac{b}{a}x$ – асимптоты:*
$y = \pm \frac{b}{a} \sqrt{ x^2 - a^2 } = \pm \frac{b}{a} |x|\sqrt{(1 - \frac{a^2}{x^2}) }$

При $x > 0:$ 
$y = \pm \frac{b}{a} x\sqrt{\left( 1 - \frac{a^2}{x^2} \right) } \iff \frac{y}{x} = \pm \frac{b}{a}\sqrt{\left( 1 - \frac{a^2}{x^2} \right) } \to \pm \frac{b}{a}, x\to +\infty$
$\implies$ угловой коэффициент асимптот: $k =\pm \frac{b}{a}$

Найдём смещение асимптот:
$\lim_{ x \to +\infty } (y(x) - kx) = \lim_{ x \to +\infty } \left( \pm \frac{b}{a} \sqrt{ x^2 - a^2 } \mp \frac{b}{a}x \right) = \pm \frac{b}{a} \lim_{ x \to +\infty }\left( \sqrt{ x^2 - a^2 } - x \right)$
$=\pm \frac{b}{a} \lim_{ x \to +\infty } \frac{(x^2 - a^2) - x^2}{\sqrt{ x^2 - a^2 } + x} = \pm \frac{b}{a}\lim_{ x \to +\infty } \frac{-a^2}{\sqrt{ x^2 - a^2 } + x} = \pm \frac{b}{a} \cdot 0 = 0$

Тогда асимптоты при $x > 0$ имеют вид: $y = \pm \frac{b}{a}x$
При $x < 0$ аналогично.

___

>**Фокальное свойство**
>Пусть $M$ – точка $I$ четверти на гиперболе
>$MF_{1} = \epsilon x_{0}  + a$
>$MF_{2} = \epsilon x_{0} - a$
>$|MF_{1} - MF_{2}| = 2a$

*Доказательство:*
$MF_{1}^2 = (x + c)^2 + y^2 = (\epsilon x + a)^2 \implies MF_{1} = |\epsilon x+a|$
$MF_{2}^2 = (x - c)^2 + y^2 = (\epsilon x - a)^2 \implies MF_{2} = |\epsilon x -a|$

$x \geq -a, \epsilon > 1 \implies \epsilon x + a > 0 \implies MF_{1} = \epsilon x +a$
$x \geq a, \epsilon > 1 \implies \epsilon x - a > 0 \implies MF_{2} = \epsilon x -a$

Тогда $MF_{1} - MF_{2} = 2a$
