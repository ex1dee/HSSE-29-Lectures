`df -h` - вывод данных об использовании места на диске файловыми системами
`lsblk` - показывает список блочных девайсов
`findmnt` - выводит список всех монтированных файловых систем
`sudo parted` - используется для управления разделами жёсткого диска
`sudo mkfs` - используется для создания файловой системы
`sudo mount` - отвечает за монтирование
/etc/fstab - текстовый файл, в который записываются как устройства хранения и файловые системы должны монтироваться при загрузке ОС
`cat /etc/fstab` - вывести содержимое этого файла

Пример:
`sudo mkfs.ext4 /dev/sdb1` 



/home/user/file - путь
Инода содержит метаинформацию о файле (имя, права, указатель на данные), но не сами данные в файле.
Количество инод ограничено в большинстве файловых систем, в btrfs не ограничено.

**Жёсткая ссылка (hard link)** - ссылка на иноду, содержащую счётчик ссылок. Когда счётчик обнуляется, данные помечаются как удалённые. Не могут работать с другими файловыми системами. Всегда актуальны.
**Мягкая ссылка (soft link)** - ссылка не на иноду, ссылка на путь файла. Могут работать с другими файловыми системами. Могут перестать быть актуальными после удаления/перемещения файла.


| Hard link                                       | Soft link                                                                       |
| ----------------------------------------------- | ------------------------------------------------------------------------------- |
| Ссылка на иноду                                 | Ссылка на путь файла                                                            |
| Не может работать с другими файловыми системами | Может работать с другими файловыми системами                                    |
| Всегда актуальна                                | Может потерять актуальность, стать "висячей", если файл переместить или удалить |
| Только для обычных файлов                       | Для файлов, каталогов, специальных файлов                                       |
