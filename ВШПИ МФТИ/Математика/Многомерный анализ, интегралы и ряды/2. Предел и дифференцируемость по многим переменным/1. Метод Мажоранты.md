Пусть $f: \dot{B}_d(x^0) \to \mathbb{R}$ — функция двух переменных. Мы хотим проверить, равен ли её предел числу $A$. Переходим к полярным координатам относительно точки $x^0$:

$$x_1 = x_1^0 + \rho \cos \phi, \quad x_2 = x_2^0 + \rho \sin \phi$$

где $\rho \in (0, d)$ — расстояние до точки (радиус), а $\phi \in [0, 2\pi)$ — угол.

___

>**Критерий мажоранты**
>$\lim_{ x \to x^0 }f(x) = A \iff \ \exists g : (0, d) \to [0, +\infty)$ — **мажоранта** $g(\rho)$, такая что:
>
>1. $|f(x_1^0 + \rho \cos \phi, x_2^0 + \rho \sin \phi) - A| \leq g(\rho)$ $\ \forall \rho \in (0, d) \ \forall \phi \in [0, 2\pi)$
>2. $\lim_{\rho \to 0} g(\rho) = 0$.

*Доказательство:*

**(=>)**
Пусть предел по совокупности существует и равен $A$. Тогда

$$\forall \varepsilon > 0 \ \exists \delta(\varepsilon) > 0 : \forall x \in \dot{B}_{\delta(\varepsilon)}(x^0) \implies |f(x) - A| < \varepsilon$$

В полярных координатах условие $x \in \dot{B}_{\delta(\varepsilon)}(x^0)$ эквивалентно тому, что $\rho \in (0, \delta(\varepsilon))$$\ \forall\phi$. Следовательно,$\ \forall \rho$ мы можем рассмотреть «самое плохое» отклонение по всем углам:

$$g(\rho) = \sup_{\phi \in [0, 2\pi)} |f(x_1^0 + \rho \cos \phi, x_2^0 + \rho \sin \phi) - A|$$

Поскольку для любого $\varepsilon$ при $\rho < \delta(\varepsilon)$ каждое значение под супремумом меньше $\varepsilon$, то и сам $g(\rho) \leq \varepsilon$. Это в точности означает, что $\lim_{\rho \to 0} g(\rho) = 0$. **Мажоранта найдена.**

**(<=)**

Пусть у нас есть мажоранта $g(\rho) \to 0$. Докажем существование предела по совокупности.
Возьмем произвольное $\varepsilon > 0$. Т.к. $g(\rho) \to 0$, то по определению предела для одной переменной:

$$\exists \delta(\varepsilon) > 0 : \forall \rho \in (0, \delta(\varepsilon)) \implies g(\rho) < \varepsilon$$

Но по условию мажорирования:

$$|f(x_1^0 + \rho \cos \phi, x_2^0 + \rho \sin \phi) - A| \leq g(\rho)$$

Следовательно, для любой точки $x$, попавшей в $\delta$-окрестность (то есть имеющей $\rho < \delta(\varepsilon)$), выполнено:

$$|f(x) - A| < \varepsilon$$
