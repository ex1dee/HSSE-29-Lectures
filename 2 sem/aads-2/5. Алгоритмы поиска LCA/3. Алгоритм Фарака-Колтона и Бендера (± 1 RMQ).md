Суть метода заключается в разделении исходного массива на блоки и раздельном решении задачи внутри блоков и между ними.

---

## 1. Подготовка и разбиение

1. Разбиваем массив $A$ длины $n$ на блоки размера $B = \frac{\log_2 n}{2}$ 
    
2. Всего получается $n/B$ блоков.
    
3. Для каждого блока $i$ находим локальный минимум $b_i$.
    
4. Строим **Sparse Table** над массивом этих минимумов $\{b_i\}$.
    
    - **Асимптотика:** $O(\frac{n}{B} \log \frac{n}{B}) = O(\frac{n}{\log n} \log n) = \mathbf{O(n)}$.
        

---

## 2. Типизация блоков (Свойство $\pm 1$)

Этот алгоритм работает эффективно только в том случае, если разность между соседними элементами массива равна $+1$ или $-1$.

> [!NOTE] Примечание
> 
> В общем случае RMQ это не так, но если мы свели **RMQ $\to$ LCA**, то в массиве глубин Эйлерова обхода это условие **всегда выполняется** (при переходе по ребру глубина меняется ровно на 1).

Поскольку мы работаем с массивом глубин Эйлерова обхода, мы знаем, что любые два соседних элемента в блоке отличаются ровно на $1$. Это ключевое свойство, которое позволяет нам не хранить сами числа, а хранить только схему их изменений.

**Как формируется маска типа**:

1. Если следующий элемент больше предыдущего ($+1$), записываем в маску бит **1**.
    
2. Если следующий элемент меньше предыдущего ($-1$), записываем в маску бит **0**.

**Количество типов блоков:**

Поскольку в блоке $B$ элементов, переходов между ними $B-1$. Каждый переход — это $+1$ или $-1$. Значит, существует всего $2^{B-1}$ различных типов «профилей» блоков. 

При $B = \frac{\log n}{2}$ количество типов составит $2^{\frac{\log n}{2} - 1} = \sqrt{n} / 2$, что значительно меньше $n$.

---

## 3. Вычисление минимумов для каждой маски

Для каждой маски мы создаем временный массив `temp[B]`.

1. Устанавливаем `temp[0] = 0`.
    
2. Проходим по битам маски от $0$ до $B-2$:
    
    - Если $i$-й бит равен `1`, то `temp[i+1] = temp[i] + 1`.
        
    - Если $i$-й бит равен `0`, то `temp[i+1] = temp[i] - 1`.

Теперь для этого массива `temp` нам нужно найти минимумы для всех возможных отрезков $[L, R]$ внутри него ($0 \le L \le R < B$).

```cpp
// precompute[mask][L][R] хранит индекс минимума относительно начала блока
for (int mask = 0; mask < (1 << (B - 1)); ++mask) {
    // 1. Восстанавливаем блок
    vector<int> temp(B);
    temp[0] = 0;
    for (int i = 0; i < B - 1; ++i) {
        if ((mask >> i) & 1) temp[i+1] = temp[i] + 1;
        else temp[i+1] = temp[i] - 1;
    }

    // 2. Считаем RMQ для всех L, R
    for (int L = 0; L < B; ++L) {
        int min_idx = L;
        for (int R = L; R < B; ++R) {
            if (temp[R] < temp[min_idx]) {
                min_idx = R;
            }
            precompute[mask][L][R] = min_idx;
        }
    }
}
```

---

## 4. Ответ на запрос $RMQ(l, r)$

Запрос разбивается на три части:

1. **Префикс:** часть от $l$ до конца его блока.
    
2. **Середина:** набор целых блоков между блоком с $l$ и блоком с $r$.
    
3. **Суффикс:** часть от начала блока с $r$ до самого $r$.
    

**Алгоритм:**

- Если $l$ и $r$ в одном блоке — берем ответ из предпосчитанной таблицы для этого типа блока за **$O(1)$**.
    
- Если в разных:
    
    - Минимум в середине ищем по **Sparse Table** (между блоками) за **$O(1)$**.
        
    - Минимумы в префиксе и суффиксе ищем по таблицам типов за **$O(1)$**.
        
    - Выбираем наименьший из трех результатов.
        

**Асимптотика**:

- **Preprocessing:** $O(n)$ (Sparse Table над блоками + таблицы типов).
    
- **Query:** $O(1)$.
