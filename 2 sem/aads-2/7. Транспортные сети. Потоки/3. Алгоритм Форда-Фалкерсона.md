Алгоритм предназначен для нахождения максимального потока в транспортной сети.

**На входе:** Ориентированный граф $G=(V, E)$ с пропускными способностями $c(u, v)$, исток $s$ и сток $t$.

### Суть алгоритма

Алгоритм основан на итеративном поиске дополняющих путей в остаточной сети до тех пор, пока они существуют.

1. **Инициализация:** Установить начальный поток $f(u, v) = 0$ для всех ребер $(u, v) \in E$.
    
2. **Поиск пути:** В остаточной сети $G_f$ найти любой путь из $s$ в $t$ (обычно используется **DFS**).
    
3. **Нахождение узкого места:** Найти ребро с минимальной остаточной пропускной способностью $\Delta$ на найденном пути:
    
    $$\Delta = \min \{c_f(u, v) : (u, v) \in \text{path}\}$$
    
4. **Модификация потока:** Вдоль всех ребер пути увеличить поток на $\Delta$. При этом для каждого ребра $(u, v)$ пути:
    
    - $f(u, v) \leftarrow f(u, v) + \Delta$
        
    - $f(v, u) \leftarrow f(v, u) - \Delta$ (согласно свойству антисимметричности)
        
5. **Повторение:** Обновить остаточную сеть и вернуться к шагу 2. Если пути из $s$ в $t$ больше нет — текущий поток максимален (из [[2. Разрезы. Теорема Форда-Фалкерсона|теоремы Форда-Фалкерсона]])
    

---

### Асимптотика

Сложность алгоритма: **$O(E \cdot |f|)$**, где $E$ — количество ребер, а $|f|$ — величина максимального потока.

**Обоснование:**

Каждая итерация (поиск пути через DFS) занимает $O(E)$. В худшем случае на каждой итерации величина потока увеличивается лишь на минимально возможную единицу (если веса целые). Таким образом, количество итераций может достигать $|f|$.

### Пример реализации

```python
def ford_fulkerson(graph, s, t):
    max_flow = 0
    
    # Пока существует путь в остаточной сети (находим через DFS)
    while True:
        path, delta = find_path_dfs(graph, s, t)
        if not path:
            break
        
        # Обновляем поток и остаточную сеть
        for u, v in path:
            graph[u][v]['flow'] += delta
            graph[v][u]['flow'] -= delta
        
        max_flow += delta
        
    return max_flow
```
