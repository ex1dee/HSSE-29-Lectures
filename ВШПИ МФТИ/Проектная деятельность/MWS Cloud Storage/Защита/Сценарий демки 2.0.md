- **Действие:** открываем демку
- **Речь:** _"А теперь давайте посмотрим, как работает наше облачное хранилище на практике. У нас готов полноценный веб-интерфейс, через который мы продемонстрируем весь жизненный цикл работы с файлами."_

___

**1. (13-16 сек) Вход в систему**

- **Действие:** Входим
- **Речь:** _"Сначала авторизуемся в системе"_

---

**2. (16-18 сек) Создание папки**
- **Действие:** Создаём папку под названием `pictures`.
- **Речь:** _"Теперь создаём новую папку..."_

___

**3. (18-28 сек) Загрузка файла (обычная)**

- **Действие:** Переходим в папку, загружаем в неё файл `image.jpg`
- **Речь:** _"...и загружаем в неё картинку небольшого размера, указывая теги. Она загрузится за один HTTP запрос."_

---

**4. (28-36 сек) Потоковая загрузка большого файла**

- **Действие:** Выходим из папки, выбираем файл `book.txt` для загрузки
- **Речь:** _"Выходим из папки и загружаем файл размером больше 5 МБ. Это минимальный размер, начиная с которого используется чанковая загрузка."_

---

**5. (36-42 сек) Просмотр содержимого хранилища**

- **Действие:** Переходим в папку `pictures`, показываем, что отображается файл `image.jpg`.
- **Речь:** _"Как видим, оба файла теперь отображаются в нашем облачном хранилище"_

---

**6. (42-48 сек) Получение информации о файле**

- **Действие:** Смотрим информацию о файле `pictures/image.jpg`
- **Речь:** _"Смотрим метаданные файла. Здесь отображаются его видимость, тип и теги"_

___

**7. (48-50 сек) Переименовывание файла**

- **Действие:** Переименовываем `pictures/image.txt` на `pictures/picture.txt`
- **Речь:** _"Переименовываем файл"_

---

**8. (50-56 сек) Потоковое скачивание**

- **Действие:** Выходим из папки и скачиваем `book.txt`. Можно даже открыть у себя файл
- **Речь:** _"Теперь скачаем его. Внутри клиент начнёт получать файл чанками и собирать их локально."_
