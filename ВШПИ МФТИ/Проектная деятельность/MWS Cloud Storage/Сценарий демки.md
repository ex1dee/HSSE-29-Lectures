#### Подготовка к демонстрации

1. Зарегистрировать юзера
#### Сценарий

**(0-5 сек) Введение:**  
_"А теперь давайте посмотрим, как работает наше облачное хранилище на практике. Я покажу ключевые операции через API."

**1. (5-15 сек) Авторизация.**

- **Действие:** `POST /api/users/auth/login`.
    
- **Комментарий:** _"Входим в систему, получаем токен для доступа."_
    
- **Важно:** Сохраните `X-Auth-Token` в переменную `authToken`.
    

**2. (15-25 сек) Обычная загрузка небольшого файла (для контекста).**

- **Действие:** `POST /api/files/upload?path=/readme.txt`.
    
- **Заголовки:** `X-Auth-Token: {{authToken}}`, `X-File-Tags: инструкция`.
    
- **Тело:** Маленький текстовый файл.
    
- **Комментарий:** _"Для начала загружаем небольшой файл обычным способом."_
    

**3. (25-40 сек) Потоковая (chunked) загрузка файла.**

- **Действие:** `POST /api/files/upload?path=/big_video_chunked.mp4`.
    
- **Заголовки:**
    
    - `X-Auth-Token: {{authToken}}`
        
    - `Transfer-Encoding: chunked` **<— КЛЮЧЕВОЙ МОМЕНТ**
        
    - `X-File-Tags: видео, потоковая_загрузка`
        
- **Тело:** Выберите файл побольше (например, 5-10 МБ видео или архив).
    
- **Комментарий:** _"А теперь ключевая фича — потоковая загрузка через `Transfer-Encoding: chunked`. Это позволяет загружать файлы любого размера без их полной загрузки в память и с возможностью возобновления."_
    
- **Визуальный акцент:** Покажите в интерфейсе Postman, что выбран режим "chunked".
    

**4. (40-50 сек) Просмотр списка файлов.**

- **Действие:** `GET /api/files/list`.
    
- **Заголовок:** `X-Auth-Token: {{authToken}}`.
    
- **Комментарий:** _"Видим, что оба файла — обычный и загруженный потоково — теперь в хранилище."_
    

**5. (50-60 сек) Потоковое скачивание файла.**

- **Действие:** `GET /api/files?path=/big_video_chunked.mp4`.
    
- **Заголовки:**
    
    - `X-Auth-Token: {{authToken}}`
        
    - `X-Download-Mode: chunked` **<— КЛЮЧЕВОЙ МОМЕНТ**
        
- **Комментарий:** _"Теперь скачаем этот большой файл тоже в потоковом режиме, используя наш кастомный заголовок `X-Download-Mode`. Сервер отдаст файл частями, что эффективно для больших объёмов."_
    
- **Важно:** Покажите в ответе заголовки, подтверждающие chunked-передачу.
    

**6. (60-70 сек) Создание папки и завершение.**

- **Действие:** Быстро выполняем `PUT /api/directories?path=/ChunkedDemo`.
    
- **Заголовок:** `X-Auth-Token: {{authToken}}`.
    
- **Комментарий:** _"Создаём папку для организации таких файлов. Таким образом, мы показали полный цикл работы с акцентом на потоковую передачу — ключевую архитектурную особенность нашего хранилища. Спасибо за внимание!"_
